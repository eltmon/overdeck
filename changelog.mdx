Overdeck ships to npm as [`@overdeck/core`](https://www.npmjs.com/package/@overdeck/core). Install or upgrade with `npm install -g @overdeck/core@latest`, then run `pan install` so the terminal backend and synced skills match the new version.

This page starts at v0.60.0, the release that removed Overdeck's state layer. Older releases are listed on [GitHub Releases](https://github.com/eltmon/overdeck/releases).

<Update label="v0.62.0" description="2026-09-26">
  #### New

  - **GPT-6 Sol and GPT-6 Luna:** OpenAI's new `gpt-6-sol` and `gpt-6-luna` are in the OpenAI provider, the model pickers and the cost tables, with the Codex 272K context limit applied. Defaults and routing are unchanged; pick them per role. ([#4234](https://github.com/eltmon/overdeck/pull/4234))
  - The Agents page opens on a **Live** view: running and in-pipeline agents are grouped into Needs you, Live and Waiting, each with one reason, in resizable panes with a collapsible preview and a new set of agent state colors. ([#4216](https://github.com/eltmon/overdeck/pull/4216))
  - Start a **bare conversation** from the Command Deck with the "No context" checkbox: no Overdeck-injected context and a faster spawn. ([#4187](https://github.com/eltmon/overdeck/pull/4187))
  - Pull requests are linked to conversations by branch, so a conversation shows the PR it produced. ([#4067](https://github.com/eltmon/overdeck/pull/4067))

  #### Improved

([#4066](https://github.com/eltmon/overdeck/pull/4066), [#4111](https://github.com/eltmon/overdeck/pull/4111))
  - **Faster CLI startup:** `pan` loads each command's code only when that command runs, so `pan --version` drops from about 560 ms to 180 ms. ([#4205](https://github.com/eltmon/overdeck/pull/4205))
  - The Command Deck issue tree shows a real state badge instead of "Allocated", one status signal per row, and each resource once as an icon cluster. ([#4218](https://github.com/eltmon/overdeck/pull/4218))
  - Board routes no longer wait on `gh pr list` or per-agent derivation, so the parked and auto-merge views load quickly. ([#4091](https://github.com/eltmon/overdeck/pull/4091))
  - An issue that was closed out renders as shipped, with its history, instead of as never started. ([#4078](https://github.com/eltmon/overdeck/pull/4078))
  - The status-bar emergency stop shows what it stopped. ([#4125](https://github.com/eltmon/overdeck/pull/4125))
  - The conversation feed shows ACP agents' thinking, prompt failures and stalled turns as their own rows. ([#4142](https://github.com/eltmon/overdeck/pull/4142), [#4141](https://github.com/eltmon/overdeck/pull/4141), [#4152](https://github.com/eltmon/overdeck/pull/4152))

  - `pan doctor` flags a stale `pan sync` source checkout, and `pan sync` prunes git hooks that were deleted upstream. ([#4148](https://github.com/eltmon/overdeck/pull/4148), [#4161](https://github.com/eltmon/overdeck/pull/4161))
  - **Dependency security updates:** an in-range refresh with security overrides clears most `bun audit` advisories, the desktop build moves to electron-builder 26 to clear a critical `tar` advisory, and the pinned CLIProxyAPI moves to v7.3.16. <Update label="v0.60.0" description="2026-09-23">
  ## The Cut

  Overdeck no longer keeps its own copy of pipeline state. Where an issue stands is read live from git, the issue tracker, the pull request and the terminal backend, so the dashboard can no longer drift from reality. Every feature stays; only the state layer is gone. [docs/THE-CUT.md](https://github.com/eltmon/overdeck/blob/main/docs/THE-CUT.md) maps each removed piece to its new home. ([#3917](https://github.com/eltmon/overdeck/issues/3917))

  What this changes for you:

  - **Herdr is the default terminal backend.** `pan install`, `pan sync`, `pan up` and `pan doctor` install and check Herdr for you. tmux is still supported through `terminal.backend: tmux`. See [Terminal backend](/configuration/terminal-backend). ([#3995](https://github.com/eltmon/overdeck/pull/3995))
  - **Planning artifacts live in your repo.** Drafts, specs, continues, orders and the backlog sequence are committed under `.pan/` in the project (or its plan home), not in a separate state worktree. `pan admin migrate-plan-home <project>` copies open issues' artifacts across.
  - **Merge readiness comes from the PR.** It is PR approvals, green checks and forge mergeability. Review verdicts are PR reviews, posted by the GitHub App.
  - **Retired commands.** `pan approve` becomes `gh pr review --approve` or the dashboard Merge button, `pan review pending` becomes `gh pr list`, and `pan inspect`, `pan reset-to-planned`, `pan unstick`, `pan review resync/reset` and `pan copy-config` are gone because there is no stored state left for them to act on.
  - **Simpler background supervisor.** The patrol loop is now four routines: nudge stuck work, nudge on API errors, reconcile liveness, and reap closed issues.

  #### New

  - Each issue keeps an append-only pipeline journal that `pan show` prints, and the work agent is told when verification passes instead of polling. ([a4fb7a4](https://github.com/eltmon/overdeck/commit/a4fb7a46abe))
  - Tests run once per push on CI, plus the touched tests locally, instead of the full suite on the host. ([#3993](https://github.com/eltmon/overdeck/pull/3993))
  - Claude Opus 5.5 support across launch, routing, model pickers and cost reporting. ([#3985](https://github.com/eltmon/overdeck/pull/3985))
  - A Conversations scope in the Ctrl-K command palette. ([#3933](https://github.com/eltmon/overdeck/pull/3933))
  - The `pan-open-threads` skill collects your unfinished threads across conversations into one checkable page. ([d35b93e](https://github.com/eltmon/overdeck/commit/d35b93ea3dd))

  #### Improved

  - Dashboard menus and popovers share one style, keyboard navigation, positioning and focus handling. ([#3945](https://github.com/eltmon/overdeck/pull/3945))
  - The backlog page is one ordered list without the Now, Next, Later and Someday bands, and it loads in a fraction of the time. ([7110e02](https://github.com/eltmon/overdeck/commit/7110e02356e), [#3978](https://github.com/eltmon/overdeck/pull/3978))
  - Transcripts stay findable: each session records its transcript path when it starts, and closing an issue keeps agent state and transcripts. ([#3976](https://github.com/eltmon/overdeck/pull/3976), [#3951](https://github.com/eltmon/overdeck/pull/3951), [#3979](https://github.com/eltmon/overdeck/pull/3979))

  - OpenCode conversations show their saved history, start and resume on Herdr, and recover from stalled permission prompts. ([#3986](https://github.com/eltmon/overdeck/pull/3986), [#3991](https://github.com/eltmon/overdeck/pull/3991), [#3970](https://github.com/eltmon/overdeck/pull/3970))
