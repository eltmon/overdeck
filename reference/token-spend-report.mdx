# Token Spend Report

Overdeck records the cost of its agents' and conversations' API calls in `~/.overdeck/costs/events.jsonl`. This interactive report visualizes that data, from model breakdowns to monthly trajectories to the actual codebase evolution video.

## What's Inside

This published report is a point-in-time snapshot. For live spend while agents
and conversations are running, open the dashboard's **Costs** page, titled
**Cost Tracking** (experimental: turn on Settings → Experimental →
**Experimental features** to show it). It shows total cost, event count, budget
warnings, issues over budget, a 30-day cost trend and costs by issue.

See [Costs and spend](/features/costs) for what the page shows today.

The report reads one data source, the cost event log at
`~/.overdeck/costs/events.jsonl`, after `pan cost backfill` has rebuilt events
from stored Claude Code, Pi/ohmypi and Codex session transcripts. It covers
April 11 to July 6, 2026. The pre-rebrand era (Feb 2025 to Jun 2026: 734,117
calls, about &#36;54k) was deliberately not imported.

today's cost (UTC), active and stuck agents, and the top agents and issues by
cost. Its handoff count and historical trend charts are placeholders that say

## Regenerating the Report

The report is regenerated with the `/token-spend-report` developer skill. To update it:

1. Run the skill: `/token-spend-report`
2. It runs `pan cost backfill` as a dry run, then `pan cost backfill --write` when the summary looks sane
3. It aggregates `~/.overdeck/costs/events.jsonl` only, sorted by timestamp
4. It updates `docs/token-spend-report/index.html`, keeping the coverage banner and the note that the pre-rebrand era was not imported
5. It regenerates the videos only when you ask

You don't publish the report by hand. After the change merges to `main`, the GitHub Pages workflow publishes it.

The skill's source is `sync-sources/dev-skills/token-spend-report/SKILL.md`. It's a developer skill, so `pan sync` installs it at `~/.claude/skills/token-spend-report/SKILL.md` only when Overdeck runs from a source checkout.

## GitHub Pages

The `.github/workflows/pages.yml` workflow publishes `docs/token-spend-report/` to GitHub Pages:

```
https://eltmon.github.io/overdeck/token-spend-report/
```

The workflow runs on pushes to `main` that change `docs/token-spend-report/` or the workflow file, and when started by hand.
