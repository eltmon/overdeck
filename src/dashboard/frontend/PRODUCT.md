# Product

## Register

product

## Users

Software developers operating AI-assisted engineering work from a local, desktop-class environment. They need to start, inspect, steer, verify, and ship work across issues without switching among tracker, terminal, CI, and model-provider tools.

## Product Purpose

Command Deck is the visual control surface for Overdeck's agent pipeline. It should make current state, inherited policy, available actions, and the consequence of each action legible enough that an operator can safely run one issue or many autonomous issues from the same interface.

## Brand Personality

Professional, direct, and operational. The interface should feel calm under load, dense without becoming cryptic, and confident without ornament competing with the work.

## Anti-references

Avoid decorative SaaS dashboards, unfamiliar controls for standard settings, hidden inheritance, ambiguous automation, and interfaces that require a second documentation view to understand the consequence of an action.

## Design Principles

- Show effective state and its source together so operators can distinguish configured values from inherited values.
- Make automation explicit before it runs and preserve deliberate manual overrides.
- Keep one visual and interaction vocabulary across CLI-backed settings, issue controls, and pipeline actions.
- Prefer dense, scan-friendly information over decorative surfaces, while keeping action consequences in complete sentences.
- Design for the current local operator without baking local-only assumptions into the information architecture.

## Accessibility & Inclusion

Use semantic controls, visible keyboard focus, sufficient text and state contrast, labels that do not depend on color, reduced-motion-safe transitions, and responsive layouts that preserve every action at narrow widths.
