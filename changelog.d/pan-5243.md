#### Fixed

- **A second `pan start` no longer kills a running work agent:** when two starts raced for the same issue, for example a recovery `pan start` and the late auto-start after planning, the losing start closed the winner's pane and left its own pane behind. Now only one start can launch an agent at a time. The second start prints that the agent is already running, names its pane and exits 0. A failed launch closes only the pane it opened itself. ([#5243](https://github.com/eltmon/overdeck/issues/5243))
