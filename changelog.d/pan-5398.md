#### Fixed

- **`pan open` opens in the right deck:** for a project whose name differs from its registered key (such as overdeck, whose key is `panopticon-cli`), `pan open` and the `/open` link now open the path in the project's own deck instead of an empty deck named after the key. The CLI line and the dashboard toast name the project as the switcher shows it, and an issue target says `Opened the <issue> workspace in <project>`. ([#5398](https://github.com/eltmon/overdeck/issues/5398))
