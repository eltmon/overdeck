#### Improved

- **Turn cards:** each turn that changed files now ends with a card that shows the files, the lines added and removed, and how many commits are pushed, not pushed or not committed. In a Command Deck tab, **Review** opens the turn's files in the side panel and **Show in files** filters the Files tab to the conversation; elsewhere the card opens the diff window. It replaces the "Changed files" card and the diff panel beside the chat; ⋯ → **Full diff in a new window** opens the full diff. ([#5295](https://github.com/eltmon/overdeck/issues/5295))
- **File paths in replies:** inside a Command Deck tab, a path the conversation changed opens its diff in the side panel and any other file opens beside the chat. Right-click adds **Open diff**, **Open beside** and **Reveal in files**. ([#5295](https://github.com/eltmon/overdeck/issues/5295))
- **Composer controls:** the delivery list is now a **Send** menu (normally, interrupt now, after this turn, when the limit resets), the effort button reads `Thinking: high` with its source in the tooltip, and the model button on a started conversation explains why the model cannot change. The controls follow one order: attach, model, Thinking, Send, then the context meter, mic and send. ([#5295](https://github.com/eltmon/overdeck/issues/5295))
- **Agents rail:** the subagents rail starts collapsed; ⋯ → **Subagents** or the **Agents** strip opens it. ([#5295](https://github.com/eltmon/overdeck/issues/5295))
- **Tab strip:** Stage tabs keep a fixed width range with the full name on hover, show no `⌘N` chips, and the **N tabs** button lists every tab. Untitled conversations read "New conversation". The **+** menu shows each item's shortcut. ([#5295](https://github.com/eltmon/overdeck/issues/5295))
