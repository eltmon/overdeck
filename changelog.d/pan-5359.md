#### Improved

- **Codex conversations get per-turn memory:** before each turn the Codex app-server host asks Overdeck for relevant memory and adds it to the prompt, the same way Claude Code conversations already get it. The chat shows only your own text. ([#5359](https://github.com/eltmon/overdeck/issues/5359))

#### Fixed

- **Project-root conversations in older projects get memory:** projects registered before workspaces existed had no main workspace, so their project-root conversations received no memory. The dashboard now creates the missing main workspace at startup. ([#5359](https://github.com/eltmon/overdeck/issues/5359))
