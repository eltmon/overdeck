#### New

- **Semgrep sast verification gate:** with `security.semgrep.enabled: true`, every verification run ends with a `sast` check that scans the lines a branch added. It is advisory by default: findings go into the verification artifact and the security review lane, and the run still passes. Set `security.semgrep.gate: blocking` (or `verification.sast: blocking` for one project in `projects.yaml`) to fail verification on a finding. A missing Semgrep binary, a scanner error, or a timeout marks the check skipped with the reason and never blocks a merge. New `nosemgrep` comments, `.semgrepignore` edits and rule-file changes are listed for the security reviewer. ([#4590](https://github.com/eltmon/overdeck/issues/4590))
