#### New

- **Cancel a message while it is still sending:** a message that shows "Sending…" now has a Cancel link. A message still waiting its turn is never sent, and its text comes back to the composer (or to the failed-message list if you have already typed something new). A message already on its way is stopped if the agent has not received it; otherwise it says "Already delivered, can't cancel". ([#5237](https://github.com/eltmon/overdeck/issues/5237))
