#### New

- **Antigravity harness:** run Gemini models in Google's Antigravity CLI (`agy acp`) as the `antigravity` harness, with resume, the managed MCP server and estimated cost. It uses a Gemini API key or Agent Platform credentials only; Overdeck never uses Antigravity's Google sign-in, because Antigravity's terms forbid it for third-party software.
