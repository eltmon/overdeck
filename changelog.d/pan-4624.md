#### Fixed

- **Polyrepo CI test verdicts are read for the member repo's head:** in a polyrepo project with `verification.tests: ci`, the verification gate looked up the CI test result under the wrapper repo's HEAD, which no PR points at, so a red CI test job never failed the `test` gate and verification passed on typecheck and lint alone. It now reads the verdict for the primary member repo's head, both at the start of the run and after an agent commit moves it. Standalone projects are unchanged. ([#4624](https://github.com/eltmon/overdeck/issues/4624))
