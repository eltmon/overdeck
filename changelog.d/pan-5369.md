#### Fixed

- **Dashboard no longer pins the main thread scanning for `/clear` orphans:** the conversation-lifecycle poll looked up every unowned transcript one at a time against SQLite without an index, costing over 11 seconds of synchronous work per tick on busy project directories; it now resolves ownership from one indexed locator set per tick and re-reads short transcripts only when they change. ([#5369](https://github.com/eltmon/overdeck/issues/5369))
