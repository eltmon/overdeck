#### Improved

- **Skills at project and issue level:** each skill now has one switch that shows whether it launches, with the level the value comes from beside it. A pin button keeps the current value when the level above changes, and a reset button returns the skill to what it inherits. Skills you changed are listed first with **Reset all**, and the issue view opens on every skill instead of a filtered list. ([#5245](https://github.com/eltmon/overdeck/issues/5245))
