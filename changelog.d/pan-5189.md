#### New

- **Office, notebook and Mermaid previews in the file explorer:** Word, Excel and PowerPoint files, OpenDocument text, spreadsheets and presentations, Jupyter notebooks and Mermaid diagrams now open as read-only previews in a file tab. Notebooks show their saved outputs and never run code. A file that cannot be previewed shows its size and a Download button. ([#5189](https://github.com/eltmon/overdeck/issues/5189))
