#### Improved

- **A starved gate queue frees memory on its own:** while the quality-gate admission queue is stalled on memory (PAN-5621), Overdeck stops the `api`, `fe`, `frontend` and `server` containers of one parked issue's workspace stack per 30 s, largest first, and records it in the issue's pipeline journal. Databases and the `dev` container are never stopped. The containers start again when the issue's agent starts a turn, an agent is spawned for it, or its verification starts. ([#5623](https://github.com/eltmon/overdeck/issues/5623))
