#### New

- **Open in Overdeck from your file manager:** `pan integrate file-manager` adds a right-click **Open in Overdeck** entry to GNOME Files, KDE Dolphin and other Linux file managers, a Finder Quick Action on macOS, and a context-menu entry on Windows. `pan install` offers it (default No), `--remove` takes it out again, and `pan doctor` warns when it goes stale. ([#5349](https://github.com/eltmon/overdeck/issues/5349))
- **An `/open?path=` link:** opening `<dashboard>/open?path=<absolute path>` shows that folder in the Files dock or that file in a code tab, in the right project's deck. A path outside every project offers to add its folder as a project. ([#5349](https://github.com/eltmon/overdeck/issues/5349))

#### Improved

- **`pan open` opens in Overdeck:** `pan open <path>`, `pan open <file>:<line>[:<column>]` and `pan open <issue>` now open the target in the dashboard tab you used last, or in a new browser tab when none is open. To open an external editor as before, add `--editor` (optionally with a name such as `zed` or `file-manager`). ([#5349](https://github.com/eltmon/overdeck/issues/5349))
