#### Fixed

- **Starting an order book reaches a running Flywheel:** `pan orders start` and the order book's Start button used to report success while dropping the book when a Flywheel conversation was already running. The book is now sent to that conversation as `/pan-flywheel <book-id> --project <key>`, the CLI prints `Flywheel already running; sent order book <id> to conversation <name>`, and a failed delivery exits non-zero or returns an error instead of claiming success. ([#5601](https://github.com/eltmon/overdeck/issues/5601))
