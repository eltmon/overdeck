#### Fixed

- **Review verdicts reach GitLab polyrepo merge requests:** `pan admin specialists done` now takes the forge from the project configuration instead of the workspace root's git remote. A polyrepo workspace root has no remote, so the command used to look for a GitHub pull request and lose the verdict. A review verdict now goes on the open merge request in every member repo the issue changed, and the merge gate finds the merge request in whichever member repo holds it. A project with no configured forge and no readable remote now reports an error instead of assuming GitHub. ([#5614](https://github.com/eltmon/overdeck/issues/5614))
