#### Fixed

- **A check that fails later on the same commit now reaches the agent:** when `lint` failed first and a test shard failed a minute later on the same pull request head, the agent heard only about `lint`. The CI failure relay now sends a new feedback file that names each check that failed after the earlier feedback. Repeated reports for a check already delivered still send nothing.
