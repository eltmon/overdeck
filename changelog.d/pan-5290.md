#### Improved

- **Edit and PR flow in the editor:** a bar at the top of every code tab on a project says the main checkout is never changed and offers **Start editing**; on an edit workspace it shows the files and lines you changed with **Discard…** and **Create PR**, then follows the PR through checks to **Merge** and a note after it merges. ([#5290](https://github.com/eltmon/overdeck/issues/5290))
- **Create PR shows what will land:** the dialog lists every file with its added and removed lines and asks "How should it land?" with two described choices. ([#5290](https://github.com/eltmon/overdeck/issues/5290))
- **Code beside the chat:** the code tab shows the project name and path as a breadcrumb, a **File / Changes** switch and **Reveal in files**, and a blue bar marks the lines the conversation beside it changed. Your cursor stays where it was when an edit workspace starts. ([#5290](https://github.com/eltmon/overdeck/issues/5290))

#### Fixed

- **Tabs of a merged or discarded edit workspace:** the tab says the edit workspace was merged or discarded and offers **Open on main** and **Close tab**, instead of "Couldn't open file". ([#5290](https://github.com/eltmon/overdeck/issues/5290))
