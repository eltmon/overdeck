#### Fixed

- **The Flywheel restarts itself when its tick timer dies:** the loop schedules each tick with a background timer, and Claude Code can stop that timer under memory pressure. The loop then sat idle until someone typed into it. The Deacon now sends `/pan-flywheel` to an idle Flywheel whose last tick is more than 20 minutes old, and it resumes a Flywheel that was running when the host rebooted. A paused Flywheel or one in the middle of a turn is left alone. ([#5667](https://github.com/eltmon/overdeck/issues/5667))
