#### Fixed

- **Bot connections that cannot use WebRTC say so:** when a bot's computer cannot reach the TURN relay or send UDP, `pan mcp connector connect` now stops with the code `no-webrtc-egress` and points to Public MCP, instead of asking the bot to retry a "direct connection failed". Connector errors name the route that failed, and `pan doctor` shows whether this machine can reach the TURN relay. ([#5242](https://github.com/eltmon/overdeck/issues/5242))
