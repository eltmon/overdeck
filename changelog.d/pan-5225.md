#### Fixed

- **`pan` follows `pan reload`:** after a reload, the shell `pan` command now runs the newly activated build instead of the previous one until the next agent launch. ([#5225](https://github.com/eltmon/overdeck/issues/5225))
- **Close-out for MYN-style polyrepo issues:** the merged check uses the last-fetched `origin/main` when a fetch fails, a branch identical to main no longer blocks the review and tests rows, and the post-merge row accepts merged GitLab MRs for issues not tracked on GitHub. ([#5225](https://github.com/eltmon/overdeck/issues/5225))
