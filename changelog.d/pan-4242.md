#### Fixed

- **Agents no longer stall at Claude Code's folder-trust dialog (PAN-4242):** every Claude Code launch now trusts the real path of its folder and its git repository root, so a trailing slash, a symlink or a project whose main checkout was never trusted no longer leaves an agent waiting at "Is this a project you trust?". Workspace settings no longer copy your user-level `permissions`, which made Claude Code ask again. An agent still stuck at a startup menu three minutes after launch now shows in Needs you, `pan answer` lists and answers such menus on Herdr hosts, and a handoff whose kickoff was refused keeps the kickoff, so Start or Resume sends it.
