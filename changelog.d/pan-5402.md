#### New

- **Publish a public knowledge site with `/okf publish`:** the bundled OKF skill is now eltmon/okf v0.1.1. Its new `/okf publish --out <dir>` command builds a static site from the knowledge concepts you mark public and applies redaction rules to them first. Run it with `--check` to see which rule matches before you publish. ([#5402](https://github.com/eltmon/overdeck/issues/5402))
