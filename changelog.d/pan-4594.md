#### New

- **Semgrep controls in the dashboard:** Settings → Security turns Semgrep on, sets the gate mode, severity, rule configs, scan timeout, MCP server and edit hook, and installs the pinned Semgrep CLI with one button. Each control writes only its own `security.semgrep` key in `~/.overdeck/config.yaml`. Project settings gains a Semgrep gate control that sets `verification.sast` for one project. ([#4594](https://github.com/eltmon/overdeck/issues/4594))
