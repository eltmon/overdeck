#### Fixed

- **Merge train batches always get CI:** a one-member batch whose feature already contained `main` used to fast-forward onto the feature's own commit, so GitHub ran no CI for the batch branch. The batch then dissolved and switched batching off for the whole project for a day, with a wrong notice telling you to add `uat/**` to the CI triggers. Batches now always get a new merge commit, and a fast-forwarded batch head no longer pauses batching. ([#5269](https://github.com/eltmon/overdeck/issues/5269))
