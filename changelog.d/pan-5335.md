#### Improved

- **New conversation shows what it will spawn with:** a second line under the button now names the default model, the harness when it is not Claude Code, and the effort. These are the same inputs quick create sends. ([#5335](https://github.com/eltmon/overdeck/issues/5335))
- **Projects get a colored mark:** the project switcher's button and every project row now show a colored initials mark, so projects are easier to tell apart at a glance. ([#5335](https://github.com/eltmon/overdeck/issues/5335))

#### Fixed

- **Conversation groups collapse by default:** a group of successors or lanes now starts collapsed unless one of them needs you, and a collapsed group still shows the conversation you have selected inside it. ([#5335](https://github.com/eltmon/overdeck/issues/5335))
- **Row cost no longer clips:** a conversation row's cost now always renders in full instead of being cut off mid-number. ([#5335](https://github.com/eltmon/overdeck/issues/5335))
- **Footer Machines button no longer wraps:** it is icon-only now, so it never truncates to a partial word in a narrow left column. ([#5335](https://github.com/eltmon/overdeck/issues/5335))
- **Only one nav item is current at a time:** Project home is no longer highlighted while another pane is active, and More is never current while you are on Settings; More also no longer lists Command Deck, since Project home already opens it. ([#5335](https://github.com/eltmon/overdeck/issues/5335))
- **The last project you picked is remembered:** a fresh load of a page that is not already project-scoped, such as Activity, restores it instead of opening with no project. ([#5335](https://github.com/eltmon/overdeck/issues/5335))
- **The Feed tab no longer repeats its title, and hides Project scope with no project:** its own header already names the view, and the Project chip only appears once a project is selected. ([#5335](https://github.com/eltmon/overdeck/issues/5335))
