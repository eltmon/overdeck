#### New

- **A work dock beside the chat:** the file explorer moved out of its own tab into a panel on the right of the Command Deck, with Files, Changes, Search and Live tabs, so the conversation stays on screen. It follows the tab you are on, shows what a conversation changed (with a diff view), and replaces the floating conversation dock. Open it from the Stage + menu, the Files buttons, or `Ctrl+Shift+E` and `Ctrl+Shift+G`. ([#5289](https://github.com/eltmon/overdeck/issues/5289))

#### Improved

- **Go to file finds the file you meant:** an exact file name now ranks first, then names that start with or contain what you typed, then paths, then fuzzy matches; files changed here rank first and carry a tag. `Ctrl+P` works anywhere in the Command Deck, and the `Ctrl+K` palette lists files too. ([#5289](https://github.com/eltmon/overdeck/issues/5289))
