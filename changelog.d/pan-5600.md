#### Fixed

- **Dashboard start works for projects with their own compose prefix:** the dashboard Start button, the post-planning hand-off and `POST /api/agents` no longer reject a workspace whose dev script names its Docker Compose project something other than `overdeck-feature-<id>`, such as MYN's `myn-feature-<id>`. A declared name that does not end in the feature folder is still refused. ([#5600](https://github.com/eltmon/overdeck/issues/5600))
