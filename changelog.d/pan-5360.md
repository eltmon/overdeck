#### New

- **Memory facts record who made a rule and what it replaces:** `pan memory add` and `edit` take
  `--source` for attribution, `add` records the `created` date, and `--supersedes <ids>` marks old facts
  superseded. The old file stays on disk but leaves every agent's memory index. `pan memory show` prints
  the attribution and links, `pan memory list --all` shows superseded facts, and `edit` now keeps
  frontmatter keys it does not know. ([#5360](https://github.com/eltmon/overdeck/issues/5360))
- **`pan memory lint`:** an advisory report of badly linked, duplicate and contradicting memory facts
  in one store. It uses embedding similarity when available, falls back to local word overlap, asks the
  memory provider about at most 20 likely conflicts (`--no-llm` skips that), and never edits a fact.
  ([#5360](https://github.com/eltmon/overdeck/issues/5360))
