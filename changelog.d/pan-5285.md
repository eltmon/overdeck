#### Fixed

- **Quality gates no longer deadlock behind one gate that cannot fit in memory:** a gate that waits on memory no longer holds every gate behind it. A later gate that fits now starts, and a head that has waited 5 minutes runs alone once the other gates finish, as long as it leaves the governor's hard reserve free. A full `npm test` run no longer sets the memory estimate for single-file `vitest run` calls. Queued gates pick up a corrected estimate or a lowered `governor_soft_reserve_gb` without a restart, and every waiting gate prints why it waits and which gate is ahead of it. ([#5285](https://github.com/eltmon/overdeck/issues/5285))
