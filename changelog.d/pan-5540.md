#### New

- **Add known skill packs from the dashboard:** the Skills page lists known packs and pack groups you have not added, such as the `video` group, and **Add…** previews each pinned commit and adds it once you trust it. The new-conversation skills list offers the same for groups. `pan skills pack list` now prints the packs you have not added and the command that adds each, and a new `pan-skills` skill tells agents how to add a missing pack. ([#5540](https://github.com/eltmon/overdeck/issues/5540))
