#### Improved

- **Idle workspace frontends stop on their own:** a workspace's `frontend`, `fe` and `dev` containers stop after 20 minutes with no browser connection, no attached session, no test or UAT agent, no running verification and no pin, even while its work agent runs. Each stop appears in the activity feed with the memory it freed. They start again when a test or UAT agent is spawned, verification starts, or you run `pan workspace up <issue>`. Keep a workspace running with `pan workspace pin <issue>`; change the timeout or services with `workspace.docker.idle_stop` in `projects.yaml`. ([#5250](https://github.com/eltmon/overdeck/issues/5250))
