#### Fixed

- **Merge train keeps its batch through bookkeeping commits:** a batch is no longer rebuilt when main moves only by commits to `.pan/**` or `.overdeck/memory/**`, the paths CI already skips. Before, frequent backlog-sequence commits rebuilt the batch every few minutes, so its combined CI never finished and the batch never merged. A main commit that touches any other file, or a file the batch changes, still rebuilds the batch. ([#5356](https://github.com/eltmon/overdeck/issues/5356))
