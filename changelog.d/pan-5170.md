#### Fixed

- **macOS no longer runs Linux-only checks:** the dashboard no longer calls `systemctl` to check the supervisor or `journalctl` to look for kernel OOM kills on macOS. Each failed call there left about ten dead processes. On macOS the dashboard now checks the supervisor over HTTP and reports it in the activity feed when it stops answering for a minute. ([#5170](https://github.com/eltmon/overdeck/issues/5170))
