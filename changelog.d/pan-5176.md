#### Improved

- **macOS and bare-host release checks:** every release now installs the exact package it publishes on a macOS host with no tmux, Docker or Homebrew, and stops if `pan up` fails or the idle dashboard spawns too many processes. ([#5176](https://github.com/eltmon/overdeck/issues/5176))

#### Fixed

- **No systemctl calls on Linux hosts without systemd:** the idle dashboard no longer starts a shell for `systemctl` every few seconds when `systemctl` is not installed, for example in a container. ([#5181](https://github.com/eltmon/overdeck/issues/5181))
