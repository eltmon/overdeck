#### Fixed

- **Search shortcut in a conversation:** `Ctrl+Shift+F` now puts the cursor in the work dock's Search box instead of the conversation's find bar. `Ctrl+F` still opens the find bar. ([#5329](https://github.com/eltmon/overdeck/issues/5329))
- **Go to file highlight:** matched characters use a soft amber background and keep the row's text color, so they are readable in the dark theme. ([#5329](https://github.com/eltmon/overdeck/issues/5329))
- **Agents rail in a split pane:** when a file opens beside a conversation, the Agents rail collapses to its strip so the messages keep a readable width. Your saved rail choice comes back when the pane is wide again. ([#5329](https://github.com/eltmon/overdeck/issues/5329))
- **No `.git` in Files:** the Files tree, the changed-files filter and Expand all folders no longer show or open the `.git` folder. ([#5329](https://github.com/eltmon/overdeck/issues/5329))
- **Long tags in Changes:** a long attribution tag on a commit row is cut short with an ellipsis and shows the full text on hover, so the commit subject stays visible. ([#5329](https://github.com/eltmon/overdeck/issues/5329))
