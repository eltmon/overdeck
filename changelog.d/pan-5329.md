#### Fixed

- **`Ctrl+Shift+F` reaches the dock Search box:** in a conversation tab, `Ctrl+Shift+F` no longer gets captured by the conversation's own find bar; plain `Ctrl/Cmd+F` still opens it. ([#5329](https://github.com/eltmon/overdeck/issues/5329))
- **Go to file highlights are legible:** the matched text in **Go to file** now uses a themed highlight instead of the browser-default yellow `<mark>`, which rendered near-white text in dark theme. ([#5329](https://github.com/eltmon/overdeck/issues/5329))
- **The Agents rail auto-collapses in a narrow pane:** opening a file beside a conversation no longer leaves the messages column squeezed to about 90px; the rail now collapses to its 30px strip below 760px of host-pane width and restores on its own once the pane widens. ([#5329](https://github.com/eltmon/overdeck/issues/5329))
- **The `.git` folder never shows in Files:** it stayed hidden before even with **Show dotfiles** on and **Expand all folders**. ([#5329](https://github.com/eltmon/overdeck/issues/5329))
- **Long attribution tags no longer crowd out the commit subject:** a project Changes commit row now caps its tag at 25% of the row's width, with the full text as a tooltip. ([#5329](https://github.com/eltmon/overdeck/issues/5329))
