#### Fixed

- **`pan conversations resume` works from the command line:** the resume route no longer refuses the CLI with `Missing origin`. It now accepts the internal token the CLI sends, the same rule the linked-conversation proxy uses. The route also finds the conversation by its numeric id or its `conv-` session name, as well as its stored name. ([#5516](https://github.com/eltmon/overdeck/issues/5516))
