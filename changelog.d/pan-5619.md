#### Fixed

- **Review starts for handoff PRs:** a PR opened from a `pan handoff` worktree (no xBRIEF) could pass verification and then never get a reviewer. If the branch conflicted with main, the review tried to start a conflict-resolver work agent, which needs an xBRIEF, and failed again on every retry. Now the review stays deferred and the reason tells you to merge main into the PR branch and request review again. Verification also moves a stale workspace to the PR head before it reuses an earlier pass, so it no longer "passes" an old head that cannot be pushed. A background review-pipeline failure is now recorded in the pipeline journal, so `pan show` reports it, and it is retried once instead of every hour. ([#5619](https://github.com/eltmon/overdeck/issues/5619))
