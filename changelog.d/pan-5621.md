#### Improved

- **A stalled gate queue is reported:** when the quality-gate admission queue cannot start any gate because available memory stays below the hard reserve plus the next gate's footprint for 15 minutes (`resources.quality_gate_starvation_minutes`), Overdeck reports it once: a line in `pan status`, an activity entry and a phone push, naming the waiting gate, how long it has waited and the top memory holders. ([#5621](https://github.com/eltmon/overdeck/issues/5621))
