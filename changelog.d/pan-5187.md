#### New

- **Edit files from the explorer:** clicking a file in the Files tree now opens it in a Monaco code tab with syntax highlighting. A single click reuses one preview tab; editing it or double-clicking keeps it open. Edits save automatically a second after you stop typing, when you leave the editor, or at once with Ctrl/Cmd+S. If another program changes the file while you have unsaved edits, a banner lets you compare, reload, keep your edits or overwrite, and a Changes toggle shows your edits against the last commit. ([#5187](https://github.com/eltmon/overdeck/issues/5187))
