#### Fixed

- **Herdr pane reads return the screen again:** on the Herdr terminal backend every pane read came back empty, so readiness waits ran to their timeouts, crash and stall checks could not see the screen, and message submit verification could not confirm delivery. Reads now return the pane's text, and a message is no longer submitted with Enter while the agent sits at a permission prompt or choice menu. ([#5232](https://github.com/eltmon/overdeck/issues/5232))
