#### Fixed

- **Review recovery no longer reviews an old commit:** when a stalled review is recovered, Overdeck now relaunches reviewers only into a review run for the current workspace head that has no verdict yet. A run for an earlier head, or one whose verdict is already recorded, gets no reviewers, and the next review request opens a run for the new head. ([#5519](https://github.com/eltmon/overdeck/issues/5519))
