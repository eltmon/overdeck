#### New

- **Video production skill packs:** `remotion`, `hyperframes`, `openmontage` and `video-use` are known packs, each pinned to an `eltmon/` fork, so `pan skills pack add <id>` needs no url or ref. `openmontage` mounts the 38 skills that work outside an OpenMontage checkout, and `video-use` mounts its root skill with a host notice and a generated `requirements.txt`. ([#5464](https://github.com/eltmon/overdeck/issues/5464))
- **Pack groups:** one name turns several packs on. The built-in `video` group holds the four video packs; `pan skills pack add --group video`, `pan skills set --group video on` and `pan handoff --group video` act on every member, and `skills.pack_groups` in `config.yaml` adds or replaces groups. ([#5464](https://github.com/eltmon/overdeck/issues/5464))

#### Fixed

- **HyperFrames pack extraction:** adding a pack no longer downloads Git LFS objects, so `hyperframes` no longer fails on the LFS rate limit. LFS pointer files in a pack now show under Not applied as `LFS objects (<n>)`. ([#5464](https://github.com/eltmon/overdeck/issues/5464))
- **AGPL license shown as unknown:** pack previews now recognize AGPL, LGPL and GPL license files by their full GNU titles. ([#5464](https://github.com/eltmon/overdeck/issues/5464))
