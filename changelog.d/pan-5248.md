#### Improved

- **Typechecks wait for memory:** every `tsc` lane of `npm run typecheck` and the lint type guards now joins the machine-wide admission queue through `scripts/tsc-admitted.mjs`, and the queue checks memory as well as CPU. A typecheck, local Vitest run or verification gate waits while starting it would push available memory below `resources.governor_soft_reserve_gb`, using the peak memory measured on its earlier runs, so overlapping typechecks no longer exhaust the host. ([#5248](https://github.com/eltmon/overdeck/issues/5248))
