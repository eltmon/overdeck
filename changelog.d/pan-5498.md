#### Fixed

- **Auto-start after planning honors `--host`:** `pan start <id> --plan auto --host` now starts the work agent on the host once planning finalizes. Before, the post-planning start dropped the host override, so the workspace Docker stack check refused it or ran a slow rebuild first. If the dashboard restarts while that start request is still running, Overdeck now retries the start after 10 minutes instead of leaving the issue planned with no work agent. ([#5498](https://github.com/eltmon/overdeck/issues/5498))
