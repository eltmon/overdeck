✗ What we do today

Render every registry action in one flat list regardless of state. The operator hunts through 37 verbs — Start next to Stop, Pause next to Unpause — and different surfaces disagree about which danger actions even exist for the same issue. Two actions point at dead endpoints; two more open stub dialogs.

✓ The contract

Enabled-filtered: inapplicable actions show greyed with the reason, never as live buttons. Grouped: six fixed groups, fixed order, learned once. One skin: one component, three presentations, parity-tested. Phased primary: the strip mirrors the phase table — Queued→Plan, Work→Tell+Done, Review→Watch+Recover, Ready→Merge.
