PAN-2377 mockup v1. One order book = one flywheel run. The operator assembles the book (search, backlog top-10, cross-surface adds), arranges lanes, fixes validation findings, and presses Start run. Draining the book ends the run → retrospective → next queued book, else backlog mode (if auto-pull is on).
