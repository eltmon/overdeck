Mockup uses the production token set from src/dashboard/frontend/src/index.css (light block), DM Sans at weight ≤500, SF Mono only for identifiers, and the badge tint formula (8% bg / 32% border). Signal semantics per the style guide: blue = machine working (Work badge, live dots), amber = a human must act (Needs-you slot, question card), emerald = outcomes (done steps, Done badge), cyan = money, purple reserved for live specialist activity (review convoy rows would turn purple while running), red only for broken.
