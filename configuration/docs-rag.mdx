Docs RAG is retrieval over Overdeck's own developer documentation, skills and rules, injected into an agent's prompt when the prompt looks like it is asking about Overdeck itself. It never indexes your project's own code or docs, and it never touches the published documentation site.

## What it indexes

Docs RAG indexes Overdeck's own package: the Markdown files under `docs/` (not `docs/prds/`), every `SKILL.md` under `sync-sources/skills/`, every rule under `sync-sources/rules/` and `.claude/rules/`, and the root `CLAUDE.md`. PRDs are indexed only when `docs.corpus.prds` is turned on; it is off by default. Search runs as SQLite full-text search plus local embeddings.

The index lives at `~/.overdeck/docs/index.sqlite`, and a prebuilt copy ships as `dist/docs-index.sqlite`.

## When snippets are added to a prompt

Injection is on by default. The trigger is nine case-insensitive patterns, matched as a substring anywhere in the prompt rather than as a whole word: a prompt containing "Japan" matches the `pan` pattern even though it does not contain the word `pan`. When one matches, Docs RAG adds a block of at most 5 snippets and 3000 tokens to the prompt, at most once every 10 turns:

```text
pan, overdeck, cloister, deacon, workspace, specialist, harness, vbrief, workhorse
```

The callers that inject this way are the Claude Code `UserPromptSubmit` hook and Codex app-server turns.

## Query the index

```bash
pan docs query "how does the merge train work"
pan docs reindex
```

`pan docs reindex` rebuilds the index from this package's own `docs/` folder, using the default corpus and embedding settings rather than your `docs.*` configuration: it does not read `docs.corpus.prds` or any other `docs.corpus.*` key, so turning PRDs on in `config.yaml` does not bring them into a reindex.

That `docs/` folder, `CLAUDE.md` and `.claude/rules/` do not ship in the published npm package. Running `pan docs reindex` from an installed copy does not fail or warn: it silently rebuilds from whatever sources are still present (Overdeck's bundled skills and rules) and replaces your existing index with that smaller one. Only run `pan docs reindex` from a source checkout of Overdeck.

## Turn it off

```bash
pan docs disable --scope global
pan docs enable --scope global
```

`pan docs disable --scope global` turns injection off everywhere; `pan docs enable --scope global` turns it back on. You can also set `docs.enabled: false` to turn off the whole feature, or `docs.prompt_injection: false` to keep the index but stop automatic injection into prompts, in `~/.overdeck/config.yaml`.

## Configuration keys

All Docs RAG keys in `config.yaml` are snake_case, under the top-level `docs` key:

| Key | Controls |
| --- | --- |
| `docs.enabled` | Turns the whole feature on or off |
| `docs.prompt_injection` | Turns automatic prompt injection on or off, independent of the index |
| `docs.trigger.regexes` | The list of trigger words or patterns above |
| `docs.trigger.case_sensitive` | Whether trigger matching cares about case |
| `docs.corpus.*` | Which sources are indexed, including `docs.corpus.prds` |
| `docs.budget.injection_rate` | How often a prompt is allowed to receive an injection |
| `docs.budget.turn_window` | The turn window the injection rate is measured over |
| `docs.budget.max_tokens_per_injection` | The token cap on one injected block |
| `docs.budget.max_chunks_per_injection` | The snippet-count cap on one injected block |
