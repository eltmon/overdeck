# PAN-4501 — Diff panel "vs main" uses the configured default branch, and whole-conversation views list their files

**Issue:** [PAN-4501](https://github.com/eltmon/overdeck/issues/4501)
**Verified against:** `main` at `473935d63fe` (2026-10-03). Line numbers below are from that commit; each also carries a quote to grep for.

## Glossary

- **Diff panel** — the React component `DiffPanel` (`src/dashboard/frontend/src/components/DiffPanel.tsx`). It shows a strip of chips ("All turns", "vs main", "Turn N") and, below it, either a file picker or the patch for one file.
- **Chip** — one button in the diff panel's strip. "All turns" = `selectedTurnId === null`; "vs main" = `selectedTurnId === 'vs-main'`; a turn chip = a turn id.
- **File picker** — `DiffFilePickerList` in `DiffPanel.tsx`. It renders the `files` array of a response; with `[]` it prints "No changed files in this selection."
- **Diff URL prefix** — the base URL the panel fetches from. Agents: `/api/agents/:agentId/diffs`. Conversations: `/api/conversations/:name/diffs` (passed as `diffUrlPrefix` by `ConversationPanel.tsx` line 1094 and by the popout route `StandaloneRoutes.tsx`).
- **Turn route** — `GET /api/conversations/:name/diffs/:turnId`, served by `getConversationDiffTurn` in `src/lib/overdeck/conversation-diffs.ts`.
- **Default branch** — the branch named by project config: the matching `workspace.repos[].default_branch`, else `workspace.default_branch`, else the literal `main`. `pr_target` does **not** participate (see Decision D2).
- **Base ref** — the git ref that names the default branch inside one repository: `refs/heads/<branch>` when that local branch exists, else `refs/remotes/origin/<branch>`, else none.
- **Three-dot diff** — `git diff <baseRef>...HEAD`: the changes committed on HEAD since its merge base with `<baseRef>`. It excludes uncommitted working-tree changes and is empty when HEAD is an ancestor of `<baseRef>`.
- **Conversation repository** — the git top-level directory of the conversation's `cwd`, from `git rev-parse --show-toplevel`.
- **Fixture repository** — a git repository a test creates in a temp dir with `git init`, no remote, and a default branch that is not `main` (`trunk`).
- **No-loss matrix** — `tests/unit/lib/overdeck/no-loss-matrix.ts` (`NO_LOSS_MATRIX`). `tests/unit/lib/overdeck/no-loss-matrix.test.ts` fails when an HTTP route exists without a row. `tests/unit/dashboard/server/routes/conversations-no-loss.test.ts` additionally locks the exact conversations route list and count.

## Problem

Four gaps, all verified:

1. **Conversation "vs main" falls through to the turn route.** `DiffPanel.tsx` line 444 requests `` `${baseUrl}/vs-main` ``. `src/dashboard/server/routes/conversations.ts` registers only `/api/conversations/:name/diffs` (line 935), `/diffs/full` (line 952) and `/diffs/:turnId` (line 969). So `/diffs/vs-main` matches `:turnId = "vs-main"`, and `getConversationDiffTurn` returns "commit at conversation start vs working tree" (grep `const patch = await diffPatchSinceCommit(cwdRepoRoot, baseCommit, fileFilter);`). It is not a comparison with any branch.
2. **No file list for whole-conversation views.** `getConversationDiffFull` returns `result({ diff: patches.join('\n') })` with no `files`, and the turn-route fallthrough returns `{ turnId, diff }`. `DiffPanel.tsx` computes `filePickerFiles = selectedTurn?.files ?? diffResponse?.files` (grep `const filePickerFiles`), so the picker gets `undefined` → `[]`. `getConversationDiffFull` also ignores `?file=`.
3. **"No completed turns yet" hides real changes.** `DiffPanel.tsx` line 730: `{orderedTurnDiffSummaries.length === 0 && !isVsMain ? (` renders "No completed turns yet." for "All turns" whenever there are no summaries. `getConversationDiffs` returns `{ summaries: [] }` whenever the transcript has no file edits (grep `if (!fileEditsByAssistantId || fileEditsByAssistantId.size === 0) {`), even when the repository changed since the conversation started.
4. **Agent "vs main" hardcodes `main`.** `src/lib/checkpoint/checkpoint-manager.ts` lines 349-392: `diffAgainstMain` and `diffAgainstMainFiles` both pass the literal `'main...HEAD'`. Their only caller is `src/dashboard/server/routes/diffs.ts` line 229-230 (grep `const files = await diffAgainstMainFiles(workspace)`). A project whose default branch is `master` or `trunk` gets a git error (500) or a diff against the wrong branch.

## Decisions

- **D1 — "vs main" keeps three-dot semantics, for agents and conversations alike.** Both views run `git diff <baseRef>...HEAD`: committed changes only, empty when HEAD is an ancestor of the base. The issue's rollout note accepts the empty case, and the arbitrary two-ref compare is [PAN-3178](https://github.com/eltmon/overdeck/issues/3178). One shared helper, one meaning.
- **D2 — Default branch = config `default_branch`, never `pr_target`.** Order: the `workspace.repos[]` entry that matches the repository (rule in WI-1), then `workspace.default_branch`, then `'main'`. The `'main'` fallback matches every other caller (`pipeline-membership-gather.ts:374`, `project-ci-fill.ts:59`).
- **D3 — Local branch before remote-tracking branch.** The base ref is `refs/heads/<b>` if it exists, else `refs/remotes/origin/<b>`. A local-only repository has no `origin`, so local-first is required. This also preserves today's agent behavior (local `main`).
- **D4 — Missing base ref is not an error.** When neither ref exists, the response is HTTP 200 with `baseRef: null`, `files: []`, and `diff: ''` when a file was requested. The panel then shows "No changed files in this selection." instead of "Failed to fetch diff".
- **D5 — Conversation repository = `git rev-parse --show-toplevel` of `conv.cwd`.** Not the `existsSync(join(cwd, '.git'))` check that `/full` uses, which misses a cwd in a subdirectory. A cwd outside any repository returns 200 with `repoRoot: null, baseBranch: null, baseRef: null, files: []`.
- **D6 — The conversation's explicit `projectKey` wins over the cwd.** `resolveDefaultBranchForRepo(repoRoot, projectKey)` uses `getProjectSync(projectKey)` when a key is given and found, else `findProjectByPath(repoRoot)`.
- **D7 — The "No completed turns yet" guard is removed for every DiffPanel.** "All turns" always fetches `/full` and shows its file list. For an agent with fewer than two checkpoints, `/api/agents/:id/diffs/full` already returns `files: []`, so that view now says "No changed files in this selection." That is the only agent-visible change.
- **D8 — Response shapes carry the proof of which route served them.** vs-main responses include `baseBranch` and `baseRef`; the turn route returns `turnId`. Tests and UAT tell them apart by those keys.
- **D9 — Conversation diff routes move to their own route file.** `routes/conversations.ts` is 1072 lines and its cap in `scripts/file-size-allowlist.txt` is 1072 (last row wins; `CEILING=1000`). Adding a route there fails `scripts/lint-file-size.sh`. The four conversation diff routes live in `src/dashboard/server/routes/conversation-diffs.ts`, following the `conversation-subagent-input.ts` precedent.
- **D10 — The chip label stays "vs main".** The response says which branch was used (`baseBranch`); relabeling the chip is out of scope.

/**
 * The configured default branch for the repository at `repoRoot` (PAN-4501).
 * Matching `workspace.repos[]` entry first, then `workspace.default_branch`,
 * then 'main'. `pr_target` is deliberately ignored: this names the branch the
 * repository is compared with, not the branch PRs target.
 */
export function defaultBranchForRepo(project: ProjectConfig | null, repoRoot: string): string {
  const normalizedRoot = repoRoot.replace(/\/+$/, '');
  const repo = project?.workspace?.repos?.find((r) => {
    const rel = r.path?.replace(/^\.\/+/, '').replace(/\/+$/, '');
    return !!rel && rel !== '.' && (normalizedRoot === rel || normalizedRoot.endsWith(`/${rel}`));
  });
  return repo?.default_branch || project?.workspace?.default_branch || 'main';
}

/** Looks the project up (explicit key first, then by path) and applies {@link defaultBranchForRepo}. */
export function resolveDefaultBranchForRepo(repoRoot: string, projectKey?: string | null): string {
  const project = (projectKey ? getProjectSync(projectKey) : null) ?? findProjectByPath(repoRoot);
  return defaultBranchForRepo(project, repoRoot);
}
```

export async function resolveBaseRef(cwd: string, branch: string): Promise<string | null> {

/**
 * "vs main" for the diff panel (PAN-4501): the repository at `repoRoot` diffed
 * three-dot against its configured default branch. Shared by the agent and
 * conversation vs-main routes so both mean the same thing.
 */
import { resolveDefaultBranchForRepo } from '../project-repos.js'
import { diffAgainstBase, diffAgainstBaseFiles, resolveBaseRef, type TurnDiffFileChange } from './checkpoint-manager.js'

export interface VsDefaultBranchDiff {
  readonly baseBranch: string
  /** 'trunk' or 'origin/trunk'; null when the branch exists neither locally nor on origin. */
  readonly baseRef: string | null
  readonly files: TurnDiffFileChange[]
  /** Present only when `filePath` was given. */
  readonly diff?: string
}

export async function diffVsDefaultBranch(
  repoRoot: string,
  options: { projectKey?: string | null; filePath?: string } = {},
): Promise<VsDefaultBranchDiff> {
  const baseBranch = resolveDefaultBranchForRepo(repoRoot, options.projectKey)
  const baseRef = await resolveBaseRef(repoRoot, baseBranch)
  if (!baseRef) {
    return { baseBranch, baseRef: null, files: [], ...(options.filePath !== undefined && { diff: '' }) }
  }
  const files = await diffAgainstBaseFiles(repoRoot, baseRef)
  const diff = options.filePath !== undefined ? await diffAgainstBase(repoRoot, baseRef, options.filePath) : undefined
  return { baseBranch, baseRef, files, ...(diff !== undefined && { diff }) }
}
```

export async function getConversationDiffVsMain(
  name: string,
  fileFilter: string | undefined,

## Non-goals

- An arbitrary two-ref compare or a whitespace toggle (tracked on [PAN-3178](https://github.com/eltmon/overdeck/issues/3178)).
- Including uncommitted working-tree changes in "vs main" (D1). "All turns" already shows them for conversations.
- Relabeling the "vs main" chip with the real branch name (D10).
- Untracked (never-added) files in any diff view; `git diff` ignores them today and this issue does not change that.
- Multi-repository "vs main": the conversation vs-main view covers the conversation repository only.
- A button to open the diff panel for a conversation with no edit turns; the panel opens from a `?diff=1` URL or the popout as today.
- Changing `getRepoTargetBranch` or any PR-sync behavior.

## Rollout hazard (operator-facing)

A popout diff URL with `diffTurnId=vs-main` on a conversation relies today on the gap-1 fallthrough. After this ships it diffs against the default branch, and for a checkout whose HEAD is an ancestor of that branch it shows nothing. Whoever runs or approves the `pan reload` that ships this merge must tell the operator first so the replacement view is ready. The PR body must carry this note.

## Repo rules that intersect this work

- **No `execSync`** anywhere reachable from the dashboard server. Use the promisified `execFile`/`exec` already in these modules.
- **Quality gates before `pan done`:** `npm run typecheck`, `npm run lint`, and `npx vitest run <the test files you touched>`. Never run the full `npm test` on the host. `npm run typecheck` excludes `*.test.ts`, so run the touched tests to catch type errors in them.
- **File-size ratchet:** `scripts/lint-file-size.sh` compares against `origin/main`. Never raise an allowlist row; extract instead (WI-5 does this).
- **New HTTP route ⇒ no-loss matrix row**, or CI fails (WI-6).
- **No new `skipIf` / `.only`**, and no tests that read source files to assert on their text.
- **Fixture repos:** set `user.email`/`user.name` locally in the repo; set the default branch with `git symbolic-ref HEAD refs/heads/trunk` before the first commit. Commits that must count as "after the conversation started" need a committer date later than `conv.createdAt` (see WI-7).
- **Commits:** one commit per work item with an `Item: <item-id>` trailer; commitlint conventional format (`fix(dashboard): …`).
