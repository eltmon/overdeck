# PAN-5335 — F follow-up: handoff groups, cost clipping, footer label, nav current state, last project, Feed tab

**Parent PRD:** `.pan/drafts/pan-5284.md` §6.6 (child F, `.pan/drafts/pan-5293.md`). Found in the epic owner's D-15 live check on :3011 at buildCommit `062bf2882ea` (1920×1000, dark and light).

## 1. Glossary

- **Left column** — `FE/components/frame/LeftColumn.tsx`: project switcher, nav, New conversation, then the Conversations, Issues and Workspaces lists, then the footer. FE means `src/dashboard/frontend/src`.
- **Group** — a conversation row that has descendants in the conversation tree (`FE/components/CommandDeck/conversation-tree.ts`), shown with a toggle line like `▾ 20 successors · 3 working`.
- **Meta line** — the second line of a conversation row (`conversationMetaParts`, `FE/components/CommandDeck/conversationMeta.ts`; rendered in `ConversationRow.tsx` around line 618 inside `.conversationMetaLine`).

## 2. What is wrong (verified)

1. **Groups open by default.** `FE/components/CommandDeck/ConversationList.tsx` lines 536–540:
   ```ts
   const isGroupCollapsed = useCallback((node) => {
     if (collapsedGroups.has(node.conv.name)) return true;
     if (expandedGroups.has(node.conv.name)) return false;
     return !node.descendants.some((child) => isConversationActive(child.conv));
   }, ...);
   ```
   `isConversationActive` (`conversation-tree.ts` line 57) is true for any child with a live session, so the Flywheel group (20 handoff children, most of them alive and idle) opens. Its 20 two-line rows push the Issues section to y≈1830 on a 1000px screen. Parent §6.6 item 4 says successor chains collapse to one line.
2. **Cost clipped mid-number.** `.conversationMetaLine` (`FE/components/CommandDeck/styles/command-deck.module.css` line 2403) is `display:flex; white-space:nowrap; overflow:hidden`. The cost part is last and gets cut: `Working · no file changes · $2` for $26.73, and `Idle 2m ago · no file changes · $` for $617.54.
3. **Footer "Mac…".** `FE/components/sidebar/MachinesNavItem.tsx` (`variant === 'footer'`, lines 25–40) renders `<span className="truncate">Machines</span>` and shrinks first.
4. **Two current nav items.** `FE/components/frame/LeftNav.tsx`: Project home is `active={activeTab === 'command-deck'}` (line 86), and `moreActive` (line 77) is true when any More item's id equals `activeTab`. `FE/components/frame/navGroups.ts` line 30 lists `{ id: 'command-deck', label: 'Command Deck' }` under More, so on any deck tab both Project home and More are current.
5. **Project lost on a fresh load of a global page.** `FE/App.tsx` line 180 initializes `selectedProjectKey` from the route only (`initialCockpitRoute?.project ?? initialProjectRoute`). Loading `/activity` directly gives `null`, and `LeftColumn.tsx` line 177 shows "Pick a project to see its conversations and issues".
6. **Feed tab repeats itself.** `FE/components/ActivityFeedTab.tsx` renders `SessionFeedSidebar` with `heading="Feed"` inside a `max-w-3xl` box, under a page tab that is already named Feed. With no project selected, the scope switcher still offers and defaults to Project (`overdeck.ui.awarenessScope`), which then shows unscoped items.

## 3. Decisions

- **D-1** A group is collapsed by default. It opens by default only when a descendant needs the operator (`(child.conv.pendingInputCount ?? 0) > 0`). The toggle line already shows `N working` / `N needs you`, so nothing is hidden silently. The persisted collapsed set and the session expanded set keep working as today.
- **D-2** In the meta line, the cost part never shrinks (`flex-shrink: 0`). Every other part may shrink and ends in an ellipsis. Wrap each part in a span with `min-width:0; overflow:hidden; text-overflow:ellipsis` except cost, which gets `flex-shrink:0`.
- **D-3** The footer Machines button becomes icon-only, the same as Settings. It keeps `aria-label="Machines"` and the title `Machines · N online` / `Machines`. The `nav` variant is unchanged.
- **D-4** Project home is current only when `activeTab === 'command-deck'` and the deck's active Stage pane is the Home pane: `usePanesStore` → `activePaneByWorkspace[<selected project key>]` names a pane whose `paneType === 'home'`. If no pane is recorded, treat Home as active. Remove `command-deck` from the More menu in `navGroups.ts`, because Project home is its door. More is current only when a remaining More item is the active tab.
- **D-5** Remember the last selected project. Whenever `selectedProjectKey` becomes a non-null project key, write it to `localStorage['overdeck.ui.lastProjectKey']` (try/catch). When the route names no project, initialize from that key. An explicit "No project" choice stays as today and is also stored. A stored key that is not a registered project is ignored. `/command-deck` with no project still clears the selection, as line 628 does today.
- **D-6** The Feed tab shows no inner heading row. Add `hideHeader?: boolean` to `SessionFeedSidebar` and pass it from `ActivityFeedTab`. Widen the box to `max-w-5xl`. When no project is selected, pass `projectScopeAvailable={false}`: the Project scope chip is hidden and a stored `project` scope reads as `global`.
- **D-7 (operator request, 2026-11-15)** The New conversation button shows the model it will use. The main part becomes two lines: line 1 is today's `+ New conversation` with the `N` keycap; line 2 (11px, `text-muted-foreground`, no extra height beyond one text line) shows the provider icon, the short model name and the effort word, joined by ` · `, for example `✳ Opus 5.5 · High`. The harness label sits between model and effort only when the harness is not `claude-code` (same rule as `conversationMeta.ts`), for example `GPT-5.5 · Codex · High`. Values come from `useNewConversationDefaults` (`model`, `harness`, `effort`), so a change in the caret menu updates the line at once. Provider and label come from `useAvailableModels()` groups via `getProviderForPickerModel(model, groups)` (`FE/components/shared/ModelPicker/ModelPicker.tsx` lines 36 and 219); the icon is `ProviderIcon` from `FE/components/shared/branding` at 12px, as the composer picker uses it (`FE/components/chat/ModelPicker.tsx` lines 466–471). Short name: the model's picker label with a leading `Claude ` and any trailing ` (…)` removed (`Claude Opus 5.5 (1M context)` → `Opus 5.5`); an unknown model id falls back to `compactModelName` (`FE/lib/model-names.ts`). Effort words are `EffortPicker.tsx`'s `SHORT_LABELS` (export it). The button title becomes `New conversation with <full label> · <harness label> · <effort> (N)`; its `aria-label` stays `New conversation`. The collapsed 48px column keeps the `+` icon only, with the same title.

- **D-8 (operator request, 2026-11-15)** Every project gets a colored mark, as in the multi-conversation mockup (`docs/design/multi-conversation-mockup.html`, the `.pmark` squares). The mark is a rounded square with the existing two-letter `projectInitials(name)` (`FE/components/frame/ProjectSwitcher.tsx` lines 38–43: `overdeck` → `OV`, `DFAI` → `DF`, `mind-your-now` → `MY`) in white, `font-mono` 600, on a color picked by a stable hash of the project key from an 8-color palette. The palette is a data constant in one module, a sanctioned exception to the no-hex rule. It avoids the signal hues and gives white text at least 4.5:1 contrast: `#4f46e5` indigo, `#0f766e` teal, `#7c3aed` violet, `#be185d` pink, `#92400e` brown, `#4d7c0f` olive, `#0369a1` sky, `#86198f` plum. Hash: sum of char codes times 31, modulo 8. The mark is computed from the key only, so it is the same everywhere and on every machine. It shows in:
  1. the closed switcher button, replacing today's `bg-foreground` square, at 28px (`h-7 w-7`);
  2. every project row in the switcher menu, at 18px before the name;
  3. the No project row, as today's muted `–` square at 18px.
  Child H (PAN-5343) reuses this component for its project groups, split headers and tabs.

## 4. Requirements

- **FR-1** Groups start collapsed except when a child needs you (D-1).
- **FR-2** The cost on a conversation row is never cut (D-2).
- **FR-3** The footer shows no truncated text (D-3).
- **FR-4** At most one nav item is current; on a conversation tab, none of Project home and More is current (D-4).
- **FR-5** A fresh load of a non-deck route shows the last project's lists (D-5).
- **FR-6** The Feed tab has no duplicate heading and no Project scope without a project (D-6).
- **FR-7** The New conversation button shows the default model's provider icon, short name and effort, and the harness when it is not Claude Code (D-7).
- **FR-8** The project switcher button and its menu rows show each project's colored mark (D-8).
- **NFR-1** No file grows past its `scripts/file-size-allowlist.txt` row. Extract a module if one would.
