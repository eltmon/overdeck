# PAN-5131: God View honesty pass

**Issue:** https://github.com/eltmon/overdeck/issues/5131
**Status:** planned 2026-11-11. Verified against the workspace at `6f15b351f4f` (the issue was written against `b19a4fdc282`, an ancestor; no God View file changed between them).

Remove simulated ages, rates and effects from the God View canvas, fix mislabeled orbs, and make the field guide and the docs match the code. This is a tidy-up: no new panel, no new layout, no legend redesign.

This document is the implementation brief. It restates the issue body, corrects the places where the issue's steps did not hold against the code, and makes every decision the issue left open. Where this document and the issue body disagree, this document wins; each difference is listed in "Decisions made during planning".

## Glossary

- **God View / Confluence:** the canvas at `/god-view`. All code is under `src/dashboard/frontend/src/components/GodView/`. In this document a path that starts with `confluence/` is under that directory.
- **Orb:** one issue drawn on the river canvas. Data shape `ConfluenceOrb` (`confluence/useConfluenceData.ts`, line 38). Render shape `RenderOrb` (`confluence/RiverCanvas.tsx`, line 55), which extends `ConfluenceOrb` with position and animation fields.
- **Cast:** the list of orbs `useConfluenceOrbs()` returns.
- **Cached orb:** `useConfluenceOrbs` reuses the previous `ConfluenceOrb` object when `orbSignature()` is unchanged (`confluence/useConfluenceData.ts`, line 346).
- **Reconcile:** `reconcile()` in `confluence/RiverCanvas.tsx` (line 379). It runs on every props change, which is at least every 1.6 s (the `RATE_DECAY_MS` timer in `useHookStream`), and does `Object.assign(current, source)`.
- **Advance:** `advance(dt)` in `confluence/RiverCanvas.tsx` (line 666). It runs once per animation frame.
- **Heat:** a 0 to 1 number on a render orb. It drives orb size, glow, orbit speed and the stage-header pulse.
- **Hook stream:** `ConfluenceHookStream` from `useHookStream()`. `entries` holds the hook events of the trailing 60 s (at most 500 entries, `HOOK_STREAM_LIMIT`). Each entry has `issueId` and `ts`.
- **Choreography:** `confluence/useConfluenceChoreography.ts`. It diffs the previous and current cast and plays effects through `RiverEffectsApi`.
- **Effect order:** React runs a child's effects before its parent's. `RiverCanvas` reconciles first; the choreography effect in `GodViewConfluence` runs after. So when an effect plays, the render orb already holds the new state.
- **Doldrums / shelf:** the two bands under the river for stale orbs and for paused or yielded orbs.
- **Lane:** the orbs drawn in one stage column of the river (states `active` and `failed`).
- **Parked row:** a row of `GET /api/parked` (`ParkedRowView`). It has `parkedAt`, an ISO timestamp.
- **Attention:** `IssueAttention` from `packages/contracts/src/derived-issue-state.ts` (line 34). `stuck` means idle with unpushed commits. `api-error` means 429 or provider-failure text in a pane.
- **CI frontend subset:** `scripts/frontend-test-subset.txt`. CI runs only the frontend test files listed there.

## Why

The operator could not work out what the God View was telling them and asked for every animation to have a purpose and to represent a real action. `docs/GOD-VIEW.md` promises "cast real, motion real". The audit found places where the canvas shows simulated, frozen, mislabeled or unattributable information.

## Requirements

Requirement ids are the issue's. Do not renumber them.

- **FR-1 (real rate):** the tag under an active orb shows that issue's real hook events in the last 60 s as `<role> · <n> ev/m`, or `<role> · quiet` when n is 0. No `~`.
- **FR-2 (real heat):** heat derives from the same real rate and survives reconcile.
- **FR-3 (real ages):** every idle or parked age shown anywhere (canvas labels, tooltip, rail, top-bar OLDEST and STALE, emissary sort) is computed from a timestamp at read time. No age is stored in a cached orb. No time-lapse.
- **FR-4 (frost from real time):** frost on an active orb is `frostFromIdleMinutes(real idle minutes)`. The canvas never changes an orb's `state` or `stage`; only data does.
- **FR-5 (honest effects):** thaw, tide and merge effects decorate a transition the data already made. They never mutate orb state, never guess a participant, and merge plays only for a merged issue.
- **FR-6 (honest cast):** orbs exist only for tracker issue ids. The sun and the sequencer animate only when their agent is live.
- **FR-7 (honest labels):** a `failed` orb says what its attention is. Project rings differ per project. Model glyphs cover every model family in the catalog.
- **FR-8 (readable lanes):** orbs in one stage column do not share a position.
- **FR-9 (no dead UI):** the footer matches `STAGES`; the beads stats are removed; one ticker per sampled event.
- **FR-10 (text matches behavior):** `ConfluenceHelp.tsx`, `docs/GOD-VIEW.md` and `reference/god-view.mdx` describe what the code does after this change.
- **NFR-1:** no new polling of the server. A local clock tick is allowed.
- **NFR-2:** `confluence/RiverCanvas.tsx` stays at or under 808 lines and `confluence/useConfluenceData.ts` at or under 902 lines (their counts on `origin/main`). `scripts/lint-file-size.sh` checks only files above 1000 lines, so the work items check these two with `wc -l`.
- **NFR-3:** no test reads source files as text, and no added `skipIf`, `.skip` or `.only`. Tests that involve time use `vi.useFakeTimers()`.

## Repo rules that apply (restated)

1. **Frontend typecheck does not cover tests.** `src/dashboard/frontend/tsconfig.json` excludes `src/**/*.test.*` and `src/**/__tests__/**`, and Vitest does not typecheck. A test fixture that still carries a removed field passes silently. Each work item that removes a field or an API member names the grep that proves the test files are clean.
2. **CI runs only listed frontend tests.** `scripts/frontend-test-subset.txt` lists paths relative to `src/dashboard/frontend`, one per line, in sorted position. Today it lists `choreography`, `fit-text`, `model`, `rail-link` and `useConfluenceData` from `confluence/__tests__/`. W19 appends the others.
3. **Run a frontend test** with `npm --prefix src/dashboard/frontend run test -- <path relative to src/dashboard/frontend>`. Never run the full `npm test` on the host.
4. **No source-reading tests.** `npm run lint` includes `lint:source-introspection`: a new test that reads a source file as text fails. Check text through rendered output or exported values.
5. **Fake timers.** A test that depends on time uses `vi.useFakeTimers()` plus `vi.setSystemTime()` and `vi.advanceTimersByTimeAsync()`. `useConfluenceData.test.ts` already does this in `beforeEach`.
6. **File-size ratchet.** Agents may not raise a row in `scripts/file-size-allowlist.txt`. To stay under a count, extract a module.
7. **No `git stash`, no `git checkout` to another branch** in the workspace. One commit per plan item with an `Item: <item-id>` trailer.
8. **If frontend Vitest fails at startup with `EEXIST`** on `node_modules` links, run `bun install` in the workspace and retry.
9. **Tests under `GodView/` never spell a removed identifier**, not even to assert that it is absent (`idleMin`, `staleMin`, `parkedMin`, `frostHold`, `beads`, `beneficiaryId`, `pulseSun`, `spawnFromSun`, `playMerge`, `PROJECT_RING`, `FEED_TICKER_CHANCE`, `pickWeighted`, the text `merge failed`). The grep checks cover the test directory, so such a test would fail its own item. Assert the exact new value instead (`toEqual({ type: 'tide', targetId: 'PAN-5' })`). Absence checks on object keys belong in the Playwright spec of W19, which is outside `GodView/`.

   ```ts
   /** Minutes since the orb last did anything, computed at call time (PAN-5131 FR-3).
    * A stale orb with a parked row counts from parkedAt; every other orb from lastActivity. 0 when unknown. */
   export function orbIdleMinutes(
     orb: { lastActivity: string | null; parkedAt: string | null; state: OrbState },
     now: number,
   ): number {
     const parked = orb.state === 'stale' && orb.parkedAt ? Date.parse(orb.parkedAt) : Number.NaN;
     const stamp = Number.isFinite(parked) ? parked : orb.lastActivity ? Date.parse(orb.lastActivity) : Number.NaN;
     return Number.isFinite(stamp) ? Math.max(0, (now - stamp) / 60_000) : 0;
   }
   ```

   import { useEffect, useState } from 'react';

   /** A local clock tick (PAN-5131 NFR-1): re-renders the caller every intervalMs. It fetches nothing. */
   export function useNowTick(intervalMs = 30_000): number {
     const [now, setNow] = useState(() => Date.now());
