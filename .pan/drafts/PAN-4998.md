# PAN-4998: Keep agent scratch files out of /tmp so a reboot doesn't delete them

**Issue:** https://github.com/eltmon/overdeck/issues/4998
**Status:** planned (auto mode, 2026-11-04)

## Summary

Every managed launch exports `CLAUDE_CODE_TMPDIR=~/.overdeck/tmp`, so Claude Code puts its session
scratchpad under `~/.overdeck/tmp/claude-<uid>/…` instead of `/tmp/claude-<uid>/…`. Ubuntu empties
`/tmp` at every boot (`D /tmp 1777 root root 30d` in `/usr/lib/tmpfiles.d/tmp.conf`), so today a
reboot deletes every agent's scratch files. A new hourly Deacon hygiene routine removes session
directories that are idle for 14 days and not owned by a live agent. `pan doctor` reports the size
of `~/.overdeck/tmp` and warns above 10 GiB. A new universal rule tells agents not to keep files
they may need later in `/tmp`.

## Glossary

- **Agent tmp root** — `<OVERDECK_HOME>/tmp`, which is `~/.overdeck/tmp` unless `OVERDECK_HOME` is
  set. Returned by the new `getAgentTmpDir()` (work item 1). It already exists on this machine and
  holds `background-ai/`, the empty cwd for background `claude -p` calls
  (`src/lib/conversation-search/indexer.ts`, line 344: `join(getOverdeckHome(), 'tmp', 'background-ai')`).
  The sweep must never touch `background-ai/`.
- **`CLAUDE_CODE_TMPDIR`** — Claude Code environment variable that moves its per-user temp root.
  Verified in the installed binary (strings: "the screenshot temp path (override with
  CLAUDE_CODE_TMPDIR)", "Point XDG_RUNTIME_DIR or CLAUDE_CODE_TMPDIR at a private (0700) directory
  you own") and by a live probe on 2026-11-04 (see "Verified behavior").
- **Claude tmp layout** — what Claude Code creates under the tmp root. Verified by probe:
  `<CLAUDE_CODE_TMPDIR>/claude-<uid>/<encoded-project-dir>/<session-uuid>/{scratchpad,tasks}`.
  `<encoded-project-dir>` is the cwd with `/` and `.` replaced by `-` (for example
  `-home-eltmon-Projects-overdeck`). Claude Code also writes loose files directly in
  `claude-<uid>/` (for example `cache-break-state-<uuid>.json`).
- **Session directory** — one `<session-uuid>` directory at depth 3 under the agent tmp root:
  `<root>/claude-<uid>/<encoded-project-dir>/<session-uuid>/`. This is the unit the sweep removes.
  The issue text calls these "top-level session directories"; they are not top-level.
- **Live agent ids** — `listLiveAgentIds()` in `src/lib/terminal-backends/inventory.ts` (line 90):
  the set of agent ids the selected terminal backend (Herdr or tmux) currently hosts. `null` means
  the inventory is indeterminate and the caller must skip. The ids are the directory names under
  `~/.overdeck/agents/` (`conv-<name>`, `agent-pan-…`, `planning-pan-…`).
- **Session index** — `~/.overdeck/agents/<agentId>/sessions.json`, one JSON object per line with a
  `sessionId` field (written by the session-start and heartbeat hooks; append-only).
- **Hygiene scheduler** — `src/lib/cloister/hygiene-scheduler.ts`: the Deacon's host-hygiene
  routines, each on its own `setInterval`.
- **Deacon pause** — `isDeaconGloballyPaused()` from `src/lib/overdeck/control-settings.ts`. Hygiene
  reapers return `[]` while it is true (`src/lib/cloister/herdr-residue-reaper.ts`, line 98).

## Verified behavior (2026-11-04)

1. `git grep -n "CLAUDE_CODE_TMPDIR" -- src` returns nothing. Overdeck sets neither
   `CLAUDE_CODE_TMPDIR` nor `TMPDIR` for managed sessions.
2. Probe: `CLAUDE_CODE_TMPDIR=<scratch>/probe-tmp claude -p --model haiku --allowedTools=Bash "…echo TMPDIR=\$TMPDIR"`
   created `<scratch>/probe-tmp/claude-1000/<encoded-cwd>/<session-uuid>/tasks` and the Bash tool
   printed `TMPDIR=` (empty). Child processes keep the system default temp dir (`/tmp`).
3. The binary contains: "CLAUDE_CODE_TMPDIR makes the per-uid temp dir N bytes, too long for AF_UNIX
   sockets; child-process $TMPDIR falls back to … Shorten CLAUDE_CODE_TMPDIR to ~30 bytes if child
   processes should use your override." `~/.overdeck/tmp/claude-1000` is longer than 30 bytes on
   every normal home, so child `TMPDIR` falls back. That is the wanted outcome: build tools keep
   using `/tmp`.
4. `/tmp/claude-1000` held 465 MB on 2026-11-04; the root disk is 98% full (24 GB free).
5. `~/.overdeck/tmp` exists with mode `0775` (created by the background-AI cwd code). `mkdir -p -m 700`
   does not change an existing directory's mode, so the launcher must also `chmod 700`.
6. Every managed launch (conversations, work/review/test/plan agents, handoffs, workers, resumes)
   builds its script with `generateLauncherScript()` in `src/lib/launcher-generator.ts`. Callers:
   `src/dashboard/server/routes/conversations.ts`, `src/dashboard/server/routes/misc/planning.ts`,
   `src/lib/agents/{messaging,recovery,runtime-command,spawn-prep,spawn}.ts`,
   `src/lib/mcp/agent-injection.ts`, `src/lib/overdeck/conversation-runtime.ts`,
   `src/lib/planning/spawn-planning-session.ts`, `src/lib/remote/remote-agents.ts`,
   `src/lib/runtimes/{kimi-code,muse,ohmypi,prime-agent}.ts`. One export there covers them all.
7. Codex keeps its sessions in a per-agent `CODEX_HOME` (`~/.overdeck/agents/<id>/codex-home*`,
   `src/lib/agents/state-dir-removal.ts` line 113) and pi in `piSessionDir` under the agent dir
   (`src/lib/agents/runtime-command.ts` line 117). Neither harness has a scratchpad that defaults to
   `/tmp`, so neither needs a `TMPDIR` override.

## Requirements

### Functional

- **FR-1** Every non-remote launcher script that `generateLauncherScript()` produces creates the agent
  tmp root (mode `0700`) and exports `CLAUDE_CODE_TMPDIR=<agent tmp root>` before the harness starts.
- **FR-2** Launchers with `spawnMode: 'remote'` (Fly VMs) do not export `CLAUDE_CODE_TMPDIR`; the host
  home path is invalid there.
- **FR-3** If creating or chmod-ing the root fails, the launcher does not export the variable and the
  harness still starts (Claude Code falls back to `/tmp`).
- **FR-4** The Deacon removes a session directory when (a) the newest modification time of the
  directory and everything under it is older than 14 days and (b) its `<session-uuid>` is not
  recorded in the session index of any live agent.
- **FR-5** The sweep never removes: a session directory whose uuid belongs to a live agent; anything
  outside `<root>/claude-<digits>/<dir>/<dir>`; `background-ai/`; loose files; symlinks or anything
  reached through a symlink.
- **FR-6** The sweep skips the whole pass (with one log line) when the live-agent inventory is `null`,
  and returns `[]` without reading anything while the Deacon is globally paused.
- **FR-7** The sweep runs hourly from the hygiene scheduler and once at scheduler start.
- **FR-8** `pan doctor` prints an "Agent scratch" line with the size of the agent tmp root, `ok` at or
  below 10 GiB, `warn` above, `ok` "not created yet" when the root is absent, `warn` when measuring
  fails.
- **FR-9** A universal bundled rule `no-tmp-scratch` tells agents to keep working files in their
  session scratchpad or the project, never in `/tmp`.
- **FR-10** User docs describe the location, the variable, the 14-day cleanup and the doctor line.

### Non-functional

- **NFR-1** No sync child-process calls in code the dashboard server reaches (the sweep runs in the
  server's Deacon). Use `node:fs/promises` and async `execFile` only.
- **NFR-2** Tests that depend on "now" use `vi.useFakeTimers()` + `vi.setSystemTime()`; no real waits.
- **NFR-3** `src/lib/launcher-generator.ts` is 995 lines; the file-size ceiling is 1000
  (`scripts/lint-file-size.sh`, `CEILING=1000`; files at or under it pass without an allowlist row).
  The launcher change adds at most 3 lines. Never raise an allowlist cap.
- **NFR-4** Do not add `harness === '…'` comparisons in `src/` (`npm run lint:harness-branches`
  ratchet). The export is harness-independent.

## Decisions

- **D1 (auto)** Export `CLAUDE_CODE_TMPDIR` in every non-remote launcher regardless of harness.
  Non-Claude harnesses ignore it; any Claude Code child they start benefits. This avoids a harness
  branch (NFR-4).
- **D2 (auto)** Do not set `TMPDIR` for any harness. For Claude Code the issue says so; for codex and
  pi their persistent state already lives under `~/.overdeck/agents/<id>/` (Verified behavior 7), and
  moving all their build temp output onto a 98%-full home disk would be worse.
- **D3 (auto)** Liveness = `listLiveAgentIds()` (backend inventory), then the session ids recorded in
  those agents' `sessions.json`. This is the same oracle `transcript-retention.ts` uses for deletion.
  The issue says "liveness from `src/lib/agents/liveness.ts`", but `isAlive(agentId)` needs an agent
  id and a session directory only carries a session uuid; reading `sessions.json` for the ~10 live
  agents is cheap, while reverse-mapping all 3,800 agent dirs is not. The inventory counts a pane as
  live even when only its shell remains, so it errs toward keeping. A `null` inventory skips.
- **D4 (auto)** 14 days and 10 GiB are constants (`AGENT_TMP_RETENTION_DAYS`, `AGENT_TMP_WARN_BYTES`),
  not config keys.
- **D5 (auto)** Hourly cadence, like transcript retention (`TRANSCRIPT_RETENTION_INTERVAL_MS`).
- **D6 (auto)** "Modified" = the newest `lstat` mtime of the session directory and every entry under it
  (no symlink following). The walk stops at the first entry newer than the cutoff.
- **D7 (auto)** Measure size with async `execFile('du', ['-sk', root])`, 30 s timeout. `du` is faster
  than a Node walk on a large tree and exists on Linux and macOS.
- **D8 (auto)** Docs go in `configuration/harnesses.mdx` (new "Scratch directory" subsection in the
  Claude Code section). Neither `configuration/context-layers.mdx` nor `docs/CONTEXT-LAYERS.md` lists
  individual bundled rules (the "Instruction source inventory" table has one row for all of
  `sync-sources/rules/*.md`), so they need no change. The codebase map
  (`.overdeck/context/codebase/architecture.md`) gets one line for the new modules.

## Work items

### W1 — Agent tmp path module (foundation)

**What/why:** One place names the agent tmp root and the launcher line, so the launcher, the sweep
and doctor agree on the path.

**Files:** new `src/lib/agent-tmpdir.ts`; new `src/lib/__tests__/agent-tmpdir.test.ts`.

**Steps:**
1. Create `src/lib/agent-tmpdir.ts` (leaf: imports only `node:path`, `./paths.js`, `./shell-quote.js`):

   ```ts
   /**
    * Agent scratch root (PAN-4998). Claude Code keeps its session scratchpad under
    * `<CLAUDE_CODE_TMPDIR>/claude-<uid>/<encoded-cwd>/<session-uuid>/`; the default is
    * /tmp, which Ubuntu empties at every boot. Managed launches point it here instead,
    * and the Deacon's agent-tmp sweep removes idle session directories.
    */
   import { join } from 'node:path';

   import { getOverdeckHome } from './paths.js';
   import { shellQuote } from './shell-quote.js';

   export const AGENT_TMP_RETENTION_DAYS = 14;

   /** `<OVERDECK_HOME>/tmp` — read at call time so OVERDECK_HOME overrides apply. */
   export function getAgentTmpDir(): string {
     return join(getOverdeckHome(), 'tmp');
   }

   /**
    * The launcher line: create the root private (0700) and export it. A failed
    * mkdir/chmod leaves the variable unset, so Claude Code falls back to /tmp.
    * Contains no `$`, so `escapeForBase64` leaves it unchanged.
    */
   export function agentTmpdirLauncherLine(dir: string = getAgentTmpDir()): string {
     const q = shellQuote(dir);
     return `mkdir -p ${q} && chmod 700 ${q} && export CLAUDE_CODE_TMPDIR=${q}`;
   }
   ```
2. Tests (`src/lib/__tests__/agent-tmpdir.test.ts`): `getAgentTmpDir()` returns `<OVERDECK_HOME>/tmp`
   when `process.env.OVERDECK_HOME` is set (restore it after); `agentTmpdirLauncherLine('/a b/tmp')`
   equals `mkdir -p '/a b/tmp' && chmod 700 '/a b/tmp' && export CLAUDE_CODE_TMPDIR='/a b/tmp'`
   (`shellQuote` in `src/lib/shell-quote.ts` wraps in single quotes); run the line in `bash -c "<line>; printf %s \"\$CLAUDE_CODE_TMPDIR\""`
   via async `execFile` against a `mkdtemp` dir whose `tmp` child pre-exists with mode `0775`, and
   assert the output equals the path and `stat().mode & 0o777 === 0o700`.

**Traces:** FR-1, FR-3.

### W3 — Agent tmp sweep module

**Files:** new `src/lib/cloister/agent-tmp-sweep.ts`; new
`src/lib/cloister/__tests__/agent-tmp-sweep.test.ts`.

**Shape** (model on `src/lib/cloister/transcript-retention.ts`):

```ts
export interface AgentTmpSweepDeps {
  readDir(path: string): Promise<Dirent[]>;          // readdir(path, { withFileTypes: true })
  lstat(path: string): Promise<Stats>;
  realpath(path: string): Promise<string>;
  removeTree(path: string): Promise<void>;           // rm(path, { recursive: true, force: true })
  removeEmptyDir(path: string): Promise<void>;       // rmdir(path) — fails ENOTEMPTY when not empty
  readSessionsIndex(agentId: string): Promise<string | null>; // sessions.json text, null if absent
  listLiveAgentIds(): Promise<ReadonlySet<string> | null>;
  isPaused(): boolean;                               // isDeaconGloballyPaused
  now(): number;                                     // Date.now()
  log(message: string): void;                        // console.log(`[deacon] ${message}`)
}
export interface AgentTmpSweepOptions { root?: string; agentsDir?: string; deps?: Partial<AgentTmpSweepDeps> }
export async function sweepAgentTmpDirs(options: AgentTmpSweepOptions = {}): Promise<string[]>;
```

**Algorithm:**
1. If `deps.isPaused()` → return `[]`.
2. `root = options.root ?? getAgentTmpDir()`. `readDir(root)`; ENOENT → return `[]`.
3. `live = await deps.listLiveAgentIds()`; `null` or a throw → log and return
   `['Agent tmp sweep skipped: backend liveness inventory unavailable']`.
4. Live session ids: for each id in `live`, `readSessionsIndex(id)` (default reads
   `join(options.agentsDir ?? AGENTS_DIR, id, 'sessions.json')`), split lines, `JSON.parse` each in a
   try, collect string `sessionId` values. Malformed lines are skipped.
5. `canonicalRoot = await deps.realpath(root)`; `cutoff = now() - AGENT_TMP_RETENTION_DAYS * 86_400_000`.
6. For each entry of `root` that `isDirectory()` (Dirent, not following symlinks) and matches
   `/^claude-\d+$/`; for each child that `isDirectory()` (project dir); for each grandchild that
   `isDirectory()` (session dir): skip if its name is in the live session set; compute the newest
   mtime (D6, early exit when ≥ cutoff); skip if ≥ cutoff. Then `realpath` the session dir and
   require it is inside `canonicalRoot` with exactly three path segments
   (`relative(canonicalRoot, real).split(sep).length === 3`, and no segment is `..`); then
   `removeTree`. The live set is built once per pass (step 4); a session that started after that read
   has a fresh mtime and is kept by the mtime rule.
7. After a project dir's sessions are processed, and only if at least one session in it was removed
   this pass, call `removeEmptyDir` on the project dir and ignore
   `ENOTEMPTY`/`ENOENT` (removes empty project dirs only). Never `rmdir` `claude-<uid>` or the root.
8. Any error on one entry is caught and the loop continues (same as `transcript-retention.ts`).
9. Return one summary action:
   `Agent tmp sweep: removed N session director{y|ies} idle over 14 days; kept M live`.

**Tests** (`vi.useFakeTimers(); vi.setSystemTime(new Date('2026-11-04T00:00:00Z'))`, real fs in a
`mkdtemp` dir, mtimes set with `utimes`, `listLiveAgentIds`/`readSessionsIndex` injected):
- removes `claude-1000/-proj/<uuid-a>/` whose files are 15 days old and whose uuid is in no index;
- keeps a 15-day-old session dir whose uuid appears in a live agent's `sessions.json`;
- keeps a session dir with one file modified 1 day ago even though the dir itself is old;
- keeps everything and returns the "skipped" action when `listLiveAgentIds` returns `null`;
- returns `[]` and reads nothing when `isPaused` returns true;
- never touches `background-ai/`, a loose file in `claude-1000/`, or a symlink at session depth that
  points at a directory outside the root (the symlink target still exists afterwards);
- removes a project dir left empty after its only session is removed.

**Traces:** FR-4, FR-5, FR-6, NFR-1, NFR-2.

## Non-goals

- Moving or migrating existing `/tmp/claude-<uid>` contents.
- Setting `TMPDIR` for any harness.
- Removing loose files in `claude-<uid>/` or anything outside session directories.
- Changing systemd-tmpfiles configuration or making `/tmp` persistent.
- Config keys for the 14-day window or the 10 GiB threshold.
- Remote (Fly) launches.
- Rewriting launcher scripts of sessions already running; the change applies to new launches and
  relaunches.

## Repo rules that apply

- Fake timers for any time-dependent test (`vi.useFakeTimers()`, `vi.setSystemTime`,
  `vi.advanceTimersByTimeAsync`); never real waits.
- No `execSync` in server-reachable code; the sweep and doctor helper use async APIs.
- File-size ratchet: `launcher-generator.ts` must stay ≤ 1000 lines; never edit
  `scripts/file-size-allowlist.txt` upward.
- No new `harness === …` comparisons (`lint:harness-branches`).
- Spell out literal paths in shell `rm` commands you run by hand; the sweep deletes through
  `fs.rm` only after the containment check.
- Quality gates: `npm run typecheck`, `npm run lint`, and `npx vitest run <touched test files>`.
  Never run the full `npm test` on the host.

## Hazards

- `chmod 700` on the existing `~/.overdeck/tmp` also covers `background-ai/` access; that dir is used
  by the same user, so nothing breaks.
- Claude Code may print a notice that the per-uid temp path is too long for AF_UNIX sockets. Child
  `TMPDIR` then falls back to `/tmp`, which is intended (Verified behavior 3).
- A Claude Code process nested inside a managed session inherits `CLAUDE_CODE_TMPDIR` but writes no
  `sessions.json`; its directory is protected only by the 14-day mtime rule. That is acceptable: such a
  directory has had no writes for 14 days.
- `sessions.json` can be large (heartbeat lines). Read it only for live agent ids, once per pass.
- `scripts/guard-agent-dir-removal.sh` (`npm run lint:agent-dir-removal`, part of `npm run lint`)
  flags any `rm`/`rmdir` line that mentions `AGENTS_DIR` or a variable assigned from it. Keep the
  `sessions.json` reader in its own function so no `AGENTS_DIR`-derived name shares a line with a
  removal call. `scripts/lint-liveness.sh` accepts the backend live inventory as a liveness door.
