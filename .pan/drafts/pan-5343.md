## 1. Glossary

- **Deck** — the Stage's tabs, panes and split layout for one key (`deckKey`). Today the key is always a project key or `NO_PROJECT_KEY` (`'__no-project__'`, `FE/components/CommandDeck/projectsData.ts` line 14). Panes are stored in `usePanesStore` under `panesByWorkspace[deckKey]`, and the layout in localStorage `pan-layout:${deckKey}` (`FE/components/Stage/index.tsx` line 352).
- **All projects deck** — a new deck with the key `ALL_PROJECTS_KEY = '__all-projects__'`. Its panes may be conversations from any project. It has no Home pane.
- **Agent pane** — a pane with `paneType: 'agent'` and `conversationId: <conversation name>` (`FE/lib/panesStore.ts` lines 19–44). It renders `AgentPane` → `ConversationPanel`, and each one has its own composer.
- **Layout** — a binary tree of leaves and splits (`FE/lib/paneLayout.ts` lines 11–13). Split ratios clamp to 0.15–0.85 (line 101).
- **Focused pane** — the deck's active pane (`activePaneByWorkspace[deckKey]`). With more than one leaf, `PaneLayoutView` highlights its split header (`splitHeaderFocused`, `FE/components/Stage/PaneLayoutView.tsx` line 107).
- **Open beside** — show a conversation in a new leaf next to the focused leaf, without hiding the panes already on screen.

## 3. Decisions

- **H-D1 One new deck key.** Add `export const ALL_PROJECTS_KEY = '__all-projects__'` and `ALL_PROJECTS_LABEL = 'All projects'` next to `NO_PROJECT_KEY` in `projectsData.ts`. `isKnownProject` accepts it. The URL is `/command-deck/__all-projects__`, built by the existing route code with no special case. The deck's panes and layout persist under this key exactly as a project deck's do.
- **H-D2 Two doors, one state.** The project switcher gets an **All projects** item at the top of its menu, with a muted `✱` mark and the subtitle `<N> projects · <M> active`. The Conversations section gets a **This project / All projects** segmented switch under its header, matching the mockup. Both set `selectedProjectKey`. "This project" selects the remembered last real project (`readLastProjectKey()` from PAN-5335's `FE/lib/lastProject.ts`), or the first registered project when none is stored. Selecting All projects does not overwrite the remembered last project: `writeLastProjectKey` is skipped for `ALL_PROJECTS_KEY`.
- **H-D3 The All projects list.** With `ALL_PROJECTS_KEY` selected, `ConversationsSection` passes no `includeIds`. The Active / All filter still applies. Rows render in this order:
  1. today's **Needs you** section, unchanged, with each row's title prefixed by its project mark;
  2. the remaining visible rows grouped by project, each group headed by the project mark, name and `N working` (or `idle`), with projects in alphabetical order and No-project conversations last under "No project".
  Group headers are not collapsible. Rows keep today's row menu, meta line and handoff grouping. A row whose conversation is in a visible leaf of the deck shows a small pane-number badge (`1`–`4`, by leaf order from `collectLeafIds`) on its right.
- **H-D4 What hides in All projects mode:** the Project home nav item, the Issues and Workspaces sections, the deck's Home tab, and the "Changes in <project>" new-pane action. The top-bar crumb reads `All projects / Conversation` with one leaf, or `All projects / N conversations side by side` with N leaves.
- **H-D5 Click semantics, in every deck.**
  - **Plain click:** in the All projects deck, show the conversation in the focused leaf. If it is already in a visible leaf, focus that leaf. Otherwise put its agent pane in the focused leaf with `replaceLeaf`, adding the pane if needed. The replaced pane stays open as a tab. In a project deck, keep today's behavior.
  - **Ctrl+Click** (Cmd+Click on macOS), the row's hover **Beside** button, and the row menu's new **Open beside** item: open beside, in every deck. In a project deck this applies only to conversations of that project. A conversation from another project opens beside in the All projects deck instead, which switches to it.
  - **Multi-select** moves off Ctrl/Meta: **Shift+click** (range and toggle) and the row checkboxes keep bulk Settle/Snooze working. Update `handleRowClick` so `e.metaKey || e.ctrlKey` calls the new `onOpenBeside(name)` prop when it is provided, and keeps today's toggle when it is not.
- **H-D6 Open beside rule.** The new function `openBesideConversation(deckKey, name, label)` lives in `FE/components/Stage/` and is exposed on `StageDeckContext` as `openConversationBeside(name, label)`. If the conversation already has a visible leaf, it focuses that leaf. Otherwise it adds or finds the agent pane and splits the focused leaf with `splitAtLeaf(layout, focusedLeafId, paneId, 'row')`. When the deck already shows 4 leaves, it replaces the least recently focused leaf instead, and the replaced pane stays a tab. The deck's focus history is a session-only array kept in the Stage component state.
- **H-D7 Layout presets.** Add `presetLayout(paneIds: string[], preset: 1 | 2 | 3 | 4): PaneLayout` to `paneLayout.ts`:
  - 1 → `leaf(a)`;
  - 2 → row split `(a, b)` at 0.5;
  - 3 → row split `(a, rowSplit(b, c, 0.5))` at ratio `1/3`;
  - 4 → col split of `rowSplit(a, b, 0.5)` and `rowSplit(c, d, 0.5)` at 0.5.
  It takes the first `preset` ids and requires `paneIds.length >= preset`. The **Layout** bar shows four buttons at the right end of the tab strip, in the All projects deck only. They use the mockup's icons and titles: One, Two side by side, Three columns, Grid of four. A button is disabled when fewer agent panes are open than it needs. Pane order: the visible leaves in leaf order, then the other agent panes by most recent focus. The pressed button reflects `leafCount(layout)` when it is 1–4 and the shape matches.
- **H-D8 Drag a row onto a pane.** Rows get `draggable` and set `application/x-conversation-name` to the conversation name. A tiny store, `FE/components/Stage/conversationDragStore.ts` (zustand, `{ dragging: string | null }`), is set on dragstart and cleared on dragend. While it holds a value, `PaneLayoutView` shows the same drop overlay it shows for tab drags. On drop with that data type, the Stage adds or finds the agent pane and calls today's `onDropTab(targetPaneId, newPaneId, zone)`. The center zone replaces, and an edge opens beside. Dragging a row onto a project deck works only for that project's conversations; for any other conversation the drop overlay does not appear.
- **H-D9 Pane identity.** In the All projects deck, each split header (`PaneLayoutView` `showHeaders`) and each conversation tab label is prefixed with the project mark: an 18px rounded square with the project's initials, as in the mockup. Use `<ProjectMark size="sm">` from `FE/components/frame/ProjectMark.tsx`, which PAN-5335 WI-9 adds. The conversation header itself is unchanged, because its status line already shows the folder.
- **H-D10 No Home in this deck.** `ensureHome` is skipped for `ALL_PROJECTS_KEY`, both in the Stage mount effect and in the new opener. With no panes, the deck shows a centered empty state: `Pick conversations on the left. Ctrl+Click opens one beside another.` (`Cmd+Click` on macOS).
- **H-D11 Deck-bound features in this deck.** `terminalCwd` is `undefined`, so the terminal drawer opens in the home folder as it does for No project. The dock already follows the focused pane, so it needs no change. Ctrl+Alt+1..9 keep today's behavior.
- **H-D12 Deep links.** When the All projects deck is selected and a `/conv/<id>` navigation names a conversation, it opens in this deck with the H-D5 plain-click rule and does not switch projects. Change the effect in `CommandDeck/index.tsx` lines 149–182 to skip `onSelectProject` when `selectedProject === ALL_PROJECTS_KEY`.
- **H-D13 New conversation in this deck.** The New conversation button creates the conversation in the remembered last real project and opens it beside the focused pane. Its second line (from PAN-5335 D-7) gains the project name first, for example `overdeck · ✳ Opus 5.5 · High`.
