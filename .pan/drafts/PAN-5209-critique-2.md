## blocks-the-design: Failed target fetch can still pass row 4

[The PRD](/home/eltmon/Projects/overdeck/workspaces/feature-pan-5209/.pan/drafts/PAN-5209.md), line 69, says that a failed target fetch with no local target must fail the merged row. The proposed verifier does return a failure, but [checkMergedRow](/home/eltmon/Projects/overdeck/workspaces/feature-pan-5209/src/lib/lifecycle/dod-gate.ts), lines 567–580, runs branch containment after *any* verification miss and changes the row to `pass` when it sees merged work. [resolveRepositoryDefaultBranch](/home/eltmon/Projects/overdeck/workspaces/feature-pan-5209/src/lib/pipeline-membership-gather.ts), lines 407–428, can select a cached `origin/main` when local `main` is absent, and `snapshotBranchRefs`, lines 461–474, classifies against that ref without refreshing it. Thus a fetch failure with no local `main` can still close out using stale cached containment evidence. Keep this particular verification-unavailable failure as a row 4 miss; add a `checkMergedRow` test with a failed verifier and positive cached containment.

## blocks-the-design: Unpinned GitLab lookup may choose an older MR

[The PRD](/home/eltmon/Projects/overdeck/workspaces/feature-pan-5209/.pan/drafts/PAN-5209.md), line 196, removes `headSha` from the GitLab merged-artifact lookup. [findMergedGitLabArtifact](/home/eltmon/Projects/overdeck/workspaces/feature-pan-5209/src/lib/forge.ts), lines 336–359, uses `.find` on all merged MRs for the source branch, with no date sort. Its [matching predicate](/home/eltmon/Projects/overdeck/workspaces/feature-pan-5209/src/lib/forge.ts), lines 236–243, only checks the head when `input.headSha` is supplied. If the same branch has an older merged MR and a later squash-merged MR, the lookup can return the older head; the planned post-MR delta check can then reject work already merged by the later MR. Require deterministic selection of the current or latest merged MR before judging the delta, and test two merged MRs on the same source branch with the newer one returned second.
