# PAN-5338 — Conversation diff view: rendered Preview for Markdown files and an Open file action

**Issue:** [PAN-5338](https://github.com/eltmon/overdeck/issues/5338)
**Planning mode:** `pan plan --auto` (no operator questions; defaults recorded in "Decisions" and in the xBRIEF `autoDecisions`).

## Glossary

- **Diff panel** — `DiffPanel` in `src/dashboard/frontend/src/components/DiffPanel.tsx`. It renders the conversation diff: the turn strip (All turns, vs main, Compare…, Turn N chips), the toolbar toggles, and the patch of the selected file through `PatchFiles`.
- **Inline diff panel** — the `DiffPanel` that `ConversationPanel` mounts beside the chat when the URL has `?diff=1` (`components/chat/ConversationPanel.tsx`, search `<DiffPanel`).
- **Pop-out diff** — the `/popout/diff` window. `StandaloneDiffPopoutRoute` in `src/dashboard/frontend/src/App/StandaloneRoutes.tsx` mounts a bare `DiffPanel` with `mode="sheet"` from URL params.
- **Scope** — what the diff panel compares. One of: *All turns* (`diffTurnId` absent), *one turn* (`diffTurnId=<turnId>`), *vs main* (`diffTurnId=vs-main`), *Compare* (`diffTurnId=compare` plus `diffBase`/`diffHead`).
- **After side** — the file text on the right-hand side of the diff for the selected scope.
- **Diff source prefix** — `diffUrlPrefix`, the fetch base. Conversation routes: `/api/conversations/<name>/diffs`. Agent routes: `/api/agents/<id>/diffs` (the default when no prefix is given).
- **Explorer root** — a root id understood by the file explorer RPCs: `project:<key>`, `issue:<ID>`, `workspace:<id>` (`components/explorer/rootForConversation.ts`).
- **Repo path / root path** — a diff path is relative to the git top level of the conversation's cwd (a *repo path*). The explorer takes paths relative to the explorer root folder (a *root path*). `toRootPath` in `components/dock/changes-model.ts` maps one to the other.
- **openBeside** — `StageDeckContextValue.openBeside` in `components/Stage/StageDeckContext.tsx` (PAN-5287). It opens a code pane for `{ rootId, path }` beside the chat, splitting the deck when needed. It is `null`-context outside a Stage (pop-out windows).
- **MarkdownTab / ChatMarkdown** — the one Markdown renderer. `MarkdownTab` (`components/CommandDeck/ZoneCOverviewTabs/MarkdownTab.tsx`) wraps `ChatMarkdown` (`components/chat/ChatMarkdown.tsx`). The file pane's Preview uses it (`components/explorer/code/CodePane.tsx`, search `<MarkdownTab body=`).
- **Relative link** — an href with no `http:`/`https:`/`mailto:` scheme that does not start with `#` or `/`, for example `fort3d.md` or `../x.md`.

## Problem

The diff panel shows a Markdown file only as raw source lines, and it has no control to open the file. To read a document a conversation wrote, the operator must find it again in the Files dock and switch it to Preview. Conversation 3904 in `dfai` added `docs/songs-and-videos.md` (+324 lines); its diff shows 324 green source lines.

## Implementation checkpoint resolved: where the after side comes from

Verified in the server code at planning time (2026-11-15, main `c9906c2370a`):

| Scope | What the route diffs (verified) | After side | Preview source |
| --- | --- | --- | --- |
| All turns (conversation route) | `getConversationDiffFull` in `src/lib/overdeck/conversation-diffs.ts` calls `diffPatchSinceCommit(cwdRepoRoot, baseCommit, fileFilter)`; `diffPatchSinceCommit` in `src/lib/checkpoint/checkpoint-manager.ts` runs `git diff --patch … <baseCommit> [-- file]` | **working tree** | explorer `readFile(rootId, rootPath)` |
| One turn (conversation route) | `getConversationDiffTurn` runs the same `diffPatchSinceCommit(cwdRepoRoot, baseCommit, …)` for the cwd repo; the turn id does not change the cwd-repo patch | **working tree** | explorer `readFile(rootId, rootPath)` |
| vs main | `diffVsDefaultBranch` → `diffAgainstBase` runs `git diff … ${baseRef}...HEAD` | **HEAD** | explorer `readFile(rootId, rootPath, 'HEAD')` |
| Compare… | `/api/diffs/compare` with an arbitrary `head` ref | **`<head>`** | explorer cannot read an arbitrary ref (`readFile` accepts only `ref?: 'HEAD'`, `src/dashboard/server/services/explorer/read.ts`) → working tree **with the note** |
| Agent route, turn that is not the newest | `diffCheckpoints(workspace, agentId, fromTurnId, turnId)` in `src/dashboard/server/routes/diffs.ts` | checkpoint ref | working tree **with the note** |
| Added file, any scope | the patch holds every line (`@pierre/diffs` `FileDiffMetadata.type === 'new'`, `additionLines` = all `+` lines) | patch | text rebuilt from the patch, **no read** |

The note text is exactly: `Showing the current file`.

No new HTTP route is needed, so there are no `route-scopes.ts` or `tests/unit/lib/overdeck/no-loss-matrix.ts` rows to add.

Both current `DiffPanel` mounts pass a conversation prefix: `ConversationPanel` passes `diffUrlPrefix={`/api/conversations/${…}/diffs`}`, and the pop-out receives that prefix through its `prefix` URL param. The agent-route rows of the table are a defensive rule only.

## Decisions (made here; the work agent does not re-decide)

- **D-1 Preview source rule.** Exactly the table above. Pure function `markdownPreviewSource` (WI-1) encodes it.
- **D-2 Deleted file.** A file is deleted when the parsed patch file has `type === 'deleted'`, or the file list entry (`TurnDiffFileChange.kind`) starts with `D`. A deleted file shows no switch.
- **D-3 Header placement.** The `@pierre/diffs` file header is inside a shadow DOM and is not mounted in Preview. So a new DiffPanel-owned row, `DiffFileBar`, sits above the patch viewport whenever a file is selected. It shows the path, the **Diff | Preview** tablist (Markdown, not deleted, patch resolved), and **Open file** (when available).
- **D-4 Switch state.** Local state `{ path: string; view: 'diff' | 'preview' } | null`. The effective view is `preview` only when `state.path === selectedFilePath` and `state.view === 'preview'`; otherwise `diff`. So the choice resets when `diffFilePath` changes, and it survives a scope change for the same file. Diff is the default. The pop-out window opens in Diff (the view is not put in the URL).
- **D-5 Switch visibility while loading.** The switch renders only when the selected file's patch has resolved (`typeof diffResponse.diff === 'string'`). An empty patch (no net changes) still shows the switch for a Markdown file; Preview then reads the after side.
- **D-6 Open file.** Uses `useStageDeck()?.openBeside?.({ rootId, path: rootPath })`, already on main (PAN-5287; used by `components/dock/changes/DockDiffView.tsx`). No Stage-tab fallback is written. The button renders only when a deck with `openBeside` exists and `explorerRootId` is non-null. It renders for every selected file, not only Markdown. In the pop-out window there is no deck, so there is no Open file button.
- **D-7 Root id.** `DiffPanel` gets a new optional prop `explorerRootId?: string | null`. `ConversationPanel` computes it with `rootIdForConversation(conversation, useRootContext())`. The pop-out button writes it as the `root` URL param, and `StandaloneDiffPopoutRoute` passes `search.get('root')` back in.
- **D-8 Path mapping.** `rootPath = diffPathToRootPath(repoPath, { repoRoot, rootAbs, cwd })` (WI-1): (a) when `rootAbs` and `cwd` are both known and `cwd` is neither `rootAbs` nor under `rootAbs/` → `null` (the conversation works in another folder than its root, for example an issue conversation run outside its workspace; reading the root would show another tree's file); (b) when `repoRoot` or `rootAbs` is null → the repo path unchanged; (c) otherwise `toRootPath(repoRoot, rootAbs, repoPath)`. `cwd` is DiffPanel's existing `repoPath` prop (the conversation's cwd). `repoRoot` comes from the vs-main response (`body.repoRoot`, already returned) and is null for the other scopes. `rootAbs` is `useExplorerStore((s) => s.roots[rootId]?.dirs['']?.absPath ?? null)`, the same read `DockDiffView` uses. When the mapping returns null, Preview of a non-added file shows `This file is outside the conversation's folder.` and Open file is hidden.
- **D-9 No root.** When `explorerRootId` is null or absent: an added file still previews from the patch; any other file shows `Open this conversation's folder on this machine to preview this file.`; Open file is hidden.
- **D-10 Read results.** Loading → `MarkdownTab isLoading`. `kind !== 'text'` (large or binary) → `This file is too large to preview.` A read error → `Couldn't read this file: <explorerErrorMessage(error)>`.
- **D-11 Relative links (requirement 7).** #5337 is open. Until it merges, the preview must not render relative hrefs as browser links. Add an opt-in prop `plainRelativeLinks?: boolean` to `ChatMarkdown` and `MarkdownTab` (default `false`, so no other caller changes). With it set, `makeComponents().a` renders a relative href (Glossary) as a plain `<span>` holding the link text, after the existing file-link-chip check and before `TranscriptLink`. Only the diff preview passes it. **Implementation checkpoint:** if #5337 has merged when work starts and `MarkdownTab` accepts a file location (or a `resolveLink` handler), pass the root id and root path through that seam instead and do not add `plainRelativeLinks`. Record which branch was taken in the commit message.
- **D-12 Pop-out explorer reads.** `/popout/conversation/<id>` already runs `ConversationPanel` (which uses `/ws/rpc`) in a bare window, and `getTransport()` in `src/dashboard/frontend/src/lib/wsTransport.ts` opens the socket lazily, so explorer RPCs are expected to work in `/popout/diff`. **Implementation checkpoint:** confirm it during browser verification (WI-7). Fallback if it does not work: `StandaloneDiffPopoutRoute` passes no `explorerRootId` (it ignores the `root` param), so D-9 applies in the pop-out (added files preview; other files show the D-9 sentence). The inline panel still writes `root` into the pop-out URL; nothing in `DiffPanel.tsx` changes for the fallback.
- **D-14 All turns can show one file.** Today a file cannot be selected under All turns: `parseDiffRouteSearch` (`src/dashboard/frontend/src/lib/diffRouteSearch.ts`, search `const diffFilePath = diff && diffTurnId`) drops `diffFilePath` when `diffTurnId` is absent, and `DiffPanel` line ~254 (`const selectedFilePath = selectedTurnId !== null ? (effectiveParams.diffFilePath ?? null) : null`) does the same, so clicking a file in the All turns picker does nothing. The `/diffs/full?file=` fetch and the `diff-full` query key already support a file. Requirement 2 names All turns, so WI-10 removes both gates.
- **D-13 Scope.** The dock Changes diff view (`DockDiffView`) is not changed here. The new preview component is built so it can be reused there later.
