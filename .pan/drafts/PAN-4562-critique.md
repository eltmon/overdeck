## blocks-the-design: fake activity flip cannot occur

PRD WI-14 fixes the mocked fake behavior as `{ ...actual.MUSE_BEHAVIOR, displayName: 'Fake Harness', capabilities: FAKE_CAPS }`, then requires the activity parser to switch from Codex to Kimi when the capability set changes. In `packages/contracts/src/harness-behavior.ts`, line 219, `MUSE_BEHAVIOR.transcriptKind` is `muse-jsonl`. Parser selection in `src/dashboard/server/services/conversation/activity-summary.ts`, lines 89–93, reads `behavior.transcriptKind`, which is outside `capabilities`; changing `FAKE_CAPS` cannot select either parser. The cache at lines 43–57 also returns the first result for a second run with the same fake harness and unchanged file. The frontend fake proof likewise changes top-level `displayName`, not a capability (`src/dashboard/frontend/src/components/CommandDeck/ConversationRow.tsx`, lines 38–47). Smallest fix: make the fake definition vary `transcriptKind` explicitly and use distinct transcript files or invalidate the cache between cases. Describe that test as proof of declared adapter selection, then either narrow FR-17/Goal 4 to a fake *definition* or add a real server/frontend capability flip if the requirement specifically demands capabilities at all three layers.

## sharpens-framing: adding a harness needs more than four steps

PRD WI-16 calls its four steps “Adding a harness,” but those steps stop at the name, behavior declaration, transcript-kind tables, and lint. `src/lib/runtimes/index.ts`, lines 130–146, registers runtime adapters explicitly; `src/lib/conversations/harness-discovery.ts`, lines 30–59 and 133–161, explicitly lists discovery sources; `src/lib/harness-binary.ts`, lines 64–73, maps runtime names to executables. A new behavior row and passing branch lint do not register an adapter or discover its transcripts. Smallest fix: label the four steps “Adding a capability declaration” and link a complete harness-implementation procedure, or expand them to include adapter registration, binary mapping, discovery, and policy checks.
