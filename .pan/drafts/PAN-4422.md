## Glossary

- **GPT-6.1 Sol** — OpenAI model id `gpt-6.1-sol`, released 2026-09-29. Mid tier, successor to `gpt-6-sol`. Note the **dot**: `gpt-6.1-sol`, not `gpt-6-1-sol`.
- **GPT-6 Sol** — the existing id `gpt-6-sol`. It must stay a separate model everywhere; the two ids must never be confused in pricing or display.
- **Codex floor** — the oldest Codex CLI version OpenAI's backend accepts for a model under ChatGPT sign-in. Stored in `CODEX_MODEL_MINIMUM_VERSIONS` (`src/lib/codex/model-floors.ts`). Below it, OpenAI answers HTTP 400 and Overdeck's policy gate refuses the launch first. API-key auth has no floor.
- **ChatGPT sign-in / `subscription` auth** — Codex authenticated with a ChatGPT account (`AuthMode === 'subscription'`), as opposed to `api-key`.
- **CLIProxy** — the local sidecar on port 8317 that lets the `claude-code` harness run GPT models through a ChatGPT subscription. Pinned to `v7.3.16` in `src/lib/cliproxy.ts`.
- **272K billing-tier pin** — Overdeck caps GPT-6/GPT-5.6 sessions at 272,000 tokens (`CLIPROXY_GPT56_CONTEXT_WINDOW`, `src/lib/model-context-windows.ts:46`) because OpenAI bills prompts over 272K input at 2x input / 1.5x output. Codex's managed `config.toml` writes `model_context_window = 272000`; Claude Code gets `CLAUDE_CODE_AUTO_COMPACT_WINDOW`/max-context env from `provider-env.ts`.
- **`costPer1MTokens`** — the blended picker price Overdeck displays: (input + output) / 2 per 1M tokens. For $2 in / $10 out that is `6`.
- **Unreleased changelog block** — `<Update label="vX.Y.Z" description="Unreleased" tags={["Upcoming"]}>` at the top of `changelog.mdx`, finalized on release day per `docs/RELEASING.md` "Update the public changelog".

## Verified facts (2026-09-29, this host)

- Model facts from the issue (OpenAI docs): context 1,050,000; max output 128,000; $2.00/M input, **$0.10/M cached input** (GPT-6 Sol is $0.20), $10.00/M output; efforts low/medium/high/xhigh/max; knowledge cutoff 2026-04-30.
- `codex --version` → `codex-cli 0.159.0`. `codex debug models` lists `gpt-6.1-sol`: `context_window 272000`, `max_context_window 872000`, `default_reasoning_level low`, `supported_in_api true`, efforts `low, medium, high, xhigh, max, ultra` — identical shape to `gpt-6-sol` (Overdeck already omits `ultra` for GPT-6 Sol).
- Issue-measured floor: Codex 0.158.0 + ChatGPT login → 400 `The 'gpt-6.1-sol' model is not supported when using Codex with a ChatGPT account.`; 0.159.0 succeeds.
- **CLIProxy checkpoint (issue item 3) — resolved by probe:** `GET http://127.0.0.1:8317/v1/models` on the pinned CLIProxyAPI 7.3.16 lists `gpt-6.1-sol`. `POST /v1/messages` with `model: "gpt-6.1-sol"` returned a real completion (`"model":"gpt-6.1-sol"`, `"text":"OK"`). So the claude-code route **is supported** and gets the same 272K pin as GPT-6 Sol.
- Same probe: `gpt-6-sol` now answers `unknown provider for model gpt-6-sol` and is absent from `/v1/models`. This contradicts the `cliproxy.ts:57` note. Out of scope here (see hazards / NonGoals).
