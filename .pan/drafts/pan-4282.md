## Glossary

- **Prerequisites report**: the JSON returned by `GET /api/prerequisites`. Route at `src/dashboard/server/routes/misc/meta.ts:82-90` (anchor: `'/api/prerequisites'`). Built by `checkSystemPrerequisites()` in `src/lib/system-prerequisites.ts:327` from the `PREREQUISITES` catalog (`:58`).
- **Catalog entry**: one `PrerequisiteDefinition` (`id`, `name`, `required`, `purpose`, `versionArgs`, `install`) in `PREREQUISITES`.
- **Host backend**: the terminal backend this host uses for agents, `'herdr' | 'tmux'`. Policy lives in `hostTerminalBackendName()` (`src/lib/terminal-backends/select.ts:143`, anchor `export function hostTerminalBackendName`), memoized per process; env → config → default `herdr`.
- **Herdr availability**: `probeHerdrAvailability()` (`select.ts:216`) returns `{ binary, session, socket, socketExists, available, reason? }`. It spawns no subprocess.
- **Ad-hoc terminal / plain terminal**: a shell from `POST /api/terminals`, shown in the terminal drawer. It is always a tmux session, whatever the host backend is. So tmux is still needed for plain terminals under Herdr, but not for agents.
- **Claude login**: `getClaudeAuthStatus()` (`src/lib/claude-auth.ts:153`) returns an `Effect` of `{ installed, loggedIn, expired, subscriptionType, rateLimitTier, expiresAt, hasAnthropicApiKey }`. It reads `~/.claude/.credentials.json` and falls back to the macOS Keychain.
- **gh login**: the exit status of `gh auth status`. Exit 0 means logged in.
- **System-health snapshot**: `getSystemHealthSnapshot()` in `src/dashboard/server/services/system-health-service.ts:872`. It returns the sampler's cached assessment (no collection on call). The spawn route uses the same getter (`routes/agents/spawn.ts:457`, anchor `getSystemHealthSnapshot()`). Fields used here: `summary.availableMemoryBytes`, `thresholds.memoryAvailableWarningBytes`, `freshness.status` (`'fresh' | 'stale' | 'measuring'`).
- **Get set up card**: the new Home card (W11 → items D/E/F below). It lists first-run checks as done or to-do. It never blocks and never runs installs.
- **SetupChecklistBanner**: the existing top-of-app banner (`src/dashboard/frontend/src/components/SetupChecklistBanner.tsx`), mounted in `App/AppChrome.tsx:88`. It shows only while a *required* tool is missing.
- **Simple copy lint**: `BANNED_WORDS` in `src/dashboard/frontend/src/lib/simple/strings.ts:11-30`, enforced by `src/dashboard/frontend/src/lib/__tests__/simple-foundations.test.ts` (it flattens `SIMPLE_STRINGS` and checks every string). Banned words include `workspace`, `worktree`, `harness`, `tmux`.
- **Forgiven prerequisite**: an install prerequisite whose failure prints a warning but does not fail the `pan install` gate.
- **Required check (card)**: a card row whose failure keeps the card visible even after the user dismissed it. Defined exactly in D7.

## Problem

- `pan install` exits 1 unless Docker is running and `ast-grep` is present. The gate at `src/cli/commands/install.ts:204-207` forgives only `mkcert`, `ttyd`, `jq`, `Herdr`:

  ```ts
  allPassed: results.filter((r) => !['mkcert', 'ttyd', 'jq', 'Herdr'].includes(r.name)).every((r) => r.passed),
  ```

  On failure it prints "Fix prerequisites above before continuing." and exits 1 (`install.ts:239-243`). `ast-grep` is auto-installed later in Step 5c (`install.ts:408-431`), so failing on it is pointless. Docker is optional for Overdeck. Later Docker steps already tolerate Docker being down: Step 3 (`install.ts:291-300`) wraps `docker network create` in try/catch and warns; Step 6 (`install.ts:484-528`) only writes Traefik files inside try/catch. So relaxing the gate cannot move the failure to a later step.
- tmux is required by `pan install`, `pan doctor` (`doctor.ts:731-736`, anchor `const requiredCommands = [`), and the dashboard catalog (`system-prerequisites.ts:73`), even though Herdr is the default backend and agents do not need tmux under it.
- `pan doctor` checks that `claude` and `gh` exist but not that they are logged in.
- The dashboard has no Claude or `gh` login check on Home, and no memory hint. `SetupChecklistBanner` appears only for missing required tools and says "Agents cannot start", which is alarming copy for a first run.

## Decisions

- **D1 — First-run probes live in one lib module.** New `src/lib/first-run-checks.ts` exports `checkClaudeLogin`, `checkGhLogin`, `checkHostBackend`, each `Promise`-returning, each memoized for 60 s with a `force` option. The server report and `pan doctor` both use it. It imports nothing from `src/dashboard/`.
- **D2 — `required` is computed at report time from the host backend.** `checkSystemPrerequisites(probe?, resolver?, options?: { backend?: TerminalBackendName })`. When `options.backend` is omitted it awaits `hostTerminalBackendName()`. The catalog keeps a static `required` default; a new function `requiredFor(definition, backend)` overrides it: `tmux` → `backend === 'tmux'`; `herdr` → `backend === 'herdr'`; every other entry → its catalog value. `checkSystemPrerequisite(id, …)` (single) gets the same optional `options` argument.
- **D3 — Herdr becomes a catalog entry.** `{ id: 'herdr', name: 'Herdr', required: true, purpose: 'Hosts agent and conversation terminal sessions (the default terminal backend)', versionArgs: ['--version'], install: { linux: 'pan install', mac: 'pan install', win: 'pan install' } }`. `--version` is the flag `readHerdrVersion` uses (`src/lib/herdr-setup/binary.ts:53`). The tmux entry's `purpose` becomes `'Plain terminals (the terminal drawer); hosts agents when terminal.backend is tmux'`.
- **D4 — Report composition lives in a small server module.** New `src/dashboard/server/routes/misc/prerequisites-report.ts` exports `buildPrerequisitesReport(options: { refresh: boolean }, deps?: PrerequisitesReportDeps)`. `deps` are injectable: `checkPrerequisites`, `checkClaudeLogin`, `checkGhLogin`, `checkHostBackend`, `getHealth`. `meta.ts` becomes a thin `Effect.gen` that reads `?refresh=1` from `HttpServerRequest` (same pattern as `meta.ts:339-341`, anchor `url.searchParams.get('limit')`) and returns `buildPrerequisitesReport({ refresh })`.
- **D5 — Report shape.** The existing fields stay (`platform`, `allRequiredFound`, `checks`). New fields:

  ```ts
  auth: {
    claude: { ok: boolean; detail: string };          // from checkClaudeLogin
    gh: { installed: boolean; ok: boolean };           // from checkGhLogin
  };
  backend: {
    name: 'herdr' | 'tmux';
    available: boolean;                                // tmux: true iff the tmux check is found; herdr: probe.available
    reason: string | null;                             // probe.reason when unavailable
  };
  memory: { availableGb: number; warnGb: number; low: boolean } | null;
  ```

  `memory` is built from `getSystemHealthSnapshot()`: `availableGb = round1(summary.availableMemoryBytes / 2**30)`, `warnGb = round1(thresholds.memoryAvailableWarningBytes / 2**30)`, `low = summary.availableMemoryBytes <= thresholds.memoryAvailableWarningBytes`. It is `null` when `freshness.status !== 'fresh'` or when the getter throws. Thresholds are not changed (PAN-4267 owns them). The issue's implementation checkpoint ("locate the snapshot getter") is resolved: it is `getSystemHealthSnapshot`.
- **D6 — `?refresh=1` bypasses every 60 s memo** (`force: true` to all three first-run checks). The catalog tool checks have no memo today and keep none.
- **D7 — The card's "required" predicate.** A row is *required* when it is: a catalog check with `required: true` (after D2), the backend row (`backend.available`), or Claude login (`auth.claude.ok`). An installed-but-logged-out Claude cannot start agents, so login counts. `gh` login, Docker, the plain-terminals (tmux) row when tmux is optional, and memory are informational. The card is hidden only when `localStorage['overdeck:get-set-up-dismissed'] === '1'` **and** every required row passes. A failing required row shows the card even after dismissal.
- **D8 — Card rows.** In order: Claude login, GitHub login, agent terminals (backend), plain terminals (tmux), Docker (optional), free memory. Each to-do row has a "Set up" button that expands a copyable command and a Re-check button. Commands:
  - Claude: `claude` then `/login` (shown as two copyable lines: `claude`, `/login`).
  - GitHub: `gh auth login`. When `gh` is not installed, the catalog `gh` install hint for the platform.
  - Agent terminals: the `herdr` catalog install hint (`pan install`). Row hidden when `backend.name === 'tmux'` (the tmux row covers it then).
  - Plain terminals: the `tmux` catalog install hint for the platform.
  - Docker: the `docker` catalog install hint for the platform.
  - Memory: no command. Text "Free memory: N GB"; when `low`, add "New agents may wait for memory to free up." Row hidden when `memory === null`.
- **D9 — No growth of `doctor.ts` and `install.ts` logic.** New `src/cli/commands/doctor-first-run.ts` owns the core-command rows (git, tmux, node, claude) and the two login rows. It re-declares `CheckResult` like `doctor-herdr.ts:45-52` does, to avoid a module cycle. New `src/cli/commands/install-prereqs.ts` owns the gate: `forgivenPrereqNames(backend)` and `evaluatePrereqGate(results, backend) → { allPassed, warnings }`. `doctor.ts` replaces its `requiredCommands` loop with one call; it should shrink. If it grows past 1034 anyway, add `<lines> src/cli/commands/doctor.ts # PAN-4282` to `scripts/file-size-allowlist.txt` in the same commit.
- **D10 — Banner and card share one query cache.** Both use `queryKey: ['prerequisites']`. The card's Re-check fetches `/api/prerequisites?refresh=1` and writes the result with `queryClient.setQueryData(['prerequisites'], report)`, so the banner (on other tabs) sees the same data.
- **D11 — The banner is hidden on the Home tab.** `SetupChecklistBanner` gets an optional `activeTab?: Tab` prop and returns `null` when `activeTab === 'home'`. `AppChrome.tsx:88` passes `activeTab`. On other tabs the banner is unchanged.
- **D12 — Mount points do not wait for #4280.** Advanced Home: one JSX line directly after `</header>` in `src/dashboard/frontend/src/pages/HomePage.tsx` (header block at `:141-152`). Simple Home: one JSX line directly after `<TalkItThrough />` in `src/dashboard/frontend/src/components/simple/SimpleHomePage.tsx:259`. If #4280 has landed when this is implemented, place the card directly after `<HomeComposer … />` instead, in both files. Either way, one inserted line per file.
- **D13 — The checklist never runs installs** (matches `SetupChecklistBanner.tsx:13-15`: "Overdeck never runs the installs itself").
- **D14 — Install warnings.** For each forgiven failure, `pan install` prints a yellow line (chalk.yellow) after the status list:
  - Docker: "Docker not running — workspace containers are unavailable until it starts." (or "Docker not found — workspace containers are unavailable until it is installed." when absent)
  - ast-grep: "ast-grep missing — will be installed later."
  - tmux (Herdr backend only): "tmux missing — plain terminals in the dashboard need it (brew install tmux)." On Linux the hint is `sudo apt install tmux`.
  Forgiven failures print `⚠` in yellow instead of the red `✗` in `printPrereqStatus`.

export interface CheckOptions { force?: boolean }

- `checkClaudeLogin`: `const s = await Effect.runPromise(getClaudeAuthStatus())`. `ok = (s.loggedIn && !s.expired) || s.hasAnthropicApiKey`. `detail`: `'Signed in (<subscriptionType>)'` when logged in, `'Using ANTHROPIC_API_KEY'` when only the key is set, `'Sign-in expired'` when `loggedIn && expired`, `'Not signed in'` otherwise.
- `checkGhLogin`: `await execFileAsync('gh', ['auth', 'status'], { timeout: 5000 })`. Resolves → `{ installed: true, ok: true }`. Rejects with `code === 'ENOENT'` → `{ installed: false, ok: false }`. Any other rejection (non-zero exit, timeout) → `{ installed: true, ok: false }`. `execFileAsync = promisify(execFile)` from `node:child_process`, imported at module level so tests can `vi.mock('node:child_process')`.
- `checkHostBackend`: `name = await hostTerminalBackendName()`. When `name === 'herdr'`: `const p = await probeHerdrAvailability(); return { name, available: p.available, reason: p.reason ?? null }`. When `name === 'tmux'`: `{ name, available: options.tmuxFound ?? true, reason: available ? null : 'tmux is not installed.' }`.
- Memo: a module-level `Map<string, { at: number; value: Promise<…> }>` keyed by check name; hit when `Date.now() - at < 60_000` and `!force`. Store the promise, not the value, so concurrent callers share one probe. On rejection, delete the entry.
