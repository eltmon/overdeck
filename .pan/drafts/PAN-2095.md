# PAN-2095 — `pan reload` must build from freshly-fetched `origin/main`, never stale local HEAD

## Glossary

- **`pan reload`** — the CLI command (`src/cli/commands/reload.ts`) that builds the dashboard server from source and restarts it. Invoked by the Flywheel and by operators after a strike/PR lands on `origin/main`.
- **Primary worktree** — the main repo checkout at `~/.overdeck/...` (or wherever `pan` is installed), checked out on `main`. This is the cwd that `pan reload` inherits when run from the Flywheel or operator shell.
- **Local main** — the HEAD of the primary worktree's `main` branch. May diverge from `origin/main` due to auto-commit churn from `src/lib/pan-dir/auto-commit.ts` (PAN-2375 addresses this separately) or due to strike agents that have not been pulled.
- **`origin/main`** — the remote tracking ref. CI-green, landed changes live here. `pan reload` must build from this ref.
- **`reloadCommand()`** — the exported function in `src/cli/commands/reload.ts` (lines 77–186). It: (1) acquires a restart lock, (2) detects if `pan dev` is running (signals SIGUSR2 if so), (3) otherwise runs `runBunInstall()` + `runBuild()` in `process.cwd()`, then restarts the dashboard.
- **`runBuild()`** — at `reload.ts:59`: `return runCommand('npm', ['run', 'build'])`. `runCommand` at `reload.ts:36` uses `spawn(command, args, { stdio: 'inherit', env: process.env })` — no explicit `cwd`, so it inherits `process.cwd()`. This is the stale-source build root.
- **`post-merge-deploy.sh`** — the deploy script at `scripts/post-merge-deploy.sh`. Already implements the correct pattern: `git fetch origin main`, creates a throwaway detached worktree at `origin/main`, builds there, and swaps `dist/` into the primary repo. **This script is already correct; no changes needed here.**
- **Throwaway build worktree** — a temporary git worktree checked out at `origin/main`, used only for the build, then removed. Pattern copied from `post-merge-deploy.sh`.
- **SIGUSR2 path** — when `pan dev` is running (`readDevSupervisorMarker()` returns non-null at `reload.ts:108`), `pan reload` sends `SIGUSR2` to the dev supervisor instead of building. This is the dev-mode hot-reload path. The fix applies ONLY to the non-dev production path.

## Problem (verified 2026-07-04 from issue body)

`pan reload` runs `npm run build` inside `process.cwd()` — the primary worktree. The primary worktree's local `main` is routinely ahead of `origin/main` due to auto-commit churn (~60 `chore(beads)`/`chore(state)` commits per day from PAN-2375's target behavior). Meanwhile, landed strike fixes on `origin/main` are 1–2 commits BEHIND local `main`.

**Consequence (from issue body, run PAN-20):**
```
git rev-list --left-right --count origin/main...HEAD → origin=1..2, HEAD=61
```
Strike fix `0973c8c8d fix(spawn): honor ohmypi readiness timeout` landed on `origin/main` — `src/lib/agents.ts` `writeOhmypiAgentPrompt` timeout changed from 30s to 120s. `pan reload` was run and reported "✓ built ✓ Dashboard reloaded and healthy". But `dist/agents-*.js` still contained `timeoutSec = 30` because the build source (`process.cwd()`) did not include `0973c8c8d`.

**Verified code path** (`reload.ts`, production build path, lines 136–163):

```

`runBuild` at line 59:

`runCommand` at line 36:

No `cwd` option → inherits `process.cwd()` → builds from stale local HEAD.

**Note:** `scripts/post-merge-deploy.sh` is ALREADY CORRECT. It builds from a detached throwaway worktree at `origin/main` (lines `git fetch origin main`, `git worktree add --detach ... origin/main`, `bun install && npm run build`, `cp -a dist dist.incoming`, swap). The fix for `pan reload` copies this pattern.

## Requirements

- **FR-1** — Before building, `pan reload` must `git fetch origin main`.
- **FR-2** — If local `HEAD` equals `origin/main` (fast-forward aligned), `pan reload` may build in `process.cwd()` as before (no new worktree overhead for the common case where auto-push from PAN-2375 has already synced local main).
- **FR-3** — If local `HEAD` diverges from `origin/main` (specifically: `origin/main` has commits not in local HEAD), `pan reload` must create a throwaway detached worktree at `origin/main`, build there, and swap `dist/` into the primary repo before restarting — identical to `post-merge-deploy.sh`'s pattern.
- **FR-4** — A clear console message must be printed when the divergence is detected and the throwaway worktree path is taken: `"⚠  local main diverges from origin/main — building from origin/main sha <sha>"`.
- **FR-5** — The throwaway worktree must be cleaned up (`git worktree remove --force`) on success OR failure (try/finally).
- **FR-6** — The `pan reload --skip-build` path must not be affected (it bypasses the build entirely).
- **FR-7** — The SIGUSR2 dev path must not be affected.
- **NFR-1** — No `execSync`. Use `execAsync` (promisify of `exec`) or `spawn` with async handling for all git commands. The existing `runCommand` uses `spawn` — the new git subcommands must use an async exec pattern.
- **NFR-2** — No new explicit `any`. No files ≥1,000 lines. Reload.ts is currently 186 lines — keep the final file under 300 lines (extracting to a helper if needed).
- **NFR-3** — The throwaway worktree parent directory must be a sibling of the primary repo root (same filesystem as `post-merge-deploy.sh` uses), ensuring the `cp -a dist dist.incoming` step remains fast.

const execAsync = promisify(exec);

/**
 * Run a git subcommand in the given cwd. Returns stdout on success.
 * Throws on non-zero exit.
 */
async function runGitAsync(args: string[], cwd: string): Promise<string> {
  const { stdout } = await execAsync(`git ${args.map((a) => JSON.stringify(a)).join(' ')}`, { cwd });
  return stdout.trim();
}
```

**Step 3: Add `buildFromOriginMain()` helper.** After `runGitAsync`, add:

```ts
/**
 * Fetch origin/main, then build from a throwaway detached worktree if local
 * HEAD diverges from origin/main (i.e., origin has commits not in HEAD).
 *
 * If local HEAD == origin/main: builds in-place (repoRoot) and returns 'inplace'.
 * If origin/main is ahead: creates a sibling throwaway worktree, builds there,
 * swaps dist/ into repoRoot, removes worktree, and returns 'remote'.
 *
 * Always cleans up the throwaway worktree in finally{}.
 */
async function buildFromOriginMain(repoRoot: string): Promise<'inplace' | 'remote'> {
  // Step 1: fetch
  console.log(chalk.dim('  Fetching origin/main...'));
  await runGitAsync(['fetch', 'origin', 'main'], repoRoot).catch((e) => {
    console.warn(chalk.yellow(`  ⚠  git fetch failed (${(e as Error).message}) — building from local HEAD`));
  });

  // Step 2: compare
  let localSha = '';
  let originSha = '';
  try {
    localSha = await runGitAsync(['rev-parse', 'HEAD'], repoRoot);
    originSha = await runGitAsync(['rev-parse', 'origin/main'], repoRoot);
  } catch (e) {
    console.warn(chalk.yellow(`  ⚠  could not compare SHAs (${(e as Error).message}) — building from local HEAD`));
    const exitCode = await runBuild();
    return exitCode === 0 ? 'inplace' : (() => { throw new Error('Build failed'); })();
  }

  if (localSha === originSha) {
    console.log(chalk.dim(`  Local main is aligned with origin/main (${localSha.slice(0, 12)}) — building in place`));
    const exitCode = await runBuild();
    if (exitCode !== 0) throw new Error('Build failed — old dashboard left running');
    return 'inplace';
  }

  // Step 3: diverged — build from throwaway worktree at origin/main
  console.log(chalk.yellow(`  ⚠  local main diverges from origin/main — building from origin/main sha ${originSha.slice(0, 12)}`));
  const buildWt = join(dirname(repoRoot), `.pan-reload-build-${process.pid}`);
  try {
    await runGitAsync(['worktree', 'add', '--detach', buildWt, 'origin/main'], repoRoot);

    // bun install in the throwaway worktree
    const installExit = await runCommand('bun', ['install']);
    if (installExit !== 0) throw new Error('bun install failed in origin/main worktree');

    // Build in the throwaway worktree
    const buildExit = await new Promise<number>((resolve, reject) => {
      const child = spawn('npm', ['run', 'build'], { stdio: 'inherit', env: process.env, cwd: buildWt });
      child.once('error', reject);
      child.once('close', (code) => resolve(code ?? 1));
    });
    if (buildExit !== 0) throw new Error('npm run build failed in origin/main worktree');

    // Swap dist/ into repoRoot (same filesystem → near-atomic rename)
    const distSrc = join(buildWt, 'dist');
    const distDst = join(repoRoot, 'dist');
    const distOld = join(repoRoot, `dist.old.${process.pid}`);
    try { renameSync(distDst, distOld); } catch { /* dist may not exist yet */ }
    cpSync(distSrc, distDst, { recursive: true });
    try { rmSync(distOld, { recursive: true, force: true }); } catch { /* non-fatal */ }

    console.log(chalk.dim(`  Built from origin/main sha ${originSha.slice(0, 12)}, dist swapped.`));
    return 'remote';
  } finally {
    // Always clean up the throwaway worktree
    try {
      await runGitAsync(['worktree', 'remove', '--force', buildWt], repoRoot);
    } catch { /* best-effort */ }
    try { rmSync(buildWt, { recursive: true, force: true }); } catch { /* best-effort */ }
  }
}
```
