## Summary

Advanced modes, the Get set up card), Board, Pipeline, Awaiting Merge, the issue drawer and the full
issue view, Activity, Knowledge, Context, Skills, Settings, and the Experimental features switch with
the exact list of views it reveals. Add the page to `docs.json`, replace or link from the stale
"13 views" table in `introduction.mdx`, and add one cross-link line to five related pages.

Every fact in this PRD was read from the current code on 2026-11-18 (workspace on `main` at
`c5235aaecfb`, package version 0.88.x). Line numbers drift fast in this frontend, so every reference
also carries a grep anchor. **The work agent must re-grep each anchor before writing the sentence

## Glossary

- **View**: one top-level dashboard page, selected by a `Tab` id and a URL path. The map lives in
  `src/dashboard/frontend/src/App/routes.ts` (`export const TAB_PATHS: Record<Tab, string>`).
- **Left nav**: the navigation in the dashboard's left column, `components/frame/LeftNav.tsx`. It has
  four entries: `Project home`, `Flywheel`, `Order books`, and a `More` menu.
- **More menu**: the dropdown under `More` that lists every other view in four groups
  (`components/frame/navGroups.ts`, `export const MORE_GROUPS`).
- **Experimental features switch**: the `Experimental features` toggle in Settings, section
  `Experimental`. It writes `experimental.experimentalFeatures` in the settings config.
- **Experimental view**: a view whose tab id is in `EXPERIMENTAL_TAB_IDS`
  (`src/dashboard/frontend/src/lib/experimentalFeatures.ts`). It is hidden from the More menu and
  unreachable by URL while the switch is off.
- **Home**: the global landing page at `/`. Not the same thing as **Project home** (below).
- **Project home**: the Home pane of one project's Command Deck, reached from the left nav entry
  `Project home` or `/command-deck/<project>`.
- **Simple / Advanced**: the two Home modes. A per-browser setting stored in localStorage.
- **Issue drawer**: the slide-over panel that opens over the current view when you click an issue.
- **Full issue view**: the same issue content as a Command Deck tab at
  `/command-deck/<project>/<issue>`.
- **Mint check**: `npx -y mint@4.3.49 validate` and `npx -y mint@4.3.49 broken-links`, run from the
  workspace root. Always pin `mint@4.3.49` (the version PAN-5483 standardized on). Never run
  `mint validate --fix`: it rewrites about 80 files that sibling issues edit in parallel.
- **Dash rule**: no em dash (U+2014) or en dash (U+2013) anywhere this issue writes, including the
  frontmatter `title`, `sidebarTitle` and `description`, and every body line added or edited.

Paths below are relative to `src/dashboard/frontend/src/` (written `FE/`) unless they start with a
repo-root directory such as `docs/`, `features/` or `src/cli/`.

  issue forward, use its actions (Plan, Start work, and so on).

### The Experimental features switch

- Settings → `Experimental` (last section, `FE/components/Settings/sections/ExperimentalSection.tsx`,
  intro `Research-preview features that may change or be removed without notice.`). Four toggles:
  `Experimental features`, `RTK Bash compression`, `Claude Code Channels`, `Streamdown renderer`.
  This page documents only `Experimental features`; name the other three in one sentence.
- `EXPERIMENTAL_TAB_IDS` (`FE/lib/experimentalFeatures.ts`) = agents, autopreso, resources, sessions,
  metrics, costs, health, god-view. Mapped to menu labels: **Agents, AutoPreso, Resources, Sessions,
  Metrics, Costs, Health, God View**.
- What each revealed view shows (one line each on the page):
  - Agents (`/agents`): running agents, what needs you, and what waits in the pipeline;
    `?view=history` opens the Agents Directory (link `/reference/agents-directory`).
  - AutoPreso (`/autopreso`): a voice-driven drawing canvas with a live transcript.
  - Resources (`/resources`): containers and agents grouped by issue, type or status.
  - Sessions (`/sessions`): heading `Session History`, searchable index of past harness sessions.
  - Metrics (`/metrics`): heading `Metrics Dashboard`.
  - Costs (`/costs`): heading `Cost Tracking`, costs by issue, model and stage.
  - Health (`/health`): `Host health` and `Agent health`.
  - God View (`/god-view`): a live activity river across agents (link `/reference/god-view`).
- Activity is not in the list but loses its `Activity Log`, `Detailed` and `TTS` streams while the
  switch is off (`FE/components/ActivityPanel.tsx`, `const streams = experimentalFeaturesEnabled ?`).
- With the switch off, a direct URL to an experimental view (or a command palette entry such as
  `View Agents`, or the `G A` shortcut) lands on Home instead (`FE/App.tsx`, anchor
  `denyExperimental && isExperimentalTab(tab) ? 'home' : tab`).
- **Always visible regardless of the switch:** Flywheel, Order books, Backlog, Board, Pipeline,
  Awaiting Merge, Activity (Feed), Deacon, Knowledge, Skills, Context, Settings.
- The toggle's own description in Settings names Activity and Skills as experimental. That text is
  wrong (see Non-goals). The page states once, plainly, that Activity and Skills stay available with
  the switch off.
