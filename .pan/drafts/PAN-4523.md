# PAN-4523 — God View river: shelf and doldrums labels overprint, merged issues stick on the shelf, PLAN/REVIEW counters count stopped agents

**Issue:** [PAN-4523](https://github.com/eltmon/overdeck/issues/4523)
**Scope:** God View frontend only (`src/dashboard/frontend/src/components/GodView/confluence/`), its tests, `docs/GOD-VIEW.md`, and one Playwright spec. No server, `src/lib`, or `merge-agent.ts` change.
**Planned against:** `feature/pan-4523` at `3ea68b0e9cc`.

## Glossary

- **River** — the canvas drawn by `RiverCanvas.tsx`. Five stage columns (PLAN · WORK · REVIEW · TEST · MERGE) between `layout.riverTop` and `layout.riverBottom`, and two horizontal bands below them.
- **Orb** — one issue on the river (`ConfluenceOrb` in `useConfluenceData.ts`). Its `state` is one of `'active' | 'shelf' | 'stale' | 'failed'` (`OrbState`, `model.ts`).
- **Shelf** — the upper band below the river. Orbs with `state === 'shelf'` sit here: paused agents, scheduler/governor yields, operator holds.
- **Doldrums** — the lower band. Orbs with `state === 'stale'` (idle ≥ 30 min, or parked via `/api/parked`) sit here in two staggered rows.
- **Band** — a horizontal y-range `[top, bottom]` on the canvas. A band holds its header text, its orbs, and its orbs' text.
- **Header** — the right-aligned band title (`⏸ SHELF — …`, `❄ DOLDRUMS — …`) drawn in `drawZones`.
- **Orb label** — the id text drawn above or below an orb (`⏸ PAN-12`, `❄ PAN-12 · zombie 3h`).
- **Shelf reason** — `orb.yieldReason`, the pause reason text drawn next to a shelf orb.
- **Slot width** — the horizontal space allotted to one orb's text: the distance between neighbouring orbs in the same row, minus a margin.
- **Close-out pause** — the pause `merge-agent.ts` writes on `agent-*`, `planning-*` and `strike-*` agents after a merge, with reason `'awaiting close-out (verify on main)'` (`src/lib/cloister/merge-agent.ts` line 349, grep `const reason = 'awaiting close-out (verify on main)'`).
- **Derived state** — `DerivedIssueState.state` (`DerivedIssueStateName`), the server-derived issue state. `'merged'` maps to the `ship` phase and so to the MERGE column (`PHASE_BY_DERIVED_STATE` in `src/dashboard/frontend/src/lib/pipeline-state.ts` line 18: `merged: 'ship'`; `STAGE_BY_PHASE.ship = 'MERGE'` in `useConfluenceData.ts`).
- **Merge exit** — the animation that pushes an `active` MERGE orb into the portal and retires it (`advance()` in `RiverCanvas.tsx`, grep `if (orb.state === 'active' && orb.stage === 'MERGE')`).
- **Live agent** — an agent whose status satisfies `activeStatus()` (`'running' | 'starting'`, `useConfluenceData.ts` line 215) after `withObservedLiveness` has demoted pane-less rows to `stopped` (`liveness.ts`).

## Problem and verified root cause

All three defects were reproduced by reading the code at `3ea68b0e9cc`.

### P1 — Shelf and Doldrums text overprint

- The live layout is `canvasLayout` in `RiverCanvas.tsx` lines 170-189 (private, grep `function canvasLayout(width: number, height: number): LayoutRect`). With `H` = canvas height:
  - `riverBottom = H - 120`
  - shelf band = `shelfY ± shelfH/2` = `[H-108, H-74]`
  - doldrums band = `doldrumsY ± doldrumsH/2` = `[H-76, H-12]` → the bands overlap at `[H-76, H-74]`.
- Upper-row stale orbs sit at `doldrumsY - 11` = `H-55` (`model.ts` line 208, grep `orb.ty = layout.doldrumsY + (index % 2 ? 13 : -11);`). Their label baseline is `orb.y - orb.radius - 8` (`drawLabel`, `RiverCanvas.tsx` line 551) ≈ `H-77`, which is inside the shelf band.
- The doldrums header is drawn at `doldrumsTop + 11` = `H-65` (`RiverCanvas.tsx` line 498), on the same strip as those labels.
- The shelf reason is drawn at `orb.y - orb.radius - 21` (`RiverCanvas.tsx` line 574) ≈ `H-126`, above `riverBottom`, inside the river.
- Shelf orbs are spread over `width * 0.5` (`model.ts` lines 221-222), about 140 px apart at six orbs, while a reason may be 58 characters (≈ 300 px at 8.5 px mono). Nothing measures text, and nothing caps the shelf population.
- `computeLayout` in `model.ts` lines 105-126 is a second, different layout that only `model.test.ts` calls. The tests therefore check numbers the canvas never uses.

### P2 — Merged issues stick on the shelf

- `classifyOrb` (`model.ts` line 166) returns `'shelf'` first whenever `paused === true`:
  ```ts
  if (input.paused === true || input.yieldedByScheduler === true) return 'shelf';
  ```
- After a merge, `merge-agent.ts` pauses the issue's agents with the close-out reason. The issue's derived state becomes `'merged'`, so `orbStage` puts the orb in MERGE, but `classifyOrb` makes it `'shelf'`.
- The merge exit runs only for `state === 'active'` (`RiverCanvas.tsx` line 654). A shelf orb never exits.
- Bypassing only the shelf branch is not enough. Close-out-paused agents stop producing events, so `lastActivity` is soon ≥ 30 min old and the next branch returns `'stale'`, which drops the orb into the Doldrums instead. The rule must return `'active'`.

### P3 — Stage counters count stopped agents

`orbStage` in `useConfluenceData.ts` lines 308-314:

```ts
function orbStage(agents: readonly AgentSnapshot[], derived: DerivedIssueState | undefined): Stage {
  const stage = STAGE_BY_PHASE[getPipelineIssuePhase(derived ?? null)];
  if (stage === 'REVIEW' && agents.some((agent) => agent.role === 'test')) return 'TEST';
  if (stage === 'WORK' && agents.some((agent) => agent.role === 'plan')) return 'PLAN';
  if (stage === 'WORK' && agents.some((agent) => agent.role === 'review' || agent.id.includes('-review'))) return 'REVIEW';
  return stage;
}
```

`agents` includes stopped rows. A finished planner plus a running work agent counts as PLAN. The column counter (`RiverCanvas.tsx` line 521, `inLane = orbs with stage === stage && state === 'active'`) then shows "PLAN 3" with no planner alive. Line 312 has the same defect for review, and line 310 for test — the block comment above `STAGE_BY_PHASE` already says the review lane splits only "when a test agent is live".

## Requirements

### Functional

- **FR-1** The shelf band and the Doldrums band have disjoint y ranges with a gap of at least 8 px, at every canvas height ≥ 600, and the Doldrums band ends at least 30 px above the canvas bottom so the bottom HUD (`.confluence-tag` / `.confluence-hint`, `confluence.css` lines 158-170: `bottom: 8px`, the hint ≈ 21 px tall with its 5 px padding) never covers band text.
- **FR-2** Every text the river draws for the shelf and the Doldrums — both headers, every shelf and stale orb label, every shelf reason — has its baseline inside its own band (`top + fontSize ≤ baseline ≤ bottom - 2`). No shelf or Doldrums text is drawn above `riverBottom`.
- **FR-3** Shelf orb labels, shelf reasons and stale orb labels are truncated with an ellipsis, using the canvas's measured text width, so that no drawn string is wider than its orb's slot width.
- **FR-4** At most `SHELF_ORB_LIMIT = 8` shelf orbs render, the longest-idle first; the rest are dropped from the cast the same way `STALE_ORB_LIMIT` drops stale orbs. The canvas drops a shelf or stale orb at once when it leaves the cast (no one-second fade), so an eviction never draws a ninth shelf orb or a fifteenth stale orb.
- **FR-5** `model.ts` exports exactly one layout function, `computeLayout`, and `RiverCanvas.tsx` uses it. `canvasLayout` no longer exists.
- **FR-6** An issue whose derived state is `'merged'`, and whose only pauses (if any) are the close-out pause, classifies as `'active'` — never `'shelf'` and never `'stale'` — so it flows into MERGE and exits through the portal. Any other pause or scheduler yield on a merged issue still shelves it.
- **FR-7** The shelf header reads `⏸ SHELF — paused / parked / yielded`, the bottom tag reads `shelf = paused / yielded`, and the field guide's shelf paragraph names operator holds as well as yields.
- **FR-8** A stopped `plan`, `review` or `test` agent does not pull its issue into PLAN, REVIEW or TEST. Only a live agent (`activeStatus(agent.status)`) does.
- **FR-9** `docs/GOD-VIEW.md` states what lands on the shelf, what lands in the Doldrums, and that merged issues exit through MERGE even while their agents carry the close-out pause.

- **NFR-2** `RiverCanvas.tsx` (790 lines) and `useConfluenceData.ts` (889 lines) stay at or below the 1000-line ceiling enforced by `scripts/lint-file-size.sh`. Net growth is expected to be small; if a file would cross 1000, extract a helper into `model.ts` instead. Never raise `scripts/file-size-allowlist.txt`.

- **NFR-5** The Playwright verification runs against an isolated dashboard (`startIsolatedDashboard`, its own temp `OVERDECK_HOME` and port) in its own browser context — never the operator's live dashboard on `:3011`, never a shared Playwright session.

  /** Text width allotted to one shelf orb: neighbour spacing minus SLOT_MARGIN. */
  export function shelfSlotWidth(layout: LayoutRect, shelfCount: number): number;

  It returns `'active'` (not merely "not shelf") so the stale branch cannot catch the orb. A merged issue with no pause also returns `'active'`: a merged issue has nothing left to stall on, and the merge exit is the only correct way off the river.

- **D10 — Merge exit timing is safe.** An `active` MERGE orb with a large `idleMin` reaches frost 1 at once and would sink to the Doldrums after `FROST_SINK_HOLD_SECONDS` (6 s). `mergeDwell` is 1.5–3.5 s and `advance()` checks the merge dwell before frost accrual, so the merge starts first.
