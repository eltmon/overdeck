## Glossary

- **W-DOC:** the documentation work item in `.pan/drafts/pan-4927.md` (lines 843-863). AC-30: "every file in W-DOC is changed as listed, the two new pages are in `docs.json`, and `npm run lint` passes."
- **Mintlify page:** an `.mdx` (or `.md`) file at the repo root, under `configuration/`, `cli/`, `reference/` and so on, published when listed in `docs.json` `navigation.tabs[].groups[].pages`.
- **`lint:docs`:** `node scripts/lint-docs.js` (part of `npm run lint`). It fails when a `docs.json` page has no file, when a published page has a `$` in prose outside inline code, or a bare `<` directly before a digit in prose, and when a `docs/*.md` file is empty or lacks a final newline.
- **Agent token:** a `kind: 'token'` access-token record with `agentId`, `agentKind` and `role`, minted for each managed agent (`src/lib/mcp/agent-token.ts`). Its name is `agent:<role>:<agentId>` (`agent-token.ts:120`).
- **OAuth token:** a `kind: 'token'` record with `oauthClientId`, `oauthFamilyId` and `expiresAt`, issued by the `/oauth/mcp/*` flow. Its name is `<client name> (OAuth)` (`src/lib/mcp/oauth-service.ts:211`).
- **Overdeck connector:** `pan mcp connector serve` (`src/lib/mcp/connector/`), a Node process next to a self-hosted bot that pairs with one machine and serves the MCP tools on `http://127.0.0.1:7466/mcp`.
- **Public MCP:** the opt-in switch `mcp.public.enabled` that lets Tailscale Funnel reach `/mcp`, `/.well-known/*` and `/oauth/mcp/*` on port 8443 (`src/lib/mcp/public-mcp.ts:19-31`).
- **D-13 matrix:** which harness gets the `overdeck` MCP server and which gets the CLI instructions block (parent PRD D-13; code: `packages/contracts/src/harness-capabilities.ts` `overdeckMcp`, `src/lib/mcp/overdeck-mcp-gate.ts:15-19`).
- **CP-n:** an implementation checkpoint from the parent PRD ("Implementation checkpoints", line 865).
