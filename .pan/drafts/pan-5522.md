# PAN-5522: Add GPT-6.2 Astra and GPT-6.2 Sol to the model catalog

**Issue:** https://github.com/eltmon/overdeck/issues/5522 · **PR:** https://github.com/eltmon/overdeck/pull/5530

This PRD is retroactive. A supervised handoff implemented the change in commit `ca4b99b02da` before any plan existed. It records that diff so the xBRIEF checklist matches the PR.

## Glossary

- **272K billing tier:** OpenAI bills input over 272K tokens at a higher rate for the whole request. Overdeck pins GPT-6 sessions to `CLIPROXY_GPT56_CONTEXT_WINDOW` (272000) to stay under it (PAN-3388).
- **Codex floor:** the oldest Codex CLI that OpenAI accepts for a model under ChatGPT sign-in (`src/lib/codex/model-floors.ts`, PAN-4363).
- **CLIProxy route:** the claude-code harness reaching GPT models through the local CLIProxy sidecar. `GPT_56_MODELS` in `src/lib/agents/provider-env.ts` lists the models pinned to 272K on that route.

## Facts (verified 2026-11-18)

- Codex CLI 0.170.0 `codex debug models` lists `gpt-6.2-astra` (context_window 272000) and `gpt-6.2-sol` (context_window 500000). Both have max_context_window 872000 and supported_in_api true.
- developers.openai.com/api/docs/pricing, per 1M tokens: astra $8 input, $0.40 cached, $40 output (over 272K: $16/$0.80/$60). Sol $2/$0.10/$10 (over 272K: $4/$0.20/$15).
- CLIProxy v8.0.71 (the pinned version) listed both in `GET /v1/models` and returned a completion for each through `POST /v1/messages`.

## Requirements

- **FR-1:** Both models have capability entries on the openai provider, pinned to 272K, with efforts low, medium, high, xhigh and max, and capability class `frontier`.
- **FR-2:** Both models appear in the provider, settings, fallback and settings-catalog lists, with 6.2 first in the OpenAI order.
- **FR-3:** `getPricing` returns the published standard-tier prices for both models.
- **FR-4:** Under ChatGPT sign-in, a Codex launch of either model below CLI 0.170.0 is refused with the version named, and `pan doctor` shows a floor row for each.
- **FR-5:** The claude-code CLIProxy route pins both models to 272K.
- **FR-6:** The dashboard Settings catalog, model picker and friendly names show both models.
- **FR-7:** User docs and the changelog describe both models.
- **NFR-1:** No default model, role routing or harness routing changes.
