# PAN-5408 — D2 live-check fixes: the full diff window lists the conversation's own changes, Escape closes the tab-strip menus

**Issue:** [PAN-5408](https://github.com/eltmon/overdeck/issues/5408) · **Parent epic:** [PAN-5284](https://github.com/eltmon/overdeck/issues/5284) · **Found in:** live check of D2 ([PAN-5295](https://github.com/eltmon/overdeck/issues/5295), build `8bffa471f86`)

Two independent defects. Slice A is server-side (the `/diffs/full` route). Slice B is one frontend component (`PaneBar`). They share no files.

## Glossary

- **Diff window** — the standalone `/popout/diff?…&prefix=/api/conversations/<name>/diffs` page that ⋯ → **Full diff in a new window** opens (`src/dashboard/frontend/src/components/chat/diffWindow.ts`, `conversationDiffWindowUrl`). It renders `DiffPanel` (`src/dashboard/frontend/src/components/DiffPanel.tsx`).
- **All turns** — the diff window's default view. `DiffPanel` fetches `${prefix}/full` (DiffPanel.tsx, the `queryFn` that builds `` `${baseUrl}/full` ``). The file list is the response's `files`; picking a file refetches with `?file=<path>` and renders the response's `diff`.
- **cwd repo** — the git top-level of the conversation's `cwd` (`repoRootForDir(conv.cwd)` in `src/lib/overdeck/conversation-diffs.ts`).
- **Other repos** — repositories other than the cwd repo that the transcript's edit records touched (`fileEditsByAssistantId`). Their handling is unchanged by this issue.
- **Attribution / attributed files** — child A's answer to "what did this conversation change" (PAN-5288): `getConversationChanges(name, { scope: 'conversation' }, deps)` in `src/lib/overdeck/conversation-changes.ts`, served at `GET /api/conversations/:name/changes?scope=conversation`. Its `commits[].files[]` are commits tied to the conversation by an `Overdeck-Conversation: <tmuxSession>` trailer or by its own `git commit` tool output; its `uncommitted[]` are working-tree files the transcript's edit records touched. **The attributed file set** is the union of `commits[].files[].path` and `uncommitted[].path`. All paths are relative to the cwd repo's top level (`git diff-tree` / `git status -C <repoRoot>`).
- **Base commit** — the commit the All turns patch diffs the working tree against (`git diff <base> -- <paths>`).
- **Net numstat** — `git diff --no-renames --numstat <base> -- <paths>` (helper `diffFilesSinceBase` in conversation-diffs.ts).
- **Untracked file** — a working-tree file git does not track. `git diff <base>` never shows it; attribution lists it in `uncommitted[]` with `status: 'A'`.
- **Tab-strip menus** — the two portaled menus in `src/dashboard/frontend/src/components/Stage/PaneBar.tsx`: the **+** create menu (`menu.kind === 'add'`, trigger `aria-label="Open new tab"`) and the **N tabs ▾** list (`menu.kind === 'tabs'`, `role="menu" aria-label="All tabs"`, trigger `aria-label="<N> tabs, list all tabs"`).

## Problem

### Defect 1 — All turns lists the whole repository's changes

`getConversationDiffFull` (`src/lib/overdeck/conversation-diffs.ts`, search `export async function getConversationDiffFull`) diffs the **entire** cwd repo since the conversation started:

```ts
    if (cwdRepoRoot) {
      const baseCommit = await findCommitAtTime(cwdRepoRoot, conv.createdAt);
      if (baseCommit) {
        const patch = await diffPatchSinceCommit(cwdRepoRoot, baseCommit, fileFilter, options);
        if (patch) patches.push(patch);
        addFiles(await diffFilesSinceBase(cwdRepoRoot, baseCommit, []));
      }
    }
```

`diffFilesSinceBase(..., [])` with an empty pathspec means "the whole repository" (the PAN-4501 comment in that helper says so explicitly). For a conversation whose cwd is the main checkout, that is every agent's commit on main since the conversation began: the live check saw **2058 files** for conversation `20261113-6031`, while the dock's Changes tab (attribution) showed **9**.

### Defect 2 — Escape does not close the tab-strip menus

`PaneBar`'s open-menu effect (PaneBar.tsx, search `if (!menuOpen) return`) closes the menu on outside `mousedown`, `resize` and outside `scroll`, but registers no `keydown` handler. Focus stays on the trigger button after a click-open (the menu items are never focused), so nothing handles Escape. The menu stays open and keeps covering the header.

## Requirements

- **FR-1** For the cwd repo, `GET /api/conversations/:name/diffs/full` returns in `files` exactly the attributed file set — the same paths as `GET /api/conversations/:name/changes?scope=conversation` (`commits[].files[].path` ∪ `uncommitted[].path`), no more, no fewer.
- **FR-2** For the cwd repo, the `diff` patch of `/diffs/full` contains only attributed paths. With `?file=<path>`, it contains only that path, and is empty when `<path>` is not attributed.
- **FR-3** The base commit for the cwd repo is `findCommitAtTime(cwdRepoRoot, T)` where `T` is the earlier of `conv.createdAt` and (the earliest attributed commit's `authoredAt` minus 1 second), so an attributed commit made before the conversation row was created is still inside the diff.
- **FR-4** Each `files` entry for the cwd repo takes `kind`/`additions`/`deletions` from the net numstat when the path appears there; otherwise from attribution (stats summed across that path's commit and uncommitted records, `kind` = the first record's `status`). A path is never dropped because its net diff is empty.
- **FR-5** An attributed untracked file appears in the All turns patch as a new-file patch (`--- /dev/null`, `+++ b/<path>`, every line added), so selecting it in the diff window renders its content.
- **FR-6** Other repos keep today's behavior (edit-record paths only), and `/diffs` (per-turn summaries), `/diffs/:turnId`, `/diffs/vs-main` and `/api/diffs/compare` are unchanged.
- **FR-7** Pressing Escape while the **N tabs ▾** list is open closes it and moves focus to the **N tabs** trigger button.
- **FR-8** Pressing Escape while the **+** menu is open closes it and moves focus to the **+** trigger button.
- **FR-9** The docs state what All turns lists and that Escape closes both menus (WI-4).
- **NFR-1** No import cycle: `conversation-diffs.ts` must not import `conversation-changes.ts` (which already imports it); `npm run lint:circular` stays green.
- **NFR-2** Server code stays async-only (`exec`/`execFile` promisified, never `execSync`) — the dashboard server calls these functions (repo rule: no `execSync` in server-reachable code).
- **NFR-3** No file grows past its file-size ceiling (`scripts/lint-file-size.sh`, ceiling 1000 lines; `conversation-diffs.ts` is 461 lines, `PaneBar.tsx` 316).

## Decisions (made here; the executor does not re-decide)

- **D-1 Pure attribution, always.** The cwd repo's All turns list is the attributed set for every conversation, including one in its own worktree. Files changed only by shell commands without a trailer commit, and changes from harnesses that write no edit records, drop out of All turns. They remain visible under **vs main** and **Compare…**. Rationale: the issue's acceptance test demands the attributed set exactly, and the dock's Changes tab already uses that set; one definition of "this conversation's changes" beats two. The issue's sentence "for a conversation in its own worktree the result is the same as today" is read as an observation (its own worktree's changes are normally all attributed), not a separate requirement.
- **D-2 Dependency injection, not a new import.** `getConversationDiffFull` takes a new deps type `ConversationDiffFullDependencies` (extends `ConversationDiffDependencies` with `conversationChanges(name)`). The route wires it to the real `getConversationChanges`. The shared `ConversationDiffDependencies` type is **not** changed, so `getConversationDiffs` / `getConversationDiffTurn` callers are untouched.
- **D-3 Base time** as in FR-3. `findCommitAtTime` uses `git rev-list -1 --before=<T> HEAD` (committer date); a null base falls back to diffing against `HEAD` exactly as `diffPatchForFiles` already does.
- **D-4 Stats source** as in FR-4 (net numstat first, attribution fallback). An attributed file whose net diff is empty stays listed; picking it shows DiffPanel's existing "no net changes" state.
- **D-5 Unattributed `?file=`** returns `diff: ''` for the cwd repo (other repos still contribute their filtered patch) and the unfiltered attributed `files` list, as today's filter does.
- **D-6 Failure** of `deps.conversationChanges` propagates to the existing `catch` (500 `Internal server error`). A non-200 changes response maps to `null`, which means an empty attributed set (files `[]` for the cwd repo). Never fall back to the whole repository.
- **D-7 Escape handler location:** a `document` `keydown` listener inside PaneBar's existing open-menu effect (the `PaneTabMenu.tsx` pattern), guarded by `!e.defaultPrevented`, calling `preventDefault()`, `setMenu(null)` and `.focus()` on the trigger of the menu that was open. Not `MenuSurface`: it restyles the menu and autofocuses the first item, which is a visual change outside this issue. No Stage-level or registry shortcut binds Escape (`src/dashboard/frontend/src/lib/shortcuts/` has no Escape binding), so nothing else consumes this keystroke.

```ts
/** PAN-5408: the attributed file set, keyed by repo-relative path, stats summed per path. */
export function attributedFiles(changes: ConversationChanges | null): Map<string, TurnDiffFileChange> {
  const files = new Map<string, TurnDiffFileChange>();
  if (!changes) return files;
  for (const file of [...changes.commits.flatMap((commit) => commit.files), ...changes.uncommitted]) {
    const prev = files.get(file.path);
    files.set(file.path, {
      path: file.path,
      kind: prev?.kind ?? file.status,
      additions: (prev?.additions ?? 0) + file.additions,
      deletions: (prev?.deletions ?? 0) + file.deletions,
    });
  }
  return files;
}

/** PAN-5408 FR-3: the earlier of the conversation start and 1 s before its earliest attributed commit. */
function attributionBaseTime(conv: Conversation, changes: ConversationChanges | null): string {
  let earliest = Date.parse(conv.createdAt);
  for (const commit of changes?.commits ?? []) {
    const ms = Date.parse(commit.authoredAt) - 1000;
    if (Number.isFinite(ms) && (!Number.isFinite(earliest) || ms < earliest)) earliest = ms;
  }
  return Number.isFinite(earliest) ? new Date(earliest).toISOString() : conv.createdAt;
}
```

```ts
/** PAN-5408 FR-5: a new-file patch for an untracked path; `git diff --no-index` exits 1 when the files differ. */
async function untrackedFilePatch(repoRoot: string, path: string, options: DiffOptions = {}): Promise<string> {
  try {
    const { stdout } = await promisify(execFile)(
      'git',
      ['diff', '--no-index', '--patch', '--minimal', '--no-color', ...diffOptionArgs(options), '--', '/dev/null', path],
      { cwd: repoRoot, encoding: 'utf-8', maxBuffer: 50 * 1024 * 1024 },
    );
    return stdout;
  } catch (error: unknown) {
    const stdout = (error as { stdout?: unknown }).stdout;
    return typeof stdout === 'string' ? stdout : '';
  }
}
```

## Non-goals

- Changing `/diffs/:turnId`: without `?file` it still returns the whole cwd-repo patch since the conversation start. `DiffPanel` never requests it that way (it skips the turn fetch until a file is picked), so the window is unaffected.
- Changing the per-turn summaries (`/diffs`), which stay edit-record based.
- Removing other agents' hunks from a file both this conversation and another agent changed: the All turns patch for an attributed file is its full net diff since the base. Line-level filtering is out of scope.
- Changing `/diffs/vs-main`, `/api/diffs/compare`, the dock's Changes tab, or the agent diff routes (`/api/agents/:id/diffs/*`).
- Migrating PaneBar's menus to `MenuSurface` (arrow-key navigation, item autofocus, restyle).
- Arrow-key navigation inside the tab-strip menus.
