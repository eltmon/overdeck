Add Claude Fable 5.2 everywhere Overdeck knows Claude models: the model ID union, the capability table (with its Claude Code minimum), provider maps, cost tables, the session cost parser, the compaction budget, the dashboard friendly name, the three dashboard model pickers, the docs and the changelog. ## Glossary

- **Fable 5.2** — Anthropic model `claude-fable-5-2`, released 2026-11-09. 1M context, 128K max output (synchronous API). Prices per million tokens: input $8, output $40, 5-minute cache write $10, 1-hour cache write $16, cache read $0.20; batch $4/$20. Adaptive thinking is always on; API default effort `high`, Claude Code default `medium`; effort levels `low`/`medium`/`high`/`xhigh`/`max`. Forced `tool_choice` (`any`/`tool`) and sampling parameters (`temperature`, `top_p`, `top_k`) return HTTP 400. Fast mode is a request field `speed: "fast"` priced $16/$80 (Foundry alone uses deployment `claude-fable-5-2-fast`). Bedrock ID `anthropic.claude-fable-5-2`. Sources: https://platform.claude.com/docs/en/models/fable-5-2/overview, https://platform.claude.com/docs/en/about-claude/pricing, https://platform.claude.com/docs/en/build-with-claude/fast-mode.
- **Fable 5.1** — `claude-fable-5-1`, the previous Fable: $10/M input, $50/M output, $0.25/M cache read, minimum Claude Code 2.1.255. Stays selectable.
- **Capability table** — `MODEL_CAPABILITIES` in `src/lib/model-capabilities.ts`. It spreads `AUDITED_MODEL_ADDITIONS` from `src/lib/model-capability-additions.ts` first, so the order of entries in the additions file is the order of the Anthropic list in the Settings catalog API. New models land in the additions file.
- **`ModelId`** — TypeScript union in `src/lib/settings.ts`; `AnthropicModel` (line 6) is one member. Adding an ID forces an entry in every `Record<ModelId, …>` map: `MODEL_CAPABILITIES` and `MODEL_PROVIDERS` (`src/lib/model-fallback.ts`, line ~21). Typecheck fails until both have the key.
- **`minClaudeCodeVersion`** — field on a capability row (`src/lib/model-capability-types.ts:76`). `prepareHarnessLaunch` (PAN-4359, `src/lib/claude-code/requirements.ts`) refuses a `claude-code` launch whose installed Claude Code is older, and the dashboard shows an upgrade banner while any *configured* model's minimum is unmet. No other wiring is needed (`docs/RELEASING.md`, "Adding a model that needs a newer Claude Code").
- **Blended cost** — `costPer1MTokens`, the equal input/output average used by pickers: (8 + 40) / 2 = **24** for Fable 5.2 (Fable 5.1: (10 + 50) / 2 = 30).
- **Settings catalog API** — `getAvailableModelsApi()` in `src/lib/settings-model-catalog.ts`. It builds each row's name as `<displayName> (<context> context)`, so `displayName: 'Claude Fable 5.2'` with `contextWindow: 1000000` yields `Claude Fable 5.2 (1M context)`.
- **No-loss catalog fixture** — `src/lib/__tests__/fixtures/pre-opencode-model-catalog.json`, compared by `src/lib/__tests__/settings-model-catalog.test.ts` after filtering out post-fixture additions in `withoutOpus55()`. New models are added to that filter, never to the fixture.
- **Cost hook bundle** — `sync-sources/hooks/record-cost-event.js`, a committed 1 MB bundle rebuilt only by `npm run build:scripts` (kept off the default build, PAN-2699). It is stale (see Verified fact 7).

## Decisions

1. **`minClaudeCodeVersion: '2.1.321'`** (Verified facts 1–5). The issue's own rule picks the oldest version without `unrecognized_model` and with a 1M window; 2.1.319 still prints `unrecognized_model`.
2. **Do not rebuild the cost hook bundle in this PR** (Verified fact 7). Rebuilding produces a 1 MB diff that pulls in every `src/lib` change since 2026-10-01, which is unrelated to this issue and is the subject of PAN-2699. The issue's cost acceptance is satisfied by `src/lib/cost.ts` and its tests, which the reconciler and every dashboard read path use. Follow-up: [PAN-5104](https://github.com/eltmon/overdeck/issues/5104).
3. **No default flips** (Verified fact 6). Only the comment in `presets.ts:168` and the rationale in `model-presets.mdx:105` change. Fable 5.2 costs 2× Opus 5.5 ($8/$40 against $4/$20) and has no Overdeck eval, so the `expensive` slot stays on Opus 5.5. This follows the rule "never hardcode a model fallback": no new literal is added anywhere a default is resolved.
4. **Host Claude Code upgrade is not a work-agent step.** The issue asks to upgrade this host's Claude Code only through the existing PAN-4359 path. That is a host-wide side effect outside the workspace, the PR's tests do not depend on it, and no configured model needs it (Decision 3). The operator or Flywheel does it after merge with the dashboard **Upgrade Claude Code** button or the command the refusal prints. The work agent must not run `npm install -g @anthropic-ai/claude-code`.
5. **Fable 5.2 row goes directly before `'claude-fable-5-1'` in `AUDITED_MODEL_ADDITIONS`,** so it is the first Anthropic row in `getAvailableModelsApi()` (Glossary, Capability table).
6. **Friendly names cover the whole Fable family** (5.2, 5.1, 5). Adding only 5.2 would leave 5.1 and 5 rendering as raw IDs right beside it. This is display-only.
7. **Compaction budget: add Fable 5.2 only.** Adding a Fable 5.1 row would change 5.1's existing compaction behavior, which this issue does not ask for.
8. **Fast mode is out of scope.** `includes('fable-5-2')` also folds a Foundry `claude-fable-5-2-fast` deployment into standard pricing; this is accepted. The capability `notes` mention fast mode and its price.
9. **Changelog:** add an `Unreleased` v0.75.0 block per `docs/RELEASING.md` "Update the public changelog" step 2 format. The Flywheel's release step sets the date, adds the other merged entries and PR links, and runs `pan release stable --version 0.75.0`.
10. **Release to npm is not the work agent's job.** After merge, green main CI and deploy, the Flywheel runs `pan release stable --version 0.75.0` from main and pushes main and the tag.
11. **Size justification:** the change is a mechanical model addition across the catalog, cost, compaction and dashboard layers plus docs (about 30 files with tests). Sibling issues would force several releases for one model launch the operator wants shipped today.
