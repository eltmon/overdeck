## Glossary

- **Dock diff view** — `DockDiffView` in `src/dashboard/frontend/src/components/dock/changes/DockDiffView.tsx` (207 lines). It shows one changed file from the work dock's **Changes** tab, with previous/next buttons and `J`/`K`. `ChangesTab.tsx` mounts it.
- **Diff target** — `DockDiffTarget` in `src/dashboard/frontend/src/components/dock/workDockStore.ts` (search `export interface DockDiffTarget`): `{ path, sha?, committedVsMain?, repoRoot?, repoPath?, pushed?, outsideRoot? }`. `path` is a *root path* (relative to the dock's explorer root); it is a repo path only when `outsideRoot` is true.
- **Target source** — which of three fetch paths the dock diff view uses for a target:
  - *uncommitted*: no `sha`, no `committedVsMain`. The view reads the working-tree text and the `HEAD` text through the explorer `readFile` RPC and builds the diff with `parseDiffFromFile`.
  - *committedVsMain*: the file is committed on an issue branch. The view fetches `GET /api/agents/:id/diffs/vs-main?file=`.
  - *commit*: `sha` is set. The view fetches `GET /api/diffs/compare?base=<sha>^&head=<sha>&file=`.
- **Diff body** — the value DockDiffView's `useQuery` resolves to. Today it is the local type `DiffData` (search `type DiffData =`): `patch` (patch text), `files` (parsed `FileDiffMetadata[]`), or `message` (a sentence instead of a diff).
- **Diff | Preview switch** — the `role="tablist" aria-label="View"` pair of `role="tab"` buttons **Diff** and **Preview** inside `DiffFileBar` (`src/dashboard/frontend/src/components/diff/DiffFileBar.tsx`, lines 25–39). PAN-5338 added it to the conversation diff window.
- **Preview source** — `PreviewSource` in `src/dashboard/frontend/src/components/diff/markdownPreviewSource.ts`: `patch` (render this text), `read` (read `rootId`/`path`, optionally at `ref: 'HEAD'`, optionally with the note), or `unavailable` (show a sentence). `markdownPreviewSource(input)` picks one with the D-1 order of PAN-5338: added file → `patch`; no root → `NO_ROOT_PREVIEW`; no root path → `OUTSIDE_ROOT_PREVIEW`; `vs-main` → `read` at `HEAD`; `compare` → `read` with `note: true`; otherwise `read`.
- **DiffMarkdownPreview** — `src/dashboard/frontend/src/components/diff/DiffMarkdownPreview.tsx`. It renders a `PreviewSource` through `MarkdownTab` (the one Markdown renderer). A `read` source passes `docLocation={{ rootId, path }}`, so relative links resolve (PAN-5337). A `patch` source passes no location, so relative links stay inert. A `note: true` read shows `Showing the current file` (`SHOWING_CURRENT_FILE`).
- **The note** — the line `Showing the current file`, shown above the preview when the after side cannot be read exactly and the working-tree file is shown instead.
- **Tag row** — DockDiffView's second header row (lines 180–203): the source tag (`abc1234 · pushed`, `committed on the branch`, `not committed`), then **Open beside chat** and **Reveal in files** at the right.

## Problem

The dock diff view shows a Markdown file only as diff rows. PAN-5338 gave the conversation diff window a **Diff | Preview** switch and a reusable preview body, but its decision D-13 left `DockDiffView` unchanged. PAN-5295 (workflow redesign D2) removed the inline diff panel beside the chat, so the dock diff view is now the main place to read what a conversation changed — and it cannot show a rendered document.

## Verified facts (checked at planning time)

1. `DockDiffView.tsx` imports neither `DiffFileBar`, `DiffMarkdownPreview` nor `markdownPreviewSource` (`grep -n "DiffMarkdownPreview\|DiffFileBar" src/dashboard/frontend/src/components/dock/changes/DockDiffView.tsx` prints nothing).
2. `DiffPanel.tsx` wires the same pieces (lines 349–375 and 716–740); this plan mirrors that wiring.
3. `parseDiffFromFile` from `@pierre/diffs` 1.1.22 sets `type: 'new'` when the old contents are `''`, and `type: 'deleted'` when the new contents are `''`. `parsePatchFiles` sets `type: 'deleted'` for a `deleted file mode` patch and `type: 'new'` for a `new file mode` patch. (Probed with node on 2026-11-16.)
4. An uncommitted file whose working-tree read throws `NOT_FOUND` is diffed against `''` today (DockDiffView lines 108–117). An *emptied* file also has new contents `''`, so `type === 'deleted'` cannot tell "deleted" from "emptied". Decision D-3 uses the `NOT_FOUND` read instead.
5. `scope.rootId` for each Changes scope (`components/dock/dockScope.ts`, `byRootKind`): `project:<key>` for a project (changes kind `project-main`), `issue:<ID>` for an issue workspace, `workspace:<id>` for an edit workspace, and the conversation's root for a conversation tab. It can be `null` (no folder on this machine).
6. `isMarkdownPath(path)` is exported from `src/dashboard/frontend/src/components/explorer/code/CodePaneHeader.tsx` (`/\.(md|mdx|markdown)$/i`).
7. `scripts/lint-file-size.sh` has `CEILING=1000`. `DockDiffView.tsx` is 207 lines, `DiffFileBar.tsx` 55 lines; neither is near the ceiling.
8. `src/dashboard/frontend/src/components/dock/__tests__/DockDiffView.test.tsx` is already listed in `scripts/frontend-test-subset.txt` (line 85). A new test file needs its own line there, or CI never runs it.
9. No other planned issue in the order book edits `DockDiffView.tsx`: `.pan/drafts/pan-5284.md` and the PAN-5295 spec do not mention it.

## Decisions (made here; the work agent does not re-decide)

- **D-1 Reuse, do not fork, the source rule.** The dock maps its target source onto PAN-5338's `PreviewScope` and calls the existing `markdownPreviewSource`. No second rule function. The mapping:

  | Target source | Diff body | `PreviewScope` | `file` passed | Result |
  | --- | --- | --- | --- | --- |
  | uncommitted | `files` | `{ kind: 'full' }` | `undefined` | `read` of the working tree, no note |
  | committedVsMain | `patch` | `{ kind: 'vs-main' }` | the parsed patch file | added file → `patch` text; otherwise `read` at `HEAD`, no note |
  | commit (`sha`) | `patch` | `{ kind: 'compare' }` | the parsed patch file | added file → `patch` text; otherwise `read` of the working tree **with the note** |

  `agentRoute` is always `false`. `rootId` is `scope.rootId`. `rootPath` is `target.outsideRoot ? null : target.path`.
- **D-2 Uncommitted after side is a fresh explorer read.** Requirement 2 names "the working-tree text it already reads". The preview reads that same text again through `DiffMarkdownPreview`'s `read` source (React Query, `staleTime: 4000`) rather than threading the string through a `patch` source. A `read` source carries `docLocation`, so relative links resolve (PAN-5337); a `patch` source would render them inert. The cost is one extra `readFile` call when the operator clicks **Preview**. For the same reason `file` is passed as `undefined` for uncommitted targets (see D-1): an uncommitted *new* file (`type: 'new'`) still previews from the working tree, not from rebuilt patch text.
- **D-3 Deleted file has no switch.** Uncommitted: the working-tree `readFile` threw `NOT_FOUND` (the diff body carries `deleted: true`). committedVsMain and commit: the parsed patch file has `type === 'deleted'` (`isDeletedDiffFile(file, undefined)` from `markdownPreviewSource.ts`).
- **D-4 When the switch shows.** Only when all hold: `isMarkdownPath(target.path)`; the query succeeded; the diff body is `patch` or `files` (never `message`); the file is not deleted (D-3). So there is no switch while loading, on a load error, for `TOO_LARGE_SENTENCE`, `NO_FOLDER_SENTENCE`, `NO_WORKSPACE_COMMIT_DIFF`, or the "no agent" / "repository folder is not known" sentences. An empty patch ("No changes in this file.") still shows the switch for a Markdown file; Preview then reads the after side (same as PAN-5338 D-5).
- **D-5 Switch placement: in the tag row, not a third bar.** `DiffFileBar` would repeat the path (already in DockDiffView's first row) and adds an Open file slot that DockDiffView already covers with **Open beside chat**. So `DiffFileBar.tsx` exports its tablist as `DiffViewSwitch`, `DiffFileBar` renders `DiffViewSwitch`, and DockDiffView renders the same `DiffViewSwitch` in its tag row, directly after the tag and before the right-aligned buttons. The markup is identical in both places by construction.
- **D-6 Switch state.** Local state `{ key: string; view: DiffFileView } | null`. `key` is `` `${target.path}\u0000${target.sha ?? ''}\u0000${target.committedVsMain ? 'main' : ''}` `` — the same identity `sameTarget` uses in `components/dock/ChangesTab.tsx` (path + sha + committedVsMain). The effective view is `preview` only when `state.key === key` and `state.view === 'preview'`; otherwise `diff`. So Diff is the default, and `J`/`K`/previous/next to another target returns to Diff. Back to the list unmounts the view, which also resets it. The choice is not persisted.
- **D-7 Pure helper module.** The mapping (D-1, D-3, D-4 minus the query-state check) lives in a new pure module `src/dashboard/frontend/src/components/dock/changes/dockDiffPreview.ts`, which also owns the diff body type (renamed `DockDiffBody`, with `deleted` added to `files`). It parses a patch with `parsePatchFiles` from `@pierre/diffs` directly (not `getRenderablePatch` from the `PatchFiles.tsx` component), so the module has no React import.
- **D-8 No server change and no new route.** Everything reads through routes and RPCs DockDiffView already calls. No `route-scopes.ts` or `tests/unit/lib/overdeck/no-loss-matrix.ts` rows.

## Requirements

- **FR-1** For a Markdown target whose diff loaded, the dock diff view's tag row shows a **Diff | Preview** switch with **Diff** selected (D-4, D-5).
- **FR-2** **Preview** renders the after side through `DiffMarkdownPreview` (and so `MarkdownTab`); no other Markdown renderer is added, and no diff rows render while Preview is shown.
- **FR-3** Uncommitted target → Preview shows the working-tree file (D-1, D-2).
- **FR-4** committedVsMain target → Preview shows the `HEAD` file, or the patch text for an added file (D-1).
- **FR-5** Commit target → Preview shows the patch text for an added file; otherwise the current working-tree file with the note `Showing the current file` (D-1).
- **FR-6** A deleted file shows no switch (D-3).
- **FR-7** The switch's choice belongs to one target; moving to another target shows its diff (D-6).
- **FR-8** The conversation diff window's `DiffFileBar` keeps its behavior after `DiffViewSwitch` is extracted (D-5).
- **NFR-1** No server change, no new HTTP route (D-8).
- **NFR-2** `DockDiffView.tsx` stays under the 1000-line ceiling; the source mapping stays out of the component (D-7).
- **NFR-3** The tag row fits the dock's default 340 px width without horizontal page scroll: the tag truncates, the switch and buttons do not wrap.

```ts
// Markdown Preview source for one dock diff target (PAN-5341 D-1, D-3, D-7).

import { parsePatchFiles, type FileDiffMetadata } from '@pierre/diffs'

import { isMarkdownPath } from '../../explorer/code/CodePaneHeader'
import {
  isDeletedDiffFile,
  markdownPreviewSource,
  type PreviewScope,
  type PreviewSource,
} from '../../diff/markdownPreviewSource'
import type { DockDiffTarget } from '../workDockStore'

/** What DockDiffView's query resolves to. `deleted`: the working-tree read was NOT_FOUND. */
export type DockDiffBody =
  | { kind: 'patch'; patch: string }
  | { kind: 'files'; files: FileDiffMetadata[]; deleted: boolean }
  | { kind: 'message'; text: string }

/** D-1: the PAN-5338 scope that matches a target's source. */
export function dockPreviewScope(target: DockDiffTarget): PreviewScope {
  if (target.sha) return { kind: 'compare' }
  if (target.committedVsMain) return { kind: 'vs-main' }
  return { kind: 'full' }
}

/** The single file of a one-file patch; undefined when empty or unparseable. */
export function patchFileOf(patch: string): FileDiffMetadata | undefined {
  const text = patch.trim()
  if (text.length === 0) return undefined
  try {
    return parsePatchFiles(text).flatMap((p) => p.files)[0]
  } catch {
    return undefined
  }
}

/** D-1/D-3/D-4: the preview source, or null when the target gets no Diff | Preview switch. */
export function dockMarkdownPreview(input: {
  target: DockDiffTarget
  body: DockDiffBody
  rootId: string | null
}): PreviewSource | null {
  const { target, body, rootId } = input
  if (!isMarkdownPath(target.path)) return null
  if (body.kind === 'message') return null
  if (body.kind === 'files' && body.deleted) return null
  const file = body.kind === 'patch' ? patchFileOf(body.patch) : undefined
  if (isDeletedDiffFile(file, undefined)) return null
  return markdownPreviewSource({
    file,
    scope: dockPreviewScope(target),
    agentRoute: false,
    rootId,
    rootPath: target.outsideRoot ? null : target.path,
  })
}
```

- Do not import from `DockDiffView.tsx` or `PatchFiles.tsx` (keeps `lint:circular` and the module pure).
