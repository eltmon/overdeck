## Glossary

- **GPT-6.1 Terra**: OpenAI model id `gpt-6.1-terra`, released 2026-10-26. It is the workhorse tier of GPT-6.1, below `gpt-6.1-sol`, in the slot `gpt-5.6-terra` fills for GPT-5.6. Note the **dot**: `gpt-6.1-terra`, not `gpt-6-1-terra`.
- **GPT-5.6 Terra**: the existing id `gpt-5.6-terra`. It stays a separate model everywhere. Its price, display name and catalog rows must not change.
- **Codex floor**: the oldest Codex CLI version OpenAI's backend accepts for a model under ChatGPT sign-in. Stored in `CODEX_MODEL_MINIMUM_VERSIONS` (`src/lib/codex/model-floors.ts`). Below it, OpenAI answers HTTP 400, so Overdeck's policy gate refuses the launch first. API-key auth has no floor.
- **ChatGPT sign-in / `subscription` auth**: Codex authenticated with a ChatGPT account (`AuthMode === 'subscription'`), as opposed to `api-key`.
- **CLIProxy**: the local sidecar on port 8317 that lets the `claude-code` harness run GPT models through a ChatGPT subscription. Pinned to `v7.3.16` in `src/lib/cliproxy.ts` (`CLIPROXY_RELEASE_VERSION`).
- **`GPT_56_MODELS`**: the set in `src/lib/agents/provider-env.ts` that names the GPT ids whose claude-code (CLIProxy) route gets the 272K pin. Its only reader is `getClaudeCodeContextPolicyForModel` in the same file.
- **272K billing-tier pin**: Overdeck caps GPT-6/GPT-5.6 sessions at 272,000 tokens (`CLIPROXY_GPT56_CONTEXT_WINDOW`) because OpenAI bills prompts over 272K input at 2x input / 1.5x output for the whole request. The Codex managed `config.toml` writes `model_context_window = 272000`.
- **`costPer1MTokens`**: the blended picker price Overdeck shows, (input + output) / 2 per 1M tokens. For $1 in / $5 out that is `3`.
- **Unreleased changelog block**: `<Update label="vX.Y.Z" description="Unreleased" tags={["Upcoming"]}>` at the top of `changelog.mdx`, finalized on release day per `docs/RELEASING.md` "Update the public changelog".

## Decisions (made here; the executor does not re-decide)

- **D1 Capability class `workhorse`.** Same as `gpt-5.6-terra` (`src/lib/model-capability-class.ts`, anchor `'gpt-5.6-terra': 'workhorse',`).
- **D2 Effort levels `['low', 'medium', 'high', 'xhigh', 'max']`.** Same as `gpt-6.1-sol`. Omit `none` and `ultra`. Overdeck's default effort stays `high`.
- **D3 Context: 272K pin** (`CLIPROXY_GPT56_CONTEXT_WINDOW`), label "(272K context)". No `[372k]` variant. The Codex runtime pin in `src/lib/runtimes/codex.ts` already covers the id through PAN-4422's `startsWith('gpt-6.')` branch, so that file gets **no code change**, only a test row.
- **D4 Pricing row:** `inputPer1k: 0.001, outputPer1k: 0.005, cacheReadPer1k: 0.00005`. `costPer1MTokens: 3`, `costDisplay: '$3/1M'`. `getPricing` (`src/lib/cost.ts`, anchor `export function getPricing`) tries an exact match, then `model.startsWith(p.model)`. Nothing in `harness-policy.ts` refuses `claude-code` + `gpt-6.1-terra`; such a launch fails at runtime with CLIProxy's `unknown provider` error. Adding a harness gate is not part of D8 and is a NonGoal.
