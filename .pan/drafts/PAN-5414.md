# PAN-5414 — Left column rows: hidden hover buttons truncate titles, Stop × overlaps Settle, empty All-deck crumb

**Issue:** [PAN-5414](https://github.com/eltmon/overdeck/issues/5414) · Parent epic: [#5284](https://github.com/eltmon/overdeck/issues/5284) · Found in the live check of H ([#5343](https://github.com/eltmon/overdeck/issues/5343), PR [#5412](https://github.com/eltmon/overdeck/pull/5412)).

Three small polish defects in the Command Deck's left column and top bar. All three are frontend-only (CSS module + two TSX components). No server, API, or store change.

## Glossary

- **FE** — `src/dashboard/frontend/src`.
- **CSS** — `FE/components/CommandDeck/styles/command-deck.module.css` (6541 lines; CSS files are not covered by `scripts/lint-file-size.sh`).
- **Flat row** — a top-level conversation row in the left column's Conversations list: `ConversationRow` with `variant` unset or `'flat'`. Root class `styles.conversationItem`. Two lines: title, then the meta line.
- **Nested row** — a lineage child row (`ConversationRow variant="nested"`, rendered at `FE/components/CommandDeck/ConversationList.tsx` line 448). Root class `styles.projectConvItem`. Single line. Has no Settle checkbox and is never passed `onOpenBeside`.
- **Meta line** — the flat row's second line (`data-testid="conversation-meta-line"`): state · changes · harness · cost, then badges.
- **Beside button** — the `Columns2` icon button with `aria-label="Open beside"` that H (PAN-5343) added; rendered whenever `onOpenBeside` is passed (All deck **and** project decks).
- **⋮ (kebab) button** — the row's overflow-menu trigger, `aria-label="More actions for <title>"`.
- **Star** — the favorite toggle. Absolutely positioned at the row's right edge (`right: 8px`, 18 px wide). Class `conversationStarBtn` (hidden until hover/focus) or `conversationStarPersistent` (always visible, when `conv.isFavorited`).
- **Stop ×** — the absolutely positioned stop button (`conversationStopBtn`) shown on hover of a row whose `conv.sessionAlive` is true.
- **Settle checkbox** — `role="checkbox"` span with class `conversationSettleBox`, flat rows only (PAN-4639 WI-7).
- **Action group** — the existing but currently unused `.conversationActions` CSS class: a flex container that collapses to `max-width: 0; opacity: 0; margin-left: -6px` at rest and opens on row `:hover` / `:focus-within`.
- **At rest** — the row is neither hovered nor contains focus (`:hover` and `:focus-within` both false) and its menu is closed. A just-clicked row matches `:focus-within`, so "at rest" checks must blur it first.
- **All deck** — the All projects deck, key `ALL_PROJECTS_KEY = '__all-projects__'` (`FE/lib/deckKeys.ts`).
- **Crumb** — the top bar's breadcrumb, `FE/App/topbar/Breadcrumb.tsx`, `data-testid="topbar-crumb"`.

## Requirements

- **FR-1** At rest, a flat row's Beside and ⋮ buttons occupy zero width: both render inside one `<span className={styles.conversationActions}>` group that collapses at rest and opens on row hover / focus-within.
- **FR-2** While the row's overflow menu is open, the action group stays open and its buttons stay visible (opacity 1), even though the portaled menu and its overlay take hover and focus away from the row.
- **FR-3** At rest, a non-favorited flat row's right padding is 8 px, so the title and meta line extend to within 8 px of the row's right edge (or to the pane badge plus its 6 px gap when one shows).
- **FR-4** A flat row keeps 30 px right padding (room for the star) on `:hover`, on `:focus-within`, when `conv.isFavorited` (the persistent star shows), and while its menu is open.
- **FR-5** The flat row's Stop × does not overlap the Settle checkbox on hover: × spans x = 4–20, checkbox starts at x = 24.
- **FR-6** The nested row's Stop × does not overlap its first in-flow child (the status indicator at x = 28): × spans x = 10–24.
- **FR-7** With the All deck selected, fewer than two leaves in its layout, and no active pane (or an active pane with an empty label), the crumb renders only `All projects` — no `/` separator and no detail span.
- **FR-8** The user and developer docs describe the empty All deck crumb and the row's hover action layout; a `changelog.d/pan-5414.md` entry has one `#### Fixed` section.
- **FR-9** A keyboard focus ring on the Beside or ⋮ button stays fully visible; the group's `overflow: hidden` must not clip it.
- **NFR-1** No pixel-width assertions in happy-dom unit tests; geometry is verified only in a real browser (Playwright, isolated profile).
- **NFR-2** No test reads CSS or TSX source text (the lint rejects source-grep tests); no `skipIf`, no `.only`.
- **NFR-3** `ConversationRow.tsx` stays under the 1000-line ceiling of `scripts/lint-file-size.sh` (912 lines on main today; this change adds roughly 6).

## Decisions

- **D1 — Use the existing `.conversationActions` class** (FR-1). It already has the collapse / open transitions and the `.projectConvItem` overrides. No new group class.
- **D2 — Wrap applies to both variants.** The JSX is shared, so nested rows also get the group. For nested rows only ⋮ is inside (they never get `onOpenBeside`); `.projectConvItem:hover .conversationActions` already opens to `max-width: 100px`. This frees ~20 px on nested rows at rest too. Accepted.
- **D3 — Keep `margin-left: auto` on `.conversationKebabBtn`.** Inside the content-sized group the auto margin resolves to 0, so it does not break alignment; the title (`flex: 1`) already pushes the group right. Removing it is out of scope.
- **D4 — Menu-open visibility (FR-2).** `MenuSurface` takes focus and `MenuOverlay` covers the page, so the row loses `:hover` and `:focus-within` while the menu is open. `.conversationKebabBtn` has its own `opacity: 0` that only row hover/focus lifts. So the plan adds both `.conversationActionsOpen { max-width: 120px; opacity: 1; margin-left: 0; }` and `.conversationActionsOpen .conversationKebabBtn { opacity: 1; }`.
- **D5 — Padding classes.** Add two row classes for flat rows: `styles.conversationItemFavorited` when `conv.isFavorited`, and `styles.conversationItemMenuOpen` when `menuOpen`. One rule gives both 30 px right padding. Keeping 30 px while the menu is open stops the group jumping 22 px right under the already-positioned menu.
- **D6 — Nested right padding unchanged.** `.projectConvItem` keeps `padding: 3px 22px 3px 28px`. The issue scopes the padding fix to flat rows.
- **D7 — Nested Stop × moves to `left: 10px`** (FR-6), by arithmetic: 10 + 14 = 24 ≤ 28 − 4. The issue asks to check the nested × against "that variant's checkbox"; nested rows have none, but the × overlaps the status indicator, which is the same defect class.
- **D8 — Empty-crumb styling.** The lone `All projects` keeps the All deck crumb's existing first-span classes (`shrink-0 font-medium text-foreground`), because it names a selected deck, unlike the muted no-project crumb. Condition: `shown < 2 && !paneLabel` (treats an empty-string label as none).
- **D9 — No hover padding transition.** `.conversationItem`'s `transition` stays `background 0.1s`; padding snaps on hover. The issue accepts that the title truncates further while hovered.
- **D10 — `conversationItemConfirming` is left alone.** It is defined in CSS but unused in TSX; deleting it is unrelated cleanup (NonGoal).
