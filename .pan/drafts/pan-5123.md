````markdown
### Grouped List and Switch Tracks (both themes) — PAN-5123

Five named classes in `src/dashboard/frontend/src/index.css` (`@layer components`, search for `.list-group-bar`) style a grouped list: collapsible groups of single-line rows, with a switch as the row's state control. The Skills page is the first user. For every new list group, list row, list metadata strip and switch track, use these classes. Do not rebuild them from Tailwind opacity utilities.

**Why named classes.** `tailwind.config.js` defines the color tokens as bare `var()` strings (`muted: { DEFAULT: 'var(--muted)' }`), so Tailwind cannot apply an opacity modifier to them. `bg-muted/40` and `bg-foreground/8` compile to no CSS, and the element silently gets no background. Each class below mixes the token with `transparent` through `color-mix()`, so the tint renders in both themes and both color schemes.

| Class | Renders | Use it for |
|---|---|---|
| `.list-group-bar` | `--muted` at 55% | The header bar of a collapsible group: chevron, title, quiet hint, right-aligned count, optional group switch. |
| `.list-row` | `--muted` at 45% on hover, 150ms color transition | One single-line row inside a group. Add the row's own grid and padding; separate rows with `divide-y divide-border` on the parent. |
| `.list-meta` | `--muted` at 30% | A metadata strip directly under an open group header (source URL, counts). Lighter than the header bar. |
| `.switch-track-on` | `--foreground` at 62% | The track of a checked `role="switch"` button the operator can change. |
| `.switch-track-locked` | `--foreground` at 28% | The track of a checked switch that cannot change (for example a core skill: always on). |

The unchecked track has no named class: it is `border-border bg-muted`, which works because `bg-muted` has no opacity modifier. The thumb is `bg-background` when checked and `bg-muted-foreground` when unchecked. Checked tracks are neutral, never `bg-primary`: in a long list the switch is the row's only state signal, and color restraint (§4) keeps it out of the signal palette.

```tsx
// Group header — components/skills/SkillControls.tsx (GroupHeader)
<div className="list-group-bar px-3 py-2">
  <div className="flex min-h-7 items-center gap-3">
    <button type="button" aria-expanded={open} onClick={onToggle}>{/* chevron + title */}</button>
    <span className="ml-auto flex shrink-0 items-center gap-3">
      <span className="font-mono-ui text-xs tabular-nums text-muted-foreground">72 of 72 on</span>
    </span>
  </div>
</div>

// Metadata strip under an open group — components/skills/SkillPacksSection.tsx
<div className="space-y-0.5 list-meta px-3 py-2 pl-9 text-xs leading-5 text-muted-foreground">{/* url, counts */}</div>

// Rows — components/skills/SkillOverridesPanel.tsx (SkillRow)
<div className="divide-y divide-border border-t border-border">
  <div className="list-row grid items-start gap-x-4 gap-y-1 px-3 py-2 grid-cols-[minmax(0,1fr)_auto]">{/* name, description, control */}</div>
</div>

// Switch track — components/skills/SkillControls.tsx (SkillSwitch)
<button
  type="button"
  role="switch"
  aria-checked={checked}
  className={cn(
    'relative inline-flex h-[18px] w-8 shrink-0 items-center rounded-full border transition-colors duration-150',
    checked ? (locked ? 'switch-track-locked border-transparent' : 'switch-track-on border-transparent') : 'border-border bg-muted',
  )}
>
  <span
    aria-hidden
    className={cn(
      'inline-block h-3 w-3 rounded-full shadow-sm transition-transform duration-150',
      checked ? 'translate-x-[15px] bg-background' : 'translate-x-[2px] bg-muted-foreground',
    )}
  />
</button>
```

**Theme scope.** The rules are not scoped to a theme and read only `--muted` and `--foreground`, which both themes define. The classes render under Ledger and Broadsheet alike; they are not a Broadsheet-only pattern like chips or soft cards.

**Adoption.** Pages move to these classes one page at a time, when someone is already changing that page. There is no bulk Tailwind config change (for example, rewriting the color tokens to accept `<alpha-value>`) and no sweep across existing pages. Never rename or remove these classes; the Skills page depends on them.

**Canonical example:** the Skills page — `components/skills/SkillControls.tsx` (`SkillSwitch`, `GroupHeader`), `SkillOverridesPanel.tsx` (`SkillRow`), and `SkillPacksSection.tsx` (pack metadata strip and pack skill rows).
````
