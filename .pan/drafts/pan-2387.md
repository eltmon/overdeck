# PAN-2387 — Cost Tracking page: UNKNOWN bucket, dual-plane totals, missing codex spend

**Issue:** https://github.com/eltmon/overdeck/issues/2387
**Planned:** 2026-07-05 (auto mode, `pan plan --auto`)

## Glossary

- **cost event** — one row of spend: `{ts, issueId, agentId, sessionId, sessionType, provider, model, input, output, cacheRead, cacheWrite, cost, requestId, sourceFile}`. Written through the overdeck write door (`CostWriter.record`, `src/lib/overdeck/cost.ts:497`) or the sync mirror (`insertCostEventSync`, `src/lib/overdeck/cost-sync.ts:48`) into the `cost_events` table of `~/.overdeck/overdeck.db`.
- **overdeck plane** — the `cost_events` table in `overdeck.db`. Read by `/api/costs/by-issue` and `/api/costs/issue/:id` via `src/lib/overdeck/cost-sync.ts` (`getCostsByIssueSync` :246, `getCostForIssueAggregateSync` :336).
- **legacy plane** — the JSONL events + `cache.json` under `~/.overdeck/costs/`, aggregated by `src/lib/costs/aggregator.ts`. Still read by `GET /api/issues/:id/costs` (`src/dashboard/server/routes/issues.ts:702` calls the legacy `getCostsForIssueSync` imported at `:62`).
- **reconciler** — `src/lib/costs/reconciler.ts`, the periodic catch-up sweep over `~/.claude/projects/**.jsonl` (Claude transcripts) and `~/.overdeck/agents/*/` (Pi transcripts). Writes through `CostWriter.record`.
- **codex sweep** — the `source: 'codex'` branch of `CostWriter.reconcile` (`src/lib/overdeck/cost.ts:537-617`): walks `~/.overdeck/agents/<id>/codex-home/sessions/**/*.jsonl`, parses each rollout with `parseCodexSessionSync`, records one cumulative event per rollout file.
- **rollout** — a Codex CLI session JSONL file (`rollout-<ts>-<uuid>.jsonl`). Nested schema (cli ≥ 0.137.0): kind under `payload.type`; model in `turn_context.payload.model`; cumulative usage in `token_count.payload.info.total_token_usage`.
- **bucket** — a named non-issue grouping stored in the `issue_id` column: `CONVERSATIONS`, `FLYWHEEL`, `UNATTRIBUTED`.

## Verified root causes (all confirmed against live data 2026-07-05)

### Bug 1 — UNKNOWN dominates Costs by Issue ($12.8k of $16.8k)

The reconciler falls back to the literal string `'UNKNOWN'` when a transcript session has no agent mapping and no issue-shaped path. Four fallback sites in `src/lib/costs/reconciler.ts`: lines 171, 486, 615, 666 (search for `|| 'UNKNOWN'`).

Live DB evidence: 49,453 UNKNOWN events / $12,800. Of these, 12,162 events ($3,559) join to registered conversations via `conversation_files.locator = cost_events.session_id`; $7,773 come from sessions in the overdeck project-root Claude dir (conversations + the flywheel, which is itself a registered conversation named `flywheel-orchestrator`). The residual is oversight/ad-hoc sessions.

### Bug 2 — per-issue total $0.00 while model rows sum higher

Structural cause: **two read planes for the same fact.** `GET /api/issues/:id/costs` (used by Command Deck CostsTab, cockpit CostCard, IssueMetricStrip, IssueMissionControl via `useIssueCostsQuery`, `src/dashboard/frontend/src/components/CommandDeck/ZoneCOverviewTabs/queries.ts:243`) reads the **legacy plane**; the Costs page reads the **overdeck plane**. When the legacy cache misses an issue, the route returns `totalCost: 0` (`src/dashboard/server/routes/issues.ts:713`) while overdeck-plane surfaces show real model rows. As of planning, both planes happen to agree for PAN-2383 ($15.25) — the defect is intermittent by construction and must be fixed by unifying the read plane, not by patching a number.

### Bug 3 — "codex misattributed as gpt-5.4-mini at $0" is actually TWO defects

- **3a. Memory-extraction stub pricing.** The `gpt-5.4-mini / $0.00 / calls=4` rows on PAN-2383 are `sessionType: 'memory-extraction'` events, one per agent session — not codex events. `recordExtractionCost` (`src/lib/memory/providers/types.ts:91`) prices via a **local stub** `getPricing` (`types.ts:122-135`) that knows only anthropic-haiku and `gpt-4.1-nano`; everything else returns all-zero rates → $0. It duplicates and contradicts the real pricing table in `src/lib/cost.ts` (which has `gpt-5.4-mini` at line 112).
- **3b. Codex spend is never ingested at all.** No caller ever invokes `CostWriter.reconcile({source:'codex'})`. The periodic service (`src/dashboard/server/services/cost-reconcile-service.ts`) only runs `reconcilePiTranscripts()`; the Claude sweep covers `~/.claude/projects` only. PAN-2383 slot-1's rollouts exist at `~/.overdeck/agents/agent-pan-2383-slot-1/codex-home/sessions/2026/07/05/` and the main rollout carries `"model":"gpt-5.5"` in `turn_context` — `parseCodexSessionSync` reads it correctly (verified by inspection) — but no gpt-5.5 event exists for PAN-2383 in `cost_events`. `issueIdFromAgentName('agent-pan-2383-slot-1')` resolves PAN-2383 correctly (`src/lib/overdeck/cost.ts:189`), so wiring the sweep is sufficient for attribution.
- **3b hazard: cumulative-freeze.** `parseCodexSessionSync` returns cumulative session totals; the codex event has `requestId: null`, so `checkDuplicate` (`cost.ts:480-495`) dedups on `source_file`. First import permanently freezes the totals — re-sweeps of a still-growing rollout are dropped. The sweep must update-on-growth.
- Side observation: codex auto-review side threads carry `"model":"codex-auto-review"` (no pricing → $0). See autoDecision 3.

## Requirements

- **FR-1** No cost surface shows a literal `UNKNOWN` bucket. Unattributable spend is classified at ingest into `CONVERSATIONS` (registered conversations), `FLYWHEEL` (the flywheel-orchestrator conversation), or `UNATTRIBUTED` (residual).
- **FR-2** Existing `UNKNOWN` rows in `cost_events` are reclassified in place by an idempotent backfill using the same classifier.
- **FR-3** `GET /api/issues/:id/costs` reads the overdeck plane, so the issue-level total always equals the sum of its model rows (same table, same query family).
- **FR-4** Memory-extraction cost events are priced from the shared pricing table in `src/lib/cost.ts`; a gpt-5.4-mini extraction with non-zero tokens records non-zero cost.
- **FR-5** Codex rollouts are swept periodically; a gpt-5.5 rollout produces an event with `model: 'gpt-5.5'` and non-zero cost; re-sweeping a grown rollout updates the event instead of freezing or duplicating.
- **FR-6** Frontend renders neutral display labels for the buckets ("Conversations", "Flywheel orchestration", "No issue — unattributed").
- **NFR-1** All sweeps/backfills stay idempotent (safe to run any number of times).
- **NFR-2** No new sync blocking added to server request paths beyond the existing sync-SQLite pattern; never `execSync`.

## Design decisions (auto mode)

1. **Buckets live in the `issue_id` column** as reserved uppercase ids (`CONVERSATIONS`, `FLYWHEEL`, `UNATTRIBUTED`). No schema migration; by-issue grouping, drill, and stage/model rollups work unchanged. Display labels are a frontend mapping.
2. **Flywheel spend is one FLYWHEEL bucket, not per-RUN-id.** RUN-id ↔ session mapping is not reliably derivable from stored data; a per-run split can be a follow-up.
3. **codex-auto-review side threads** stay recorded under their real model id at whatever the pricing table yields ($0 today — they are subscription-included side threads). The non-zero acceptance applies to the primary gpt-5.5 rollout.
4. **Backfill is part of the reconcile sweep** (runs after import, `UPDATE`s only rows whose `issue_id` is exactly `UNKNOWN`), not a standalone migration. The DB is a disposable cache; archives are untouched.
5. **`budget` on `/api/issues/:id/costs` becomes `undefined`.** No-loss audit: `setIssueBudgetSync` has no route caller; no frontend consumer reads `budget` from this endpoint (`IssueCostData` in queries.ts has no budget field). The legacy budget affordance on this endpoint is dead code; overdeck budgets live in budgets.json via CostResolver.
6. **Codex event `sessionType`** is taken from the agent's `state.json` `role` (fallback `'work'`), not the literal `'codex'`, so stage rollups stay role-shaped.

## Intersecting repo rules (restated for the executor)

- Never `execSync` in server-reachable code; use async or the existing sync-SQLite pattern.
- Any retry/backoff/delay test uses `vi.useFakeTimers()` + `advanceTimersByTimeAsync` — never real timers (relevant if testing the reconcile interval service).
- Two-door tenet: reads via domain resolvers, writes via `CostWriter`/`insertCostEventSync`. The conversation lookup for the classifier must be an exported helper of the conversations domain (`src/lib/overdeck/conversations.ts`), not an ad-hoc query in the reconciler.
- Refactors of existing surfaces need a no-loss audit: `/api/issues/:id/costs` response keys are enumerated in work item 4 and must all survive.
- Quality gates before `pan done`: `npm run typecheck`, `npm run lint`, `npm test`.
