# PAN-2532 — Pipeline rows: widen issue title to reclaim wasted horizontal space (keep compact height)

## Glossary

- **PipelineRow** — the React component rendering one issue row in the Command Deck / Project Overview pipeline lists (`src/dashboard/frontend/src/components/CommandDeck/PipelineRow.tsx`).
- **Status chip** — the small rounded badge with a colored dot + label (e.g. purple "review", blue "building") produced by `pipelineChipFor(entry)`.
- **Subline** — the phase/status detail string from `sublineFor(entry)`.
- **WhoLine** — the model/owner line from `whoLineFor(entry)`; its signature is `string | null`.
- **Proposal B** — the operator-selected design in the issue body: a title-first 4-column grid that merges the status column into a metadata line beneath the title.

## Problem

Pipeline rows truncate the issue title far too early (e.g. `Review pipeline strande…`) while leaving empty horizontal space to the right. `PipelineRow` uses a fixed 5-column grid:

`src/dashboard/frontend/src/components/CommandDeck/PipelineRow.tsx:44`
```tsx
style={{ gridTemplateColumns: '88px 1fr 200px 90px 34px' }}
```
Columns: `issueId (88) | title+subline (1fr) | status chip+whoLine (200) | cost+sessions (90) | avatar (34)`.

At the typical container width (~580px) the fixed **200px status column** starves the `1fr` title column down to ~120px — hence the early ellipsis with whitespace to its right.

## Proposal (Proposal B — operator-selected)

Collapse the 5-column grid into a title-first **4-column** grid:

`issueId (78) | title + metadata subline (1fr) | cost+sessions (74) | avatar (34)`

- **Line 1:** full-width title, `truncate` (now gets ~440px instead of ~120px).
- **Line 2:** a single inline metadata row — the status chip (colored dot + label, `shrink-0`) followed by `sublineFor(entry)` and `whoLineFor(entry)` joined by ` · `, the tail truncating as one string.
- Cost (`$12.34`) + `N sessions` stay in their own right-aligned column so the price list stays scannable top-to-bottom.
- Colored status dot and the avatar ring are unchanged.

Row height is unchanged (still exactly two text lines).

### Truncation contract (hazard)

The metadata row is a flexbox: the chip is `shrink-0`, the container carries `min-w-0 overflow-hidden`, and only the inner subline/whoLine text span carries `truncate`. Do **not** put `truncate` on the flex container (whitespace-nowrap on a flex parent does not ellipsize its children).

`whoLineFor` may return `null` (`pipeline-helpers.ts:242`) — `[sublineFor(entry), whoLineFor(entry)].filter(Boolean).join(' · ')` handles that so no dangling ` · ` is ever rendered.
