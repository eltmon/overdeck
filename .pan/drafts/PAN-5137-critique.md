## blocks-the-design: Upcoming can bypass the stable release refusal

The PRD requires every leftover Upcoming block to stop a stable release before writes ([PRD](/home/eltmon/Projects/overdeck/workspaces/feature-pan-5137/.pan/drafts/PAN-5137.md), line 97). But its `planChangelogFold` returns `no-entries` before reading `changelog.mdx` (lines 172-174), and returns `block-exists` before calling `foldChangelogEntries`, the only proposed Upcoming check (lines 177-181 and 128-133). The existing release command then continues through preflight, commit and tag ([release.ts](/home/eltmon/Projects/overdeck/workspaces/feature-pan-5137/src/cli/commands/release.ts), lines 556-565 and 595-620). With no entry files, or on a retag with new entries, an Upcoming block can survive a stable release. Move the Upcoming/Unreleased check ahead of both skip returns, and test those two combinations. Keep the canary early return.

## blocks-the-design: Release parsing omits MDX safety checks

Decision 2 says the entry parser and lint enforce the same rules, including escaping currency dollars and `<` before digits ([PRD](/home/eltmon/Projects/overdeck/workspaces/feature-pan-5137/.pan/drafts/PAN-5137.md), lines 41-50). The proposed release parser only checks headings, bullets and continuations (lines 108-150); WI-3 alone calls the existing `findMdxProblems` in [lint-docs.js](/home/eltmon/Projects/overdeck/workspaces/feature-pan-5137/scripts/lint-docs.js), lines 38-60. Release preflight runs `npm run build` and `npm test` ([release.ts](/home/eltmon/Projects/overdeck/workspaces/feature-pan-5137/src/cli/commands/release.ts), lines 451-479), while `lint:docs` runs only through `npm run lint` ([package.json](/home/eltmon/Projects/overdeck/workspaces/feature-pan-5137/package.json), lines 122 and 134). A tracked entry containing `$2` or `<3` can therefore pass release preflight and be copied into `changelog.mdx` after the build. Add equivalent MDX safety validation to the release-time parser and tests for both characters, so release planning rejects them before preflight.
