## Glossary

- **`anywhere.mdx`:** the Mintlify page at `/anywhere`, sidebar title "Plans and pricing", listed in `docs.json` line 59. 369 lines on `main` at `4552499`.
- **Mintlify:** the docs site generator. Pages are `.mdx` at the repo root and under `cli/`, `configuration/`, `features/`, `guides/`, `reference/`. Internal links use route paths (`/configuration/linked-machines`), never file names. `.mintignore` excludes every `*.md` file, so a link to a `.md` file is a broken link.
- **`&#36;`:** the HTML entity for `$`. Mintlify renders two `$` on one line as LaTeX math, so every currency dollar sign in prose is written `&#36;`. `npm run lint:docs` (`scripts/lint-docs.js`) fails on a bare `$` in prose and on a bare `<` before a digit (write `&lt;`).
- **OD-3:** "Prices for directory service and relay service", the settled pricing decision in `.pan/drafts/pan-2350.md` lines 380–414 (operator-approved 2026-11-01).
- **W-DOC:** the documentation work item of the epic PRD, `.pan/drafts/pan-2350.md` lines 489–506.
- **"next release":** the release after v0.72.0. v0.72.0 (tagged 2026-10-26, `af8111e70f6`) is the newest tag. Every Anywhere feature listed below merged after it, so the page says "next release", never a version number.
- **Shipped:** merged on `main`. A feature is "planned" only when its code is not on `main`.
- **Supersede header:** the first line of a draft PRD that has been replaced by the epic PRD. Sibling drafts use exactly: `> **Superseded by [pan-2350.md](pan-2350.md)** (Overdeck Anywhere revision 5). Kept for history until rebaselined.` (`.pan/drafts/pan-2352.md` line 1, `.pan/drafts/pan-3513.md` line 1).

## Problem

- Roadmap steps "Notifications, remote access and a mobile web app" (159–167) and "Remote agent workspaces on Fly.io" (168–174) say "Planned". Both shipped; remote access shipped through Tailscale Serve, not a tunnel.
- The pricing reasoning predates OD-3: accordion 4 (lines 287–297) says relay and push costs are "not modeled yet"; accordion 6 (lines 318–322) says "At launch only the vault exists"; OD-3's reasons for a free directory and for the relay add-on's hard cap are missing; the Self-hosted card omits OD-3's Funnel triggers, Web Push and MCP server; the relay paragraph omits OD-3's combined prices (&#36;13/mo, &#36;126/yr).

## Decisions (made in this document)

1. **Keep the v0.64.0 and v0.65.0 rows.** W-DOC says "drop the stale v0.65.0 … lines", but every v0.65.0 row was checked against tag `v0.65.0` and is correct. The "planned PAN-4446" line W-DOC names is already gone. Deleting accurate history would make the table wrong, so the rows stay and a v0.65.0 row for **Continue on another device** (PAN-4455) is added.
2. **The free account's 1 GB hosted vault stays, labeled planned.** OD-3's table lists only the directory for the free account, but the 2026-09-28 decision (1 GB, 2 machines) is "carried over unchanged" (`pan-2350.md` line 589) and accordions 2 and 8 depend on it. The card states the two limits with separate nouns ("the directory … for up to 3 machines"; "1 GB of hosted vault storage, synced on 2 machines, when the hosted vault ships") so they do not read as a contradiction.
3. **Add the Hermes bridge as a planned line** in a new "Webhook triggers and the MCP server" roadmap step. The issue says keep it planned; the page does not mention it today, and that step is where external-agent access belongs.
4. **The Fly step is retitled "Fly VMs as machines" and marked shipped** through PAN-4652, and names PAN-4734 and PAN-1676 (both open) as still planned. PAN-1775 is no longer linked as shipped work; PAN-4734 replaces it.
5. **The notifications step drops the PAN-2352 link.** PAN-2352 (Cloudflare Tunnel) was closed as superseded by Tailscale Serve; the step links PAN-1254 instead.
6. **New accordions are appended as 10 and 11.** Renumbering accordions 1–9 would churn the diff for no reader benefit.
7. **The supersede header for `pan-2356.md` copies the sibling wording's first sentence exactly** and changes the second sentence, because `pan-2356.md` is already rebaselined (its line 3 says revision 2). Header: `> **Superseded by [pan-2350.md](pan-2350.md)** (Overdeck Anywhere revision 5) for scope and pricing (OD-3). Kept as the record of how PAN-2356 was built.`
8. **The link-check acceptance is scoped to `anywhere.mdx`** (NFR-2). Making `mint broken-links` exit 0 would mean fixing `vision.mdx` and two other pages this issue does not own. [PAN-4779](https://github.com/eltmon/overdeck/issues/4779) covers those.
