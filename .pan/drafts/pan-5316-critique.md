## blocks-the-design: Guard accepts a symlink to the primary

The proposed guard checks only `issueIdFromWorkspacePath(workspacePath)` and `existsSync(workspacePath)`. The former reads only the basename ([src/lib/xbrief/io.ts](/home/eltmon/Projects/overdeck/workspaces/feature-pan-5316/src/lib/xbrief/io.ts), lines 129–132). `writeSpecForIssue` then creates directories under the supplied path ([src/lib/pan-dir/specs.ts](/home/eltmon/Projects/overdeck/workspaces/feature-pan-5316/src/lib/pan-dir/specs.ts), lines 30–42 and 254–265). An existing `workspaces/feature-pan-5316` symlink to the primary checkout passes both checks and makes the write dirty the primary tree. An arbitrary existing directory with that basename also passes without being the issue's worktree. The dashboard uses `workspaceNeedsSetup`, which treats any existing path without an incomplete marker as ready ([src/lib/workspace-manager/setup-marker.ts](/home/eltmon/Projects/overdeck/workspaces/feature-pan-5316/src/lib/workspace-manager/setup-marker.ts), lines 37–45), so its route does not exclude that case. Require the canonical issue workspace path and verify that its resolved path is an actual distinct git worktree before writing; add a symlink-to-primary regression case.

## sharpens-framing: Real-git test omits project registration

WI-2 says the real-git test initializes a primary repo and worktree, then calls the writer, but never adds that repo to `projectRegistry.entries`. The test file resets the registry before each test ([src/lib/xbrief/__tests__/auto-synthesize.test.ts](/home/eltmon/Projects/overdeck/workspaces/feature-pan-5316/src/lib/xbrief/__tests__/auto-synthesize.test.ts), lines 16–35), and `resolvePlanHome` takes a different path when `findProjectByPath` finds a registered project ([src/lib/pan-dir/paths.ts](/home/eltmon/Projects/overdeck/workspaces/feature-pan-5316/src/lib/pan-dir/paths.ts), lines 46–50). Thus the only real-worktree regression would exercise the unregistered fallback, while production `pan start` resolves a registered project. Register the temporary primary repo in that test before synthesis and retain the primary-status and workspace-path assertions.
