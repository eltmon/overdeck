## 1. Glossary

- **FE** — `src/dashboard/frontend/src`. Every frontend path below is relative to it unless it starts with `src/`, `docs/`, `features/`, `scripts/` or `changelog.d/`.
- **Project Home** — the permanent `paneType: 'home'` tab of a project deck. Rendered by `FE/components/Stage/ProjectHome.tsx`, mounted by `FE/components/CommandDeck/index.tsx` (search `renderHome={(api) => (`).
- **Deck key** — the Stage's `api.deckKey` (the selected project's route name; may be a display name). **Project key** — the registered `projects.yaml` key, passed as `ProjectHome`'s `projectKey` prop (`selectedRegisteredProject?.key`). Selectors and API URLs always take the **project key**, never the deck key.
- **Feature** — a `ProjectFeature` (issue row) from `FE/components/CommandDeck/ProjectTree/ProjectNode.tsx`; `ProjectHome` gets them as `features`.
- **Derived state** — `DerivedIssueState` (`packages/contracts/src/derived-issue-state.ts`), from `useDashboardStore((s) => s.derivedIssueStateByIssueId)`. It has `state`, `attention`, `pr { number, checks: 'green'|'pending'|'red'|…, mergeable }`. It has **no** state-entered timestamp.
- **Entry** — a `BucketedFeature` `{ feature, derived, phase }` (`FE/components/CommandDeck/pipeline-helpers.ts`); `phase` comes from `bucketFeaturePhase` (`ProjectOverview.tsx`).
- **Lane** — one group of the Home pipeline: **Building**, **In review**, **Ready to merge**, **Stalled** (§3 G-D5).
- **Needs-you items** — `useNeedsYouItems({ projectKey })` (`FE/lib/selectors/needsYou.ts`, parent D-8). Item keys: `issue:<ID>`, `conversation:<name>`, `agent:<id>`, `flywheel:<hash>`, `decision:<id>`.
- **Agents working** — `useAgentsWorking({ projectKey })` (`FE/lib/selectors/agentsWorking.ts`, parent D-9): `{ count, byRole: Record<'planning'|'building'|'review'|'test'|'conversation'|'other', number>, rows }`. The left column's project switcher shows the same number (`FE/components/frame/ProjectSwitcher.tsx`, search `useAgentsWorking({ projectKey: project.key })`).
- **Project changes API** — `GET /api/projects/:projectKey/changes?since=7d` (child A; `src/dashboard/server/routes/project-changes.ts`, `src/lib/overdeck/project-changes.ts`). Returns `ProjectChanges { projectKey, branch, commits: ProjectCommit[] }`, newest first, first-parent commits of `origin/<default>` (falls back to the local branch), **at most 500** (`MAX_PROJECT_COMMITS`). `ProjectCommit.by = { kind: 'conversation'|'agent'|'unattributed', id?, title? }`; for `conversation`, `id` is the conversation **name**; for `agent`, `title` is the upper-cased issue id when one is in the agent id.
- **Costs summary** — `GET /api/costs/summary?project=<PREFIX>` (`src/dashboard/server/routes/costs.ts`): `{ today: { totalCost }, week: { totalCost }, month }`. Since child A it includes the project's conversation cost events, and "today" starts at the server's local midnight. It needs an issue **prefix**.
- **Release status** — `GET /api/projects/:projectKey/release-status`, already read by `FE/components/Stage/HomePane/ProjectReleasePanel.tsx` under query key `['projectReleaseStatus', projectKey]`.
- **Project CI record** — `useDashboardStore(selectProjectCi(projectKey))` + `deriveProjectCi(record)` from `@overdeck/contracts` → `{ state: 'queued'|'in_progress'|'success'|'failure', completed, total, href }` (see `FE/components/CommandDeck/ProjectCiChip.tsx`).
- **Test-skip gate** — CI gate that fails when the whole diff removes more `it(`/`test(` calls than it adds (`docs/PIPELINE-GATES.md`, "Removed `it(`/`test(` calls are balanced across the whole diff"). Replace removed tests; never add `.skip`/`.only`.

## 2. What Home is today (verified at `c9906c2370a`)

`ProjectHome.tsx` (261 lines) has two branches:
- **Cockpit** (when `features.length > 0 && onSelectFeature`): `HomePane` scaffold with `detailFirst` → `WorkspaceHeader variant="project"` (`# name`, branch `main`, rename pencil) + `StatChips` (placeholder chips + conversation count + lifetime cost) → detail = `ProjectReleasePanel` + `ProjectOverview` beside a TODAY/YESTERDAY `Timeline` aside → `Launcher` (prompt box) → `AgentDock` (Claude Code / Codex / "More Agents" pills; "More Agents" has no handler) → `ActionDock` (Terminal, Files → `api.openDock({tab:'files'})`, Web, Main checkout).
- **Sparse** (otherwise): same header/launcher/docks, `ProjectSettingsDisclosure` as detail, `Timeline` below.

`ProjectOverview.tsx` (492 lines): `HeroBillboard` (Active issues, Stuck, Agents = `features.filter(hasActiveAgentSignal).length`, Ship-ready, Spend), `ProjectCiHealthSection` (PR checks failing / merge blocked / ship-ready / work agents + per-PR blocker list), New workspace button (`data-testid="project-overview-new-workspace"`), `ProjectSettingsDisclosure`, `MergeTrain placement="project"`, then `PipelineSection` (Needs you / Stalled / Lining up to ship / Being reviewed / Being built / Planning / Ready / Todo groups of `PipelineRow` cards with a model-initials avatar, `initialsFor`).

Problems the mockup fixes: launchers sit below the fold; the Agents tile counts work sessions only (it reads 0 while conversations work); spend omits conversations unless it hits the summary; facts disagree with the top bar; the pipeline is cards with unexplained badges; nothing says who changed main.

## 4. Requirements

### Functional
- **FR-1** Home renders one layout with the three states of G-D1.
- **FR-2** Header: title (registered name, `display-lg`) with rename, repo subtitle, Settings modal (G-D2).
- **FR-3** Metadata line: path · branch · release · CI word · deploy · identity (G-D3).
- **FR-4** Action row in the first viewport at 1920×1000 with the actions, keycaps and More ▾ menu of G-D4.
- **FR-5** Start an issue dialog plans or starts through the existing paths (G-D9).
- **FR-6** Five facts from the shared selectors and APIs (G-D10); the Agents working value equals `useAgentsWorking({ projectKey }).count`, the number the project switcher shows.
- **FR-7** Needs you panel per G-D12, from `useNeedsYouItems({ projectKey })`.
- **FR-8** Pipeline as full-width rows in lanes Building / In review / Ready to merge (+ Stalled), with tag, who and age, no avatar (G-D5…G-D8).
- **FR-9** Recent changes on main with attribution and the click behavior of G-D11.
- **FR-10** The removed pieces of G-D14 are gone from Home, and every listed function is reachable from its new home.
- **FR-11** Docs and changelog describe the new Home (WI-12).

### Non-functional
- **NFR-1** No new poll faster than 60 s on Home; reuse query keys so release status and spend share caches.
