# PAN-5472: fix published docs pages that contradict the product

**Issue:** https://github.com/eltmon/overdeck/issues/5472 (part of epic #5467, docs overhaul)

## Summary

Several pages a new user reads first describe features that were removed or never shipped: a
separate `overdeck-state` branch, an inspect agent, a merge agent, an "Approve & Merge" button,
beads, mid-conversation model swaps, checkpoint rollback, Shadow Engineering, public phone apps,
and a God View that is really an experimental view. This PRD fixes those claims on eight published
pages and in `README.md`, retires `configuration/state-branch.mdx` with a redirect, and leaves a
full line-by-line audit of each page to the audit issues (#5499 to #5504) that run after this one.

## Glossary

- **Cloister**: Overdeck's agent watchdog service. `pan admin cloister start|stop|status|emergency-stop`
  controls it (`src/cli/commands/cloister/index.ts:10-38`). It starts with the dashboard by default
  (`startup.auto_start: true`, `src/lib/cloister/config.ts:389`). It does not pick models.
- **deacon-lite**: the patrol loop Cloister runs in a forked child process
  (`src/lib/cloister/deacon-lite.ts:1-22`). Its routines only observe, nudge and recover.
- **Role**: a kind of agent run. Spawned roles are `plan`, `work`, `strike`, `review`, `test` and
  `worker` (`docs/ROLES.md:13-20`). There is no spawned `ship` role: shipping is server-side
  (`docs/ROLES.md:34-38`).
- **Specialist**: the docs' word for the agents that check finished work: the review role and the
  test role. There is no inspect agent, no UAT agent and no merge agent today.
- **Review convoy**: review mode `full`. Four sub-reviewers (security, correctness, performance,
  requirements) run in parallel and the review parent writes the verdict. The default review mode
  is `quick` (`src/lib/config-yaml/roles.ts:43-50`).
- **Verification gate**: the project quality gates that run after `pan done` and before review
  (`docs/PIPELINE-GATES.md`).
- **`.pan/`**: the directory in the project repo (or its plan home) that holds planning artifacts:
  `drafts/`, `specs/`, `continues/`, `orders/`, `notes/`, `backlog/sequence.md`
  (`docs/XBRIEF.md:41-68`).
- **Plan home**: the repo that holds `.pan/` for a polyrepo project, set by `pan_records.repo` in
  `projects.yaml` (`docs/XBRIEF.md:433`).
- **`overdeck-state` branch**: the retired branch that held pipeline state before v0.60.0. It is
  archived and tagged `state-final`. Overdeck no longer reads or writes it
  (`sync-sources/rules/protect-overdeck-state-branch.md`, `docs/XBRIEF.md:41`).
- **Experimental features switch**: Settings → Experimental → **Experimental features**
  (`src/dashboard/frontend/src/components/Settings/sections/ExperimentalSection.tsx:76`). It
  shows the views listed in `EXPERIMENTAL_TAB_IDS`
  (`src/dashboard/frontend/src/lib/experimentalFeatures.ts:4-15`).
- **Home / Project home / Command Deck**: `/` is the Home page
  (`src/dashboard/frontend/src/App/appChromeLabels.ts:16`). The left nav item **Project home**
  opens the selected project's Command Deck on its Home pane. The term "Mission Control" appears
  nowhere in the frontend source.
- **Dash rule**: no U+2013 (en dash) or U+2014 (em dash) anywhere in a touched page, body
  included. Check with `grep -nP '[\x{2013}\x{2014}]' <file>`; no output means it passes. Box
  drawing characters such as `─` (U+2500) in code-block diagrams are not dashes.
