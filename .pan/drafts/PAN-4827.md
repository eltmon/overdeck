# PAN-4827 — Gemini, Qwen and GLM catalog refresh (dead tier ids, new models, prices)

**Issue:** https://github.com/eltmon/overdeck/issues/4827
**Status:** planned (auto mode, 2026-11-02, HEAD `f133009482e`)
**Siblings:** PAN-4825 (MiMo/Groq/Cerebras/MiniMax/xAI/Mistral/Meta/Kimi), PAN-4826 (OpenAI/Anthropic). They edit
other entries in the same files. This issue touches only the `google`, `dashscope` and `zai` providers.
**Follow-up filed:** PAN-4844 (GLM/Qwen sessions mis-priced by the Claude Code and ohmypi cost parsers).

Google's and DashScope's `tierModels` name dead ids today, and Z.AI's name ids Overdeck itself retired. Claude Code
launches export these as `ANTHROPIC_DEFAULT_{OPUS,SONNET,HAIKU}_MODEL`, `ANTHROPIC_SMALL_FAST_MODEL` and
`CLAUDE_CODE_SUBAGENT_MODEL`, so subagents on those providers fail. This PRD fixes the tiers, retires the dead
ids through `MODEL_DEPRECATIONS`, adds four new models, and corrects prices against the official pages.

## Glossary

- **Tier ids:** `PROVIDERS.<name>.tierModels.{opus,sonnet,haiku}` plus `PROVIDERS.<name>.haikuModel`
  (`src/lib/providers.ts`). `getProviderEnv()` (search `if (provider.tierModels && !isKimiCode)`) exports them as
  the Claude Code tier env vars listed above.
- **`MODEL_DEPRECATIONS`:** the single-hop map from a retired id to its live replacement
  (`src/lib/model-deprecations.ts`). `resolveModelId()` (`src/lib/model-capabilities.ts` line 46) applies it.
  `getAvailableModels()` (`src/lib/model-fallback.ts` line 497) and the chat picker
  (`src/lib/settings-model-catalog.ts` line 59) hide every key in it.
- **Provider-retired id:** the provider shut it down or deprecated it. It gets a `MODEL_DEPRECATIONS` row, leaves
  `PROVIDERS.<name>.models`, the settings available list and the Settings-page picker, and keeps its capability and
  cost rows so old transcripts still price.
- **Operator-retired id:** already in `MODEL_DEPRECATIONS` by operator choice (September 2026), e.g. `glm-4.7`.
  It stays retired even though the provider still serves it.
- **Lookup list:** the hard-coded id arrays in `getProviderForModel()` (`src/lib/providers.ts`, e.g. search
  `if (['gemini-4-argon',`). Retired ids stay in these lists so old configs still resolve a provider before the
  deprecation hop (the Kimi K2 precedent, `providers.ts` comment above `PROVIDERS.kimi.models`).
- **`costPer1MTokens`:** the blended price on capability and picker rows, always `(input + output) / 2` USD per
  million tokens (e.g. `gemini-3.1-pro-preview` $2/$12 → 7).
- **Cost row:** a `DEFAULT_PRICING` entry in `src/lib/cost.ts`, per-1K prices. `getPricing()` (line 267) tries an
  exact `provider + model` match, then the first row whose `model` is a prefix of the id.
- **omp registry rows:** `ompProviderDef()` in `src/lib/ohmypi-models.ts` writes the `google` and `dashscope`
  providers into `~/.omp/agent/models.json` at spawn, with their own prices and windows. `google` and `dashscope`
  both default to the `ohmypi` harness (`defaultHarness: 'ohmypi'`), so these rows decide what omp can launch.
- **File-size ratchet:** `scripts/lint-file-size.sh` (ceiling 1000 lines unless allowlisted).
  `src/lib/model-capabilities.ts` is 1422 lines, capped at 1422 (`scripts/file-size-allowlist.txt`, `# PAN-4327`).
  `src/dashboard/server/routes/settings.ts` is 1104 lines, capped at 1104 (`# PAN-3771`). Both accept only
  line-neutral or shrinking edits. `src/lib/model-capability-additions.ts` is 354 lines (ceiling 1000).

## Corrections to the issue text (the official page wins)

1. **`qwen3-max` retires to `qwen3.7-max`, not `qwen3.8-max`.** The official deprecation notice names
   `qwen3.7-max` as the replacement for the `qwen3-max` snapshots, and the bare alias is absent from the Singapore
   price list Overdeck routes to. The opus tier still becomes `qwen3.8-max`, as the issue asks; only the
   `MODEL_DEPRECATIONS` target differs.
2. **`qwen3.8-max`'s context window is 1,000,000**, not 1,048,576 (official model page).
3. **`glm-5.3-flashx` is on the official pricing page**, so the issue's conditional applies and it is added.
4. **`glm-5.3` is the current flagship** (its model page says so), so opus moves to `glm-5.3` too.
5. **`gemini-3-flash-preview` stays the sonnet tier.** The deprecations page lists no shutdown date for it (only a
   recommended replacement), and the issue says to retire it only on a listed shutdown.
6. **`gemini-4-argon` needs no change.** `cost.ts` and its capability row already carry the current $2/$10 rate and
   the 2026-12-01 $4/$20 change as dated comments. The PR body lists it under "verified, already correct".
7. **`gemini-3.6-flash` costs $0.75/$3.75 now**, with the same 2027-01-01 step to $1.50/$7.50 as 3.8 Flash.
8. **`gemini-3.8-flash`'s promotional rate ends 2026-12-31** (new rate from 2027-01-01), as the issue said.

## Decisions (made here, do not re-litigate)

1. **Google tiers:** opus `gemini-3.1-pro-preview` (unchanged), sonnet `gemini-3-flash-preview` (unchanged), haiku
   `gemini-3.1-flash-lite`. Not `gemini-3.5-flash-lite`: the issue names 3.1 Flash Lite and Google lists it as the
   preview's replacement. Its 2027-05-07 shutdown goes in a dated comment.
2. **DashScope tiers:** opus `qwen3.8-max`, sonnet `qwen3.7-plus`, haiku and `haikuModel` `qwen3.8-flash`.
3. **Z.AI tiers:** opus `glm-5.3`, sonnet `glm-5.3`, haiku and `haikuModel` `glm-5.3-flash`.
4. **New `MODEL_DEPRECATIONS` rows:** `gemini-3.1-flash-lite-preview → gemini-3.1-flash-lite`,
   `qwen3-coder-plus → qwen3.7-plus`, `qwen3-max → qwen3.7-max`, `qwen3-plus → qwen3.8-flash` (operator mapping;
   the id never existed).
5. **Retired ids keep** their capability rows (with `(deprecated)` added to `displayName`, in place), their lookup-list
   entries, their `settings.ts` union members, their `MODEL_PROVIDERS`/`FALLBACK_MAP`/class rows, and any cost row.
   They leave `PROVIDERS.<name>.models`, the `settings.ts` available list, the Settings-page catalog and the omp
   registry rows.
6. **New models:** `gemini-3.6-flash` (class `workhorse`), `gemini-3.1-flash-lite` (`small`), `glm-5.3-flash`
   (`small`), `glm-5.3-flashx` (`small`). Each fallback is `claude-haiku-4-5`. Capability rows go in
   `model-capability-additions.ts`, multi-line, after the neighbor of the same provider.
7. **Capability values for new rows:**
   - `gemini-3.6-flash`: displayName `Gemini 3.6 Flash`, `costPer1MTokens: 2.25`, `contextWindow: 1048576`,
     `maxOutputTokens: 65536`, skills copied from the `gemini-3-flash-preview` row, no `effortLevels`.
   - `gemini-3.1-flash-lite`: displayName `Gemini 3.1 Flash Lite`, `costPer1MTokens: 0.875`,
     `contextWindow: 1048576`, `maxOutputTokens: 65536`, skills copied from the `gemini-3.1-flash-lite-preview` row.
   - `glm-5.3-flash`: displayName `GLM-5.3 Flash`, `costPer1MTokens: 0.325`, `contextWindow: 1000000`,
     `effortLevels: ['low', 'high', 'max']`, `supportsImages: true`, skills copied from the `glm-4.7-flash` row.
   - `glm-5.3-flashx`: displayName `GLM-5.3 FlashX`, `costPer1MTokens: 0.81`, otherwise the same as `glm-5.3-flash`.
8. **Prices with a dated change use the current rate** and carry a comment naming the date and the next rate.
   `qwen3.7-plus` records the ≤256K rate and says the rate is a limited-time 20% discount.
9. **Qwen cost rows are added** to `cost.ts` (`provider: 'custom'`) because the pi reconciler reaches them.
   Parser routing for the Claude Code and ohmypi parsers is PAN-4844, not this issue.
10. **The omp registry rows follow the catalog:** live prices, the two new Gemini ids added to the `google` def
    (whether omp's bundled catalog already has them could not be confirmed from the installed binary; a user-registry
    row is harmless either way), the three retired Qwen rows removed.
11. **`routes/settings.ts` gets line-neutral fixes only** (file at its 1104 cap). The four legacy Google
    `MODEL_API_IDS` rows point at their `MODEL_DEPRECATIONS` targets (and `gemini-3-flash-preview` at itself); the
    three retired Qwen rows point at their new targets. The Google and DashScope model-test lookups fall through to
    the selected id (`|| model`) instead of a hard-coded dead id; with no selected model they probe
    `gemini-3.5-flash-lite` and `qwen3.8-flash` (cheapest live ids with no announced shutdown).
12. **`FALLBACK_MAP` gaps for existing ids** (`gemini-3.8-flash`, `gemini-3.5-flash-lite`, `glm-5.3`,
    `qwen3.7-plus`, `qwen3.8-flash`) are pre-existing and stay as they are.
