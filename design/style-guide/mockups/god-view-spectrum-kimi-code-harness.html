This deck renders a real snapshot of Overdeck captured at build time — 26 running agents, issue ids, roles, models, review convoys, staleness and system load from pan status, /api/activity, /api/godview/system-health and bd stats (2026-08-01 ~15:52 UTC) — then drives it with a built-in event simulator so it never sleeps. In production this same layout would be event-driven, not polled: harness hooks POST to /api/agents/:id/heartbeat → event store → PubSub → /ws/rpc + SSE /events/stream → dashboard store.

THE STAGE · PIPELINE LANES

  • Each orb is a live agent, placed in its pipeline lane: PLAN → WORK → REVIEW → TEST → MERGE. Gate chevrons sit between lanes.
  • Ring color = role: blue plan · green work · pink review · amber test · red strike · purple flywheel · orange sequencer.
  • GLetter in the core = model: S sonnet · G gpt-5.6 · O opus · F fable · K k3 (kimi).
  • Label below = issue id · role · runtime. The fading ribbon behind an orb is its recent path.
  • The two large portals above the lanes are the orchestrators: flywheel (RUN-79) and the sequencer.

READING THE MOTION

  • Gentle wave drift = working normally. Orbs bob on sine waves; busier orbs pulse brighter.
  • A fast lateral glide into the next lane + a blue flash at the gate = stage transition (e.g. plan → work).
  • Small pink moons spiraling in = review convoy forming; moons in orbit = convoy actively reviewing (MIN-839 has three).
  • A very fast upward comet = the issue merged — merge-queue flush, then it respawns in PLAN with a fresh issue from the ready pool.
  • Sudden flight to the dashed PARKED shelf (bottom right) = the scheduler paused/yielded that agent to free resources for another issue's review cycle. It resumes on its own.
  • Orb contracts then flashes orange = context compaction (PreCompact → PostCompact). Amber dashed ring = waiting on a permission/question. White inner arc = thinking. Rising $ = cost events.

FROST = STALENESS

  • An orb that stops emitting events slowly frosts over: colors desaturate to ice, a frost crown grows, snow falls. Any activity thaws it instantly.
  • MIN-864 in TEST is deep-frozen — its test agent has shown no life for 1.8 days. PAN-3367 is a slow worker that frosts and thaws. PAN-3362 flickers red: its stack is broken.

HOOK BUS · AGENT HARNESS

  • Every wired harness hook fires here: LED flash + running count. PreToolUse and PostToolUse dominate — that's the fast pace of tool calls.
  • Dotted names = hook events that exist upstream in the harness but are not wired into Overdeck yet — dark fiber. e.g. InstructionsLoaded fires when a CLAUDE.md / rules file loads into context; SubagentStart/Stop bracket subagent lifetimes.

BOTTOM STRIP · WINAMP SECTION

  • Spectrum analyzer: 56 bands keyed to hook categories (PreToolUse ▸ … ▸ Cost). Every real event spikes its band; white caps are falling peak-holds.
  • Oscilloscope: aggregate event energy over the last few seconds — the deck's heartbeat.
  • The glowing waveform ribbon across the stage is the same signal drawn large: amplitude = total events/s across all agents, color follows the lane gradient. Calm pipeline = low ripple; storm = tall waves.
