Style guide v2 · the Broadsheet theme

Pages, not panels.

Style v2 ships as a selectable theme, not a cutover. The current style becomes Ledger — DM Sans, flat weight, panel-first — and stays as a first-class legacy option. The new style is Broadsheet: Geist, a real weight hierarchy with display tiers, chips, soft cards, hero placeholders, keycap CTAs, and dot-metadata lines. Color discipline, semantic tokens, and the badge tint formula are identical in both — this is a typography revision, not a rebrand.

00 · The setting — Overdeck Theme

One picker, two design languages

Settings → Appearance gains an Overdeck Theme picker (ui.theme in ~/.overdeck/config.yaml, default broadsheet). The choice is carried by a single data-theme attribute on the document root, so switching is instant — no restart, no rebuild. Click either card to flip this whole page between the two themes.

01 · Typefaces — D-1

Geist & Geist Mono, self-hosted

One variable woff2 per family, self-hosted with licenses — Geist + Geist Mono for Broadsheet, DM Sans + Space Grotesk for Ledger, all four shipping with the app (~350KB total). The Google Fonts <link> is removed: zero external font requests in either theme.

Before · DM Sans, capped at 500
Review convoy synthesizes four findings
Every surface sets the same weight, so hierarchy comes from size alone. Nothing can read as a page — everything reads as a panel. Mono is reserved for identifiers only.

02 · Weight hierarchy & display scale — D-2, D-3

No bold outside its tier

The old rule “no bold anywhere” becomes “no bold outside its tier.” Display tiers are the only place weights above 600 may appear, and they are named theme utilities, never ad-hoc arbitrary values.

TierSampleWeightUse
display-xl Untitled workspace 700–800 page heroes, hero-editable titles
display-lg Pipeline overview 650–700 section heroes, view headers
heading Merge queue 500–600 section & card headings
body / ui The default weight for everything else. 400–500 body text, nav, buttons, labels
eyebrow Getting started 500 mono kickers, categories, quiet buttons
03 · New patterns — D-4 through D-9

The vocabulary the guide was missing

Six patterns, each with a copy-paste class recipe in the law file. Live renderings below — the input and cards on this page are functional.

Hero placeholderD-4
A chromeless editable title — no border, no fill at rest — whose placeholder renders at full display size in muted/40 ink. The name of the thing becomes the page.
Chips · default, dashed, selectedD-6
Bordered rounded-lg pill-adjacent buttons with a leading 16px icon. border-dashed marks the additive action; selection is a strengthened border plus subtle fill. Hover changes fill only, never color.
Soft cardD-7
A rounded-xl card with a muted fill, optional hairline border, and generous padding — an eyebrow category over a short title. The sanctioned pattern for suggestion, idea, and preview cards.
Large CTA + keycapD-8
A new cta tier: h-12, rounded-xl, soft primary fill at rest, solid on hover. Optional trailing keycap hint. One per view — the single-primary rule is unchanged.
Dot-metadata lineD-9
Memory enabled · Files shared · git repository
A 6px semantic status dot plus quiet Geist Mono text, segments separated by ·. For ambient state summaries — never for anything that demands action.
Eyebrow labelD-5
Ideas for your next workspace Cancel
Uppercase Geist Mono, 11px, wide tracking, muted. Sanctioned as card categories, kicker labels, and quiet text-buttons. This deliberately widens mono beyond identifiers — the mono rule is rewritten to name both uses.

05 · What does not change — D-11

The restraint stays

Stated verbatim in both docs so agents don't over-rotate.

Semantic tokens only — no hardcoded hex, no bg-gray-*, no decorative color.
Color discipline — one colored signal per row; amber / blue / emerald / red keep their meanings.
Badge tint formula — 8% bg / 32% border stays; radius moves rounded-sm → rounded-md as the single deliberate texture change. WorkReviewDone
Single primary CTA per view — the new large cta tier obeys the same rule.
Depth through tonal shifts — borders stay hairline, shadows stay absent.
06 · Page-not-modal doctrine — D-10

Creation flows are pages

Major creation and composition flows render as routed full pages; modals are reserved for confirmations and quick forms of four fields or fewer. PAN-3411 executes this for workspace creation — open its mockup to see every pattern on this page composed into a real surface.
