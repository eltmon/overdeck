# PAN-3254 — Review/test pipeline re-drove one issue 426 times; document the landed fix

## Glossary

- **Anchor** — the commit identity a review verdict was stamped against. Two shapes exist: a **bare** anchor (single wrapper-repo SHA, e.g. `7492ae82`) and a **composite** anchor (space-separated `repoKey@sha` tokens for a polyrepo workspace, e.g. `fe@aaa api@bbb`).
- **Drift evaluator** — `evaluateWorkspaceAnchorDrift()` in `src/lib/workspace-anchor-drift.ts`; compares the stamped `reviewedAtCommit` anchor against a fresh workspace snapshot and returns `unchanged | benign | drifted | unreadable`.
- **Post-review patrol** — `checkPostReviewCommits()` in `src/lib/cloister/deacon-post-review-commits.ts`; a Deacon patrol that resets a passed/blocked review to `pending` when the drift evaluator reports real code drift.
- **Repeat-reset bound** — the PAN-3254 guard in the patrol: at most one reset per distinct current anchor; a second `drifted` verdict against the same anchor is suppressed and escalates one needs-you.
- **Needs-you** — an operator-facing escalation recorded via `recordDeadEndNeedsYou()` (`src/lib/cloister/dead-end-trip.ts:4`); it surfaces on the dashboard instead of looping silently.

## Background — the incident and the fix that already landed

MIN-901 cycled review→test 426 times in 19.5 hours (≈ every 100 s), each cycle passing with "Approved unchanged review / Skipped: no code changed", then being reset to `pending`. Three sibling MYN issues (MIN-891, MIN-902, MIN-858) showed the same signature. This churn drove the storage blowup in PAN-3253.

**Root cause** (established, not speculative): the post-review patrol compared a polyrepo **composite** `reviewedAtCommit` against a **bare** wrapper-HEAD snapshot. The shape mismatch was reported as `drifted` before any content comparison ran, and since the wrapper HEAD never moves, the patrol reset review every ~60 s forever. The candidate drivers listed in the issue (merge watchdog, rebase trigger) were ruled out.

**The fix landed on main in `fb99ed40fa`** (2026-07-28, operator-directed direct work, confirmed ancestor of `feature/pan-3254`), in four layers:

1. `src/lib/workspace-anchor-drift.ts:88` — a composite/bare SHAPE disagreement now returns `{ kind: 'unreadable' }` (verdict preserved), never `drifted`.
2. `src/lib/project-repos.ts` — polyrepo sub-repo dirs resolve by `repoKey` OR `repoPath`, so composite snapshots resolve for MYN's path-based layout.
3. `src/lib/git-utils.ts` — a >1-repo config resolving zero sub-repo roots refuses to snapshot the wrapper HEAD (`undefined` → unreadable) instead of fabricating a bare anchor.
4. `src/lib/cloister/deacon-post-review-commits.ts:117-128` — the repeat-reset bound: `lastResetAnchors` records the current anchor at each reset; a second `drifted` verdict against the same anchor is suppressed and escalates once via `recordDeadEndNeedsYou(issueId, 'review-reset-loop', …)`. A genuinely new anchor still resets. Bound state is **process-local** (in-memory Maps, cleared on merge and on dashboard restart) — an accepted backstop, since the primary driver (shape-mismatch-as-drift) is eliminated at layer 1.

**Test coverage already landed** (all in `fb99ed40fa`, one stale-test update in `08ade63d62`):

- `tests/unit/lib/workspace-anchor-drift.test.ts:129` — "treats an anchor SHAPE mismatch as unreadable, never drifted (PAN-3254)".
- `tests/unit/lib/cloister/deacon-post-blocked-review-commits.test.ts:302` — "resets once for a static current anchor, then suppresses and escalates instead of looping" (literally replays the MIN-901 signature: passed review, static anchor, repeated patrols → one reset, one `review-reset-loop` needs-you, no further dispatches).
- `tests/unit/lib/cloister/deacon-post-blocked-review-commits.test.ts:332` — "a genuinely new current anchor still resets and re-dispatches after suppression".

This maps 1:1 onto the issue's acceptance criteria: unchanged branch re-drive is a no-op (layer 1 + bound), a per-commit cycle bound with needs-you escalation exists (layer 4), and replaying MIN-901 conditions yields ≤1 cycle, not 426 (test at line 302).
