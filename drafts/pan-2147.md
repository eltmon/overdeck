# PAN-2147 — Decompose `src/dashboard/server/routes/agents.ts` (4071 lines)

**Type:** Refactor · codebase-health · behavior-preserving.
**Flywheel objection (honored):** hot-path pipeline-runtime machinery (start-agent / spawn / live-control). Supervised handoff only; no autonomous parallel pickup. Every seam keeps the FULL suite green.

## Glossary
- **Target file** — `src/dashboard/server/routes/agents.ts`, 4071 lines, an Effect `HttpRouter.Layer` module implementing all `/api/agents/*` endpoints. Exported publicly: `agentsRouteLayer` (default + named), plus helper functions consumed by co-located tests.
- **Barrel** — after decomposition, `routes/agents.ts` becomes a thin entry that (a) imports each route Layer from `routes/agents/*.ts`, composes them into `agentsRouteLayer` via `Layer.mergeAll`, and (b) `export … from './agents/*.js'` re-exports every symbol it currently exports, so all importers and tests resolve unchanged.
- **Move + re-export** — relocate declarations verbatim into `routes/agents/<seam>.ts`; the barrel re-exports them. This is the established repo pattern (see `docs/codebase-health/B3-agents-queries-extract.md`, `B-agents-decomp.md` — same technique applied to `src/lib/agents.ts`).
- **File-size guard** — `scripts/lint-file-size.sh` (in `npm run lint`), CEILING=1000. `scripts/file-size-baseline.txt` currently holds `4071 src/dashboard/server/routes/agents.ts`. Shrinking the file makes the baseline **stale → lint fails** until `bash scripts/lint-file-size.sh --update` lowers/drops it (`--update` only lowers/drops, never raises). New files >1000 fail the guard; new files ≤1000 need no baseline entry.
- **A1 any-ratchet** — ESLint `no-explicit-any` is enforced except for files listed in `eslint-any-allowlist.json`. `routes/agents.ts` is currently allowlisted (24 `any` occurrences). A new module that receives moved `any` code must be added to the allowlist in the same commit.
- **state-write guard** — `scripts/lint-state-writes.sh`. Not triggered here (this file writes no agent-state via the guarded writer), but keep `npm run lint` fully green.

## Problem
`routes/agents.ts` is a 4071-line god file on the pipeline hot path. It mixes ~40 route handlers (list, conversation, messaging, permissions, runtime-event ingestion, lifecycle control, spawn) plus ~600 lines of shared helpers in one file. It is baselined shrink-only by the file-size guard but sits far above the 1000-line ceiling.

## Proposal
Extract cohesive route clusters into a sibling directory `src/dashboard/server/routes/agents/`, leaving `routes/agents.ts` as a thin barrel. Each new module < 1000 lines. Pure relocation + re-export; the only structural deviation is the spawn handler (below). One seam per bead, serialized, each independently green.

## Non-goals
- Any logic change, renamed export, or changed HTTP behavior. Behavior byte-identical.
- Decomposing `src/lib/agents.ts` (a different file) or other route files.
- Refactoring the spawn handler's *logic* — only physically relocating its self-contained inner blocks.
- Changing the `Layer.mergeAll` route set — all 41 routes must remain composed (no-loss audit gate).
- Editing importers or tests (barrel re-export keeps them resolving) — except a test that a bead demonstrably breaks.

## Planning Q&A
_Auto mode — no interactive questions. Inferred decisions:_

- **AD1 — sibling `agents/` dir + barrel re-export.** Matches the repo's own established B3/agents-decomp move+re-export pattern; zero call-site churn.
- **AD2 — spawn handler is split, not byte-moved.** `postAgentsRoute` (~1094 lines) exceeds the 1000 ceiling alone; relocating only top-level declarations cannot fix it. Its container-orchestration and remote-spawn inner blocks are extracted into `agents/spawn-helpers.ts` as parameterized, behavior-preserving functions. This is the single deviation from "pure move," required by the ceiling. Deep-inspected.
- **AD3 — seams serialized.** Every seam edits the barrel `agents.ts`; parallel execution would conflict. Linear `blocks` chain; `readiness: sequential`. Consistent with the supervised-handoff objection (no autonomous parallel pickup).
- **AD4 — zero test repointing.** All co-located tests (`__tests__/agents-*.test.ts`) import via the barrel `../agents.js`; the re-export keeps them green. Repoint a test only if a specific move demonstrably breaks it.
- **AD5 — guard housekeeping per seam.** Each shrinking seam runs `bash scripts/lint-file-size.sh --update` (the sanctioned workflow the guard itself prints) and adds any new module carrying moved `any` to `eslint-any-allowlist.json`.
