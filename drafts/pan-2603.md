---

## Glossary

- **Docs RAG** — the PAN-1203 feature: a prebuilt SQLite index of Overdeck's own docs/skills/rules, queried at prompt time to inject relevant snippets into agent prompts.
- **Live index path** — `~/.overdeck/docs/index.sqlite`, resolved by `getDocsIndexPath()` (`src/lib/paths.ts:221`). This is the ONLY path the query layer reads (`src/lib/docs/query.ts:78`).
- **Dist artifact** — `<packageRoot>/dist/docs-index.sqlite`, `DEFAULT_DOCS_INDEX_PATH` (`src/lib/docs/index-builder.ts:11`). What `scripts/build-docs-index.mjs` writes today.
- **Prompt gate** — `evaluateDocsPromptGate()` (`src/lib/docs/state.ts:95`): enabled-check → disable-scopes → trigger regex match → budget check. Returns `{ shouldInject, reason }`.
- **Injection hook** — the Claude Code `UserPromptSubmit` hook script `sync-sources/hooks/user-prompt-submit-hook`, which POSTs to `/api/memory/inject` and prints the returned `context` to stdout; Claude Code appends hook stdout to the prompt context.
- **SKIP_DOCS_INDEX** — env flag honored by `scripts/build-docs-index.mjs:9` and set in CI (`.github/workflows/ci.yml:15`), release (`.github/workflows/release.yml:129`), and workspace builds (`src/lib/launcher-generator.ts:241`, PAN-1659/PAN-1678).

## Verified current state (2026-07-12 audit of this workspace)

The issue's premise is partially wrong. Verified against the code:

| Issue claim | Reality |
|---|---|
| "Zero callers" | **Wrong.** `pan docs query/reindex/disable/enable` is registered (`src/cli/index.ts:609`, `src/cli/commands/docs.ts`); `src/index.ts:10-13` exports the lib. |
| "`build-docs-index.mjs` not wired into build" | **Wrong.** `npm run build` → `scripts/build-post-cli.mjs:18` runs `build:docs-index` (skipped only under `SKIP_DOCS_INDEX=1`). |
| "UserPromptSubmit hook never injects docs" | **True.** `evaluateDocsPromptGate`/`recordDocsInjection`/`recordDocsTelemetry` (`src/lib/docs/state.ts`) have zero callers outside the lib. The hook route does no docs work. |
| "No ops doc" | **True.** No `docs/DOCS-RAG.md`. |

**Root defect (why everything is dead):** path mismatch. The builder writes the dist artifact; the query layer reads the live index path; nothing copies between them (`pan install` has no docs logic, contrary to PAN-1203 PRD §Install). `queryDocsIndex` swallows every error (`src/lib/docs/query.ts:91-92` `catch { return { query, results: [] } }`), so `pan docs query` silently prints nothing — verified live on this machine. Additionally the release workflow sets `SKIP_DOCS_INDEX=1` and `package.json` `files` excludes `docs/` and `skills/`, so published packages have neither index nor corpus — docs RAG is a **source-checkout-only** feature today, and this plan keeps it that way.

## Keep-vs-kill decision

**Keep.** Rationale: (1) the lib, CLI surface, config schema (`docs.*` in `src/lib/config-yaml/defaults.ts:77`), budget/telemetry, and tests are complete — the remaining delta is materialization + one route wiring + a doc; (2) the kill path is much larger than the issue assumed (CLI command, config schema, gitignore entries, `pan docs query` advertised in the agent briefing, skills); (3) the hook already has a proven injection pattern (`/api/memory/inject` → stdout) that docs can join with ~1 service call.

## Requirements

- **FR-1** `node scripts/build-docs-index.mjs` (i.e. an un-skipped `npm run build`) materializes the live index in addition to the dist artifact.
- **FR-2** `pan docs reindex` rebuilds the index directly at the live index path, in-process (no dependency on `scripts/` existing).
- **FR-3** A thin injection service in `src/lib/docs/injection.ts` composes gate → query → budget-bump → telemetry → formatted `<overdeck-docs>` block.
- **FR-4** `POST /api/memory/inject` appends the docs block to the returned `context` when the gate passes, exactly once per request.
- **FR-5** `pan docs query` prints a stderr hint naming the resolved index path and `pan docs reindex` when the index file is absent (stdout contract unchanged).
- **FR-6** `docs/DOCS-RAG.md` documents build/refresh/consumption/config/troubleshooting; the PAN-1203 PRD status header is updated.
- **NFR-1** The injection path adds no network calls and no model loads — local SQLite + two small JSON state files only (the hook's curl timeout is 1 s: `sync-sources/hooks/user-prompt-submit-hook:49` `-m 1`).
- **NFR-2** No test may download the gte-small embedding model — always inject a fake embedding provider (pattern: `src/lib/docs/__tests__/index-builder.test.ts`).
- **NFR-3** No fallback read paths: the query layer keeps exactly one canonical index location (no-bandaids rule — fix materialization, don't add a dist-path fallback in `queryDocsIndex`).

### WI-1 — `pan docs reindex` builds in-process to the live index path (FR-2)

**Files:** `src/cli/commands/docs.ts` (reindex action, lines 52-62), test under `src/cli/commands/__tests__/`.

```ts
.action(async () => {

```

After (in-process build straight to the live path; `buildDocsIndex` already does tmp-file + atomic rename):

```ts
.action(async () => {
  const { buildDocsIndex, DEFAULT_DOCS_INDEX_MAX_BYTES } = await import('../../lib/docs/index-builder.js');
  const { getDocsIndexPath, packageRoot } = await import('../../lib/paths.js');
  const result = await buildDocsIndex({
    outputPath: getDocsIndexPath(),
    rootDir: packageRoot,
    maxIndexBytes: DEFAULT_DOCS_INDEX_MAX_BYTES,
  });
  console.log(`Built docs index at ${result.outputPath} (${result.chunkCount} chunks, ${result.sizeBytes} bytes)`);
});
```

Test: with `OVERDECK_HOME` pointed at a temp dir and a fake embedding provider, the reindex code path creates `<tmp>/docs/index.sqlite` and a follow-up `queryDocsIndex({ indexPath })` returns rows. ### WI-3 — injection service `src/lib/docs/injection.ts` (FR-3) — foundation, inspect

**Files:** `src/lib/docs/injection.ts` (new), `src/lib/docs/__tests__/injection.test.ts` (new), re-export from `src/index.ts` alongside the other docs modules.

```ts
export interface DocsInjectionOptions {
  prompt: string;
  sessionId?: string | null;
  projectPath?: string | null;
  config?: NormalizedDocsConfig;          // resolved docs config; defaults via getDefaultDocsConfig()
  paths?: DocsPathOverrides;              // test seam
  now?: Date;                             // test seam
}
export interface DocsInjectionResult {
  injected: boolean;
  context: string | null;                 // the <overdeck-docs> markdown block when injected
  reason?: DocsGateReason;                // gate reason when not injected
}
export async function buildDocsInjectionContext(options: DocsInjectionOptions): Promise<DocsInjectionResult>
```

Behavior, in order: (1) `evaluateDocsPromptGate` — on `shouldInject === false` return `{ injected: false, context: null, reason }` with **no** budget bump or telemetry; (2) `queryDocsIndex({ query: prompt, config, indexPath: paths?.indexPath })` — on zero results return `{ injected: false, context: null }` with **no** budget bump (an empty query must not consume budget); (3) otherwise `recordDocsInjection` + `recordDocsTelemetry`, return `{ injected: true, context: formatDocsQueryMarkdown(result) }`. Never throw — wrap in try/catch returning `{ injected: false, context: null }` (the hook path must never 500 because of docs).

Tests (temp `DocsPathOverrides` dirs, fixture index built with fake embeddings): gate-off (docs disabled), no trigger match, budget exhausted, missing index (silently no-inject), happy path (context contains `<overdeck-docs>` and budget state advanced), empty-results path does not advance budget.

## Intersecting repo rules (restated for the executor)

- **Fake timers** for any retry/delay test (`vi.useFakeTimers()`); none expected here, but budget/`now` seams already accept an injected `Date` — use it instead of sleeping.

2. `node scripts/build-docs-index.mjs` (dist present, no SKIP flag) produces both the dist artifact and the live index (WI-2).
