## 1. Summary

The god view's center canvas is empty. This PRD replaces it with **The River**: a real-time, GPU-shader-driven visualization of the entire Overdeck pipeline, styled deliberately like an old-school Winamp visualizer — motion, glow, particles, and a spectrum analyzer — rather than like the rest of the (style-guided) dashboard. The operator has explicitly exempted this surface from the style guide; the existing god-view theme (`theme.css`, PAN-341 lineage) is the design law here.

A complete, working reference implementation exists as a committed mockup. **Appendix A of this PRD contains that implementation verbatim** (HTML + CSS + the full JS engine), and **Appendix B contains the live data snapshot** it renders. The production work is: port the engine to React modules, delete the event simulator, and wire the real data surfaces (DashboardStore + the PAN-800 hook-event ingestion fanout) into the exact same data shapes the mockup already consumes.

The mockup is the spec. Where prose and Appendix A disagree, **Appendix A wins**.

## 2. Glossary

- **River** — the luminous canal occupying the center canvas, flowing left→right through six stage columns.
- **Stage column** — one of `PLAN · WORK · REVIEW · TEST · VERIFY · MERGE`. Each issue orb lives in the column of its pipeline stage.
- **Orb** — one glowing sphere per in-pipeline issue, labeled with its issue ID. Core color = role working it; ring color = project; size/glow = activity heat.
- **Hook event** — one harness hook beat: PreToolUse/PostToolUse per tool call, Stop, Notification, UserPromptSubmit, PreCompact, SessionStart. In production these arrive via the PAN-800 ingestion path (§4 refs R-8…R-11).
- **Hook family** — spark color bucket: `tool_read` (Read/Grep/Glob/TLDR), `tool_write` (Edit/Write/NotebookEdit), `tool_exec` (Bash/Task), `tool_web` (WebFetch/WebSearch), `tool_agent` (Agent/SendMessage), `lifecycle` (Stop/Notification/UserPromptSubmit/PreCompact/SessionStart).
- **Heat** — 0..1 activity level of an orb; drives glow, orbit frenzy, and decay.
- **Convoy** — the review fan-out for one issue: satellites `security/correctness/performance/requirements` plus `synthesis`, orbiting the issue nucleus.
- **Shelf** — the amber strip above the Doldrums holding paused/yielded agents, with the yield reason attached.
- **Tide** — the amber sweep crossing the river when the preemptive scheduler or memory governor yields an agent to free a slot.
- **Doldrums** — the frosted bottom strip where stale issues (no hook activity ≥ threshold) sink, ice over, and show idle age.
- **Portal** — the white vertical slit at the right edge representing `main`; merges exit through it as comets.
- **Wreck** — a merge-failed issue: blinking pink hull parked near the portal.
- **Flywheel sun** — the purple pulsing sun top-left representing the flywheel orchestrator; pulses on dispatch.
- **Constellation** — one twinkling star per live `conv-*` conversation session.
- **Hook spectrum** — the bottom analyzer: per-hook-family event-rate bars with falling peak caps.
- **Cast vs motion** — the *cast* (which orbs exist, their stages/states/ages) is real data; the *motion* (sparks, choreography) in the mockup is simulated. Production makes the motion real too.

## 6. Data flow: from store to orb

`useRiverData` builds the same `SNAP` shape the mockup consumes (Appendix B):

- **orbs**: for each in-pipeline issue (pipeline-membership resolver output already in the store), join: agents on the issue (role, model, harness, status, paused, pausedReason, lastActivity), review/merge status (stage mapping below), issue title/labels/project. Classification (mirrors `spawnOrb` + `positionOrb`):
  - `paused || yieldedByScheduler` → `state: 'shelf'`, `yieldReason: pausedReason`.
  - `mergeStatus === 'failed'` → `state: 'failed'`.
  - `now - lastActivity ≥ 30 min` (and not shelf/failed) → `state: 'stale'`, `staleMin`.
  - else `state: 'active'`.
  - **Stage mapping**: planning agent running → `PLAN`; review agent/convoy running → `REVIEW`; test agent running → `TEST`; `mergeStatus` in `queued/merging/verifying` → `VERIFY`; `merged` and close-out pending → `VERIFY`; otherwise → `WORK`. (Checkpoint: if the store exposes a canonical per-issue pipeline stage already, use it instead — see D-2.)
  - **Convoy**: agents whose id matches `<issue>-review[-<sub>]` → satellite list; `review` parent → `synthesis`.
- **hook stream**: domain events `agent.activity_changed` carrying `tool` → map tool name to hook family (`HOOKS` table in Appendix A) → ring buffer of 500, plus per-family `specRates` bump-and-decay, plus the 60 s `eventTimes` window for events/min. Lifecycle beats (Stop/Notification/etc.) arrive via the same event type with no `tool` or via dedicated kinds — map to `lifecycle`.
- **merges today / tokens today**: merges from `recentActivity` merge entries since local midnight (fallback: count from review_status rows); tokens from the cost surface already feeding the Costs tab (read-only selector — do NOT add a new cost pipeline).
- **conversations**: count of live `conv-*` sessions (the store slice the Command Deck uses).
- **system**: `selectSystemHealth` (already on the god view).

### WI-4 — real event choreography (replaces the simulator) (FR-3…FR-8)

**What:** translate live data changes into the canvas effects, deleting every simulated behavior.

**Files:** NEW `…/river/useRiverChoreography.ts`.

**Rules (decisions are made here — do not re-litigate):**

1. Hook event for issue X → `emitSparks(X, family)`, heat bump +0.06 (decay unchanged), `specRates[family] += 0.13`, 13% chance of ticker (`<id> · <tool>`), 16% chance of feed-style ticker — same constants as Appendix A's `fireHookEvent`.
2. Orb's stage changes between renders → ring + burst in the new stage color and the orb swims (the existing lerp does the swim; no extra code).
3. `mergeStatus → merging` → `playMerge` (comet). `→ failed` → orb reclassifies to wreck via WI-2 (no animation needed beyond the wreck render).
4. Agent paused with `yieldedByScheduler` (or `pausedReason` starting `yield:`) → `playTide(yielded, beneficiary)` where beneficiary = the issue whose review/test dispatch the governor log names if derivable, else the most recently admitted review orb; if none, tide plays with no beneficiary.
5. Shelf orb unpaused → green ring + burst (`▶ resumed`), orb swims back to WORK.
6. Stale orb with fresh hook event → `playThaw`.
7. `agent.created` with role plan (flywheel dispatch) → `pulseSun()` + `spawnFromSun`.
8. **Nothing runs on a timer.** No `nextTransition`, no `nextTide`, no `nextThaw`. Ambient motion (bob, orbit, waves, spectrum idle sine, sun pulse, constellation twinkle) continues — it is a pure function of `simT`.

**Tests:** a dispatch table test — feed scripted event sequences, assert the effect calls (mock the canvas API object). Fake timers for any debounce.

function pickWeighted(arr, w) {
  let s = 0;
  for (let i = 0; i < arr.length; i++) s += w(arr[i]);
  let r = Math.random() * s;
  for (const a of arr) { r -= w(a); if (r <= 0) return a; }
  return arr[arr.length - 1];
}

function fireHookEvent(orb) {

/* preemption tide — the governor pauses one agent so another can run */
const tide = { active: false, x: 0, target: null, beneficiary: null, t: 0 };
function startTide() {
  const candidates = orbs.filter(o => o.state === 'active' && o.stage === 'WORK' && !o.merging);
  const shelved = orbs.filter(o => o.state === 'shelf');
  if (!candidates.length) return;
  tide.target = candidates[Math.floor(Math.random()*candidates.length)];
  tide.beneficiary = shelved.length ? shelved[0] : orbs.filter(o => o.state === 'active' && o.stage === 'REVIEW')[0] || null;
  tide.active = true; tide.x = L.padX - 40; tide.t = 0;
  feed('yield', `preemptive scheduler — yielding ${tide.target.id} to free a slot`, null);
}
function tidePass(orb) {
  if (orb === tide.target && orb.state === 'active') {
    orb.state = 'shelf'; orb.yieldT = 0;
    burst(orb.x, orb.y, '#ffb800', 20, 70, 1.2, 2.2);
    ring(orb.x, orb.y, '#ffb800', 60, 2);
    feed('yield', `⏸ paused · slot freed`, orb.id);
  }
  if (orb === tide.beneficiary && orb.state === 'shelf') {
    orb.state = 'active'; orb.stage = 'WORK'; orb.role = 'work'; orb.yieldReason = null; positionOrb(orb);
    ring(orb.x, orb.y, '#39ff14', 80, 3);

    feed('work', `▶ resumed — work agent re-dispatched`, orb.id);
  } else if (orb === tide.beneficiary && orb.state === 'active') {
    orb.heat = 1;
    ring(orb.x, orb.y, '#39ff14', 70, 2.5);
    feed('review', `review dispatch admitted into freed slot`, orb.id);
  }
}

/* ════════════════════════ RENDER ════════════════════════ */
let last = performance.now(), simT = 0;
let nextTransition = 5, nextTide = 16, nextThaw = 24, nextConvoyPulse = 7;

function frame(now) {
  const dt = Math.min(.05, (now - last) / 1000); last = now; simT += dt;

  /* ── simulation ── */
  // hook events — poisson-ish, weighted to hot orbs
  const targetEps = (SNAP.eventsPerMinute || 90) / 60;
  const actives = orbs.filter(o => o.state === 'active');
  if (actives.length && Math.random() < targetEps * dt * 1.6) {
    const orb = pickWeighted(actives, o => .15 + o.heat);
    fireHookEvent(orb);
    if (Math.random() < .4) fireHookEvent(pickWeighted(actives, o => .15 + o.heat));
  }
  // decay
  for (const k of SPEC_BUCKETS) specRates[k] *= Math.pow(.5, dt / 1.6);
  for (const o of orbs) o.heat = Math.max(o.state === 'stale' ? .04 : .12, o.heat * Math.pow(.5, dt / 9));
  // events/min window
  const cutoff = now - 60000;
  while (eventTimes.length && eventTimes[0] < cutoff) eventTimes.shift();
  const evm = eventTimes.length;
  energy += ((Math.min(1, evm / 110)) - energy) * dt * 1.5;

  // choreography
  if (simT > nextTransition) { nextTransition = simT + 5 + Math.random()*8;
    const hot = actives.filter(o => !o.merging && o.heat > .45 && o.stage !== 'MERGE');
    if (hot.length) advanceStage(hot[Math.floor(Math.random()*hot.length)]); }
  if (simT > nextTide) { nextTide = simT + 34 + Math.random()*20; startTide(); }
  if (simT > nextThaw) { nextThaw = simT + 26 + Math.random()*22;
    const st = orbs.filter(o => o.state === 'stale'); if (st.length) thaw(st[0]); }
  if (simT > nextConvoyPulse) { nextConvoyPulse = simT + 9 + Math.random()*8;
    for (const o of orbs) if (o.convoy) { const s = o.convoy[Math.floor(Math.random()*o.convoy.length)]; s.flash = 1; feed('review', `${s.role} verdict posted`, o.id); } }

  // tide sweep
  if (tide.active) {
    tide.t += dt; tide.x = L.padX - 40 + (tide.t / 1.6) * (W - L.padX*2 + 80);
    for (const o of orbs) if (Math.abs(o.x - tide.x) < 30) tidePass(o);
    if (tide.x > W - L.padX + 40) tide.active = false;
  }

  /* ── movement ── */
  for (const o of orbs) {
    o.wobA += dt * o.wobSpeed * (1 + o.heat * 2.2);
    o.wobB += dt * o.wobSpeed * .7;
    if (o.merging) {
      o.mergeVx += dt * 260; o.x += o.mergeVx * dt;
      burst(o.x, o.y, '#e8edf8', 3, 40, .7, 2);
      if (o.x > L.portalX - 6) finishMerge(o);
      continue;
    }
    if (o.state === 'shelf') {
      o.y += ((L.shelfY) - o.y) * dt * 3;
      o.x += (o.tx - o.x) * dt * 1.5;
      continue;
    }
    if (o.state === 'failed') {
      o.y += Math.sin(simT * .5 + o.wobA) * dt * 3;
      o.x += Math.cos(simT * .4 + o.wobB) * dt * 2;
      if (Math.random() < dt * .8) burst(o.x, o.y, '#ff2d7c', 1, 22, 1.2, 1.4);
      continue;
    }
    if (o.state === 'stale') {
      o.x += ((o.tx + Math.sin(simT * .3 + o.wobA) * 8) - o.x) * dt * 1.2;
      o.y += ((o.ty + Math.cos(simT * .22 + o.wobB) * 4) - o.y) * dt * 1.2;
      if (Math.random() < dt * .5) frostMotes(o.x, o.y, 1);
      continue;
    }
    // active: drift toward anchor + sine bob + frantic orbit when hot
    const orbitR = o.heat * 26;
    o.orbitA += dt * (1 + o.heat * 4);
    const ox = Math.cos(o.orbitA) * orbitR, oy = Math.sin(o.orbitA) * orbitR * .7;
    const bx = Math.sin(o.wobA) * 10, by = Math.cos(o.wobB) * 8;
    o.x += ((o.tx + ox + bx) - o.x) * dt * 3.2;
    o.y += ((o.ty + oy + by) - o.y) * dt * 3.2;
    // soft separation from same-stage neighbors — keeps labels readable
    for (const q of orbs) {
      if (q === o || q.state !== 'active' || q.stage !== o.stage || q.merging) continue;
      const dx = o.x - q.x, dy = o.y - q.y;
      const d2 = dx * dx + dy * dy;
      if (d2 > 1 && d2 < 74 * 74) {
        const d = Math.sqrt(d2), push = (74 - d) / 74 * 26 * dt;
        o.x += (dx / d) * push; o.y += (dy / d) * push;
      }
    }
    if (o.convoy) for (const s of o.convoy) { s.angle += dt * (0.6 + s.heat); s.flash = Math.max(0, s.flash - dt * 2); }
  }

  // particles
  for (let i = particles.length - 1; i >= 0; i--) {
    const p = particles[i];
    p.life += dt;
    if (p.life > p.maxLife) { particles.splice(i, 1); continue; }
    p.x += p.vx * dt; p.y += p.vy * dt;
    if (p.kind === 'spark') { p.vy -= 14 * dt; p.vx *= (1 - dt * 1.4); }
    if (p.kind === 'frost') { p.vx += Math.sin(simT * 2 + p.y) * dt * 4; }
  }
  for (let i = pulses.length - 1; i >= 0; i--) {
    const p = pulses[i]; p.r += dt * (p.maxR - 6) * 1.6; p.alpha -= dt * 1.1;
    if (p.alpha <= 0 || p.r >= p.maxR) pulses.splice(i, 1);
  }
  for (let i = tickers.length - 1; i >= 0; i--) {
    const t = tickers[i]; t.life += dt; t.x += dt * 34;
    if (t.life > t.maxLife) tickers.splice(i, 1);
  }

  /* ── draw GL background ── */
  if (gl) {
    gl.uniform2f(glU.res, glCv.width, glCv.height);
    gl.uniform1f(glU.time, simT);
    gl.uniform1f(glU.energy, energy);
    gl.drawArrays(gl.TRIANGLES, 0, 3);
  }

  /* ── fx canvas ── */
  fx.clearRect(0, 0, W, H);

  // trails fade + stamp
  trail.globalCompositeOperation = 'destination-out';
  trail.fillStyle = 'rgba(0,0,0,0.055)';
  trail.fillRect(0, 0, W, H);
  trail.globalCompositeOperation = 'lighter';
  for (const o of orbs) {
    if (o.state === 'stale' || o.state === 'shelf') continue;
    const rc = ROLE_COLORS[o.role] || '#00d4ff';
    const g = trail.createRadialGradient(o.x, o.y, 0, o.x, o.y, 5 + o.heat * 8);
    g.addColorStop(0, hexA(rc, .5 * (0.25 + o.heat)));
    g.addColorStop(1, hexA(rc, 0));
    trail.fillStyle = g;
    trail.beginPath(); trail.arc(o.x, o.y, 5 + o.heat * 8, 0, 7); trail.fill();
  }

  drawRiver();
  drawZones();
  drawPortal();
  drawSun();

  // composite trails additively
  fx.globalCompositeOperation = 'lighter';
  fx.drawImage(trailCv, 0, 0, W, H);
  fx.globalCompositeOperation = 'source-over';

  drawConvoys();
  drawOrbs();
  drawParticles();
  drawPulses();
  drawTickers();
  drawTide();
  drawSpectrum();
  drawStageHeaders();
  drawConstellation();
  drawSequencer();

  /* hover tracking — orbs move, so re-pick every frame (with stickiness) */
  if (mouse.inside) {
    let hit = pickOrb(mouse.x, mouse.y);
    if (!hit && hoverOrb) {
      // hysteresis: a hot orb orbits under a still cursor — only drop hover
      // when the cursor is clearly outside the orb's whole dance circle
      const dx = mouse.x - hoverOrb.x, dy = mouse.y - hoverOrb.y;
      const dropR = Math.max(52, hoverOrb.radius * 4.2);
      if (dx * dx + dy * dy < dropR * dropR) hit = hoverOrb;
    }
    if (hit !== hoverOrb) {
      hoverOrb = hit;
      wrap.classList.toggle('orb-hover', !!hit);
      if (hit) showTooltip(hit); else hideTooltip();
    } else if (hit) {
      positionTooltip(hit);
    }
  }

  /* ── HUD ── */
  hudTick(evm);
  requestAnimationFrame(frame);
}

function hexA(hex, a) {
  const n = parseInt(hex.slice(1), 16);
  return `rgba(${(n>>16)&255},${(n>>8)&255},${n&255},${a})`;
}
function fmtAge(m) { if (!m) return '—'; if (m >= 1440) return Math.round(m/1440) + 'd'; if (m >= 60) return Math.round(m/60) + 'h'; return m + 'm'; }

function drawRiver() {
  const midY = (L.riverTop + L.riverBottom) / 2, rh = L.riverBottom - L.riverTop;
  // luminous flow band
  const grad = fx.createLinearGradient(0, L.riverTop, 0, L.riverBottom);
  grad.addColorStop(0, 'rgba(0,212,255,0.015)');
  grad.addColorStop(.5, 'rgba(0,212,255,0.06)');
  grad.addColorStop(1, 'rgba(0,212,255,0.015)');
  fx.fillStyle = grad;
  fx.fillRect(L.padX, L.riverTop, W - L.padX*2, rh);
  // three sine layers — the "waves"
  for (let layer = 0; layer < 3; layer++) {
    const amp = (10 + layer * 9) * (0.7 + energy * 1.1);
    const speed = simT * (0.7 + layer * 0.45) * (1 + energy);
    fx.beginPath();
    for (let x = L.padX; x <= W - L.padX; x += 6) {
      const y = midY + Math.sin(x * 0.012 + speed + layer * 1.7) * amp + Math.sin(x * 0.031 - speed * 1.4) * amp * .35;
      x === L.padX ? fx.moveTo(x, y) : fx.lineTo(x, y);
    }
    fx.strokeStyle = `rgba(0,212,255,${0.05 + layer * 0.035 + energy * 0.05})`;
    fx.lineWidth = 1.5 - layer * .3;
    fx.stroke();
  }
  // flow chevrons scrolling right
  fx.save(); fx.globalAlpha = .10 + energy * .08;
  fx.strokeStyle = '#00d4ff'; fx.lineWidth = 1.5;
  const off = (simT * 60) % 90;
  for (let x = L.padX - 90 + off; x < W - L.padX; x += 90) {
    fx.beginPath(); fx.moveTo(x, midY - 7); fx.lineTo(x + 9, midY); fx.lineTo(x, midY + 7); fx.stroke();
  }
  fx.restore();
  // stage separators
  for (let i = 1; i < STAGES.length; i++) {
    const x = L.colX(i);

    fx.fillStyle = g; fx.fillRect(x - .5, L.riverTop - 30, 1, L.riverBottom - L.riverTop + 36);
  }
}

function drawSpectrum() {
  const y0 = H - L.spectrumH;
  fx.fillStyle = 'rgba(5,7,15,.75)';

  fx.strokeStyle = 'rgba(0,212,255,.18)'; fx.beginPath(); fx.moveTo(0, y0 + .5); fx.lineTo(W, y0 + .5); fx.stroke();
  const N = 64, bw = (W - L.padX*2) / N;
  if (!drawSpectrum.peaks) drawSpectrum.peaks = new Array(N).fill(0);
  const peaks = drawSpectrum.peaks;
  for (let i = 0; i < N; i++) {
    const bk = SPEC_BUCKETS[i % SPEC_BUCKETS.length];
    const rate = specRates[bk];
    const idle = .05 + .04 * Math.sin(simT * 3 + i * .7) + .03 * Math.sin(simT * 7.3 + i * 2.1);
    const v = Math.min(1, idle + rate * (0.55 + 0.45 * Math.sin(i * 1.3 + simT * 5)));
    const h = Math.max(2, v * (L.spectrumH - 12));
    const x = L.padX + i * bw;
    // winamp gradient: cyan → green → amber
    const grad = fx.createLinearGradient(0, H - 4, 0, y0 + 6);
    grad.addColorStop(0, '#00d4ff'); grad.addColorStop(.55, '#39ff14'); grad.addColorStop(1, '#ffb800');
    fx.fillStyle = grad; fx.globalAlpha = .85;
    fx.fillRect(x + 1, H - 4 - h, bw - 2, h);
    // peak cap
    peaks[i] = Math.max(peaks[i] - (L.spectrumH * .4) * (1/60), h);
    fx.fillStyle = '#e8edf8'; fx.globalAlpha = .8;
    fx.fillRect(x + 1, H - 6 - peaks[i], bw - 2, 1.6);
    fx.globalAlpha = 1;
  }
  fx.font = '600 8.5px "JetBrains Mono"'; fx.fillStyle = 'rgba(122,138,170,.7)';
  fx.fillText('HOOK SPECTRUM · ' + HOOK_KEYS.map(k => HOOKS[k].label).join(' / '), L.padX, y0 + 12);

function pickOrb(mx, my) {
  for (let i = orbs.length - 1; i >= 0; i--) {
