# Keyboard shortcuts

The dashboard has one set of keyboard shortcuts. Each one names its keys for macOS and for Linux and Windows, because the browser keeps some keys for itself on each platform.

## Open the list

Press `?` anywhere outside a text field to open the **Keyboard shortcuts** sheet. It lists every shortcut that works on the page you are on, with the keys for your platform. On God View, `?` opens God View's own help instead.

## Shortcuts

| Action | macOS | Linux and Windows |
| --- | --- | --- |
| Command palette | `⌘K` | `Ctrl+K` |
| Find a conversation | `⌘J` | `Ctrl+J` |
| Search | `/` | `/` |
| Go to Pipeline | `G` then `P` | `G` then `P` |
| Go to Board | `G` then `B` | `G` then `B` |
| Go to Agents | `G` then `A` | `G` then `A` |
| Go to Command Deck | `G` then `C` | `G` then `C` |
| Keyboard shortcuts sheet | `?` | `?` |
| Go to Stage tab 1 to 9 | `⌘1` to `⌘9` | `Ctrl+Alt+1` to `Ctrl+Alt+9` |
| Close the Stage tab | `⌘W` | `Ctrl+Alt+W` |
| Toggle the terminal drawer | `⌘T` | none |
| Collapse the sidebar | `[` | `[` |
| New conversation (Command Deck) | `N` | `N` |
| Show or hide Files | `⌘⇧E` | `Ctrl+Shift+E` |
| Show or hide Changes | `⌘⇧G` | `Ctrl+Shift+G` |
| Search file contents | `⌘⇧F` | `Ctrl+Shift+F` |
| Go to file | `⌘P` | `Ctrl+P` |
| Next / previous file in a diff | `J` / `K` | `J` / `K` |
| Emergency stop | `⌘⇧.` | `Ctrl+Shift+.` |

For the `G` shortcuts, press `G`, let go, then press the second key within one and a half seconds.

## Where shortcuts work

Single keys such as `N`, `?`, `/`, `[`, `J`, `K` and the `G` shortcuts, and the Stage tab keys, work only when you are not typing. They do nothing while focus is in a text field, a terminal or a code editor, so the key goes to what you are typing in.

Shortcuts with `⌘` or `Ctrl`, such as the command palette, also work in text fields and code editors. In a terminal, the terminal gets the key first: `Ctrl+K`, `Ctrl+J` and `Ctrl+W` go to the shell, as they would in any terminal. The emergency stop works from anywhere outside a terminal, including text fields.

The four Files keys (show or hide Files, show or hide Changes, search file contents and Go to file) work only in the Command Deck, where the work dock is. There they work from anywhere, including text fields and the code editor, where they win over the editor's own keys: on macOS `⌘⇧G` opens Changes instead of Monaco's Find Previous. On other pages, `Ctrl+P` keeps the browser's print dialog.

In a conversation, `Ctrl+F` without `Shift` opens the conversation's own find bar instead of the dock's Search box; add `Shift` to reach Search file contents.

## Keys the browser keeps

Chrome never passes `Ctrl+N`, `Ctrl+T` or `Ctrl+W` to a web page, and on Linux and Windows it keeps `Ctrl+1` to `Ctrl+9` to switch browser tabs. That is why Stage tabs switch with `Ctrl+Alt+1` to `Ctrl+Alt+9` and close with `Ctrl+Alt+W` there. On macOS, `⌘1` to `⌘9` and `⌘W` reach the page, so they stay.
