# Knowledge Repository

This repository stores an Open Knowledge Format bundle for the paired code repository.

Use the code repository's `/okf` skill commands to author, sync, validate, embed, and extract knowledge.

## Local Checks

```bash
python3 ../code-repo/skills/okf/scripts/validate.py --bundle . --strict
```
